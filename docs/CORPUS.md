# CORPUS

Large PDF corpora are fetched, checksum-verified, and gitignored. The committed
`fixtures/` directory contains only small generated files.

## Layout

```text
corpus/
├── manifest.toml
├── cache/            # gitignored downloads
├── private/          # gitignored, never uploaded
└── README.md
```

## Committed fixtures

`fixtures/` holds 50 deterministic PDFs (about 68 KiB total) generated by
`pdfxi-testkit` builders. `fixtures/manifest.toml` records each file's builder,
SHA-256 digest, page count, and text marker; `crates/pdfxi-testkit/tests/`
verifies the hashes and structure on every test run.

```text
cargo run -p pdfxi-testkit --example generate_fixtures   # regenerate
cargo xtask corpus smoke                                 # verify committed set
cargo xtask bench                                        # 50-fixture open timing
```

## Real-world corpus

`fixtures/realworld/` holds small PDFs produced by mainstream software (Excel,
PowerPoint, Edge) plus clearly labelled self-produced fixtures for the slots no
installed external producer can fill (AcroForm, password protection). Each file
is listed in `fixtures/realworld/manifest.toml` with producer, SHA-256, page
count, marker words, and any current core limitation. The Word slots are a
recorded gap; see `orchestration/blockers/T-0215-word-com.md`.

```text
cargo test -p pdfxi-testkit --test realworld_corpus
pwsh -File fixtures/realworld/generate.ps1                 # regenerate
```

`cargo xtask corpus smoke` runs both `committed_fixtures` and this suite.

## manifest.toml

```toml
[[corpus]]
id = "pdfjs"
url = "https://github.com/mozilla/pdf.js/archive/refs/heads/master.zip"
sha256 = "REPLACE_ME"
license = "Apache-2.0"
kind = "render"
```

`cargo xtask corpus fetch` verifies the checksum before extraction.
`cargo xtask corpus smoke` uses only the committed fixture set.

## Rules

- Never commit a corpus download.
- Never upload a private corpus.
- Record license and provenance for every corpus.
- Malformed samples are fuzz seeds, not runtime fixtures.
- Baseline images are generated, not hand-edited.
