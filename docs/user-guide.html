PDFXI user guide

PDFXI is a local PDF viewer and editor for Windows. This page covers the desktop viewer and the command line. Everything runs on this machine; the only network destination is the optional assistant, which connects only when you ask it to.

Getting started

Open the app and choose a PDF from Home, Files, Recent, Starred, the Open button, or drag a file onto the window. Each document opens in its own tab. Tabs remember their scroll position, zoom, rotation and view mode.

Use Save to write changes back to the same file, or Save As to write a copy. Closing a tab with unsaved edits asks before discarding them. If the file changed on disk while you were editing, PDFXI offers Save As instead of overwriting the other change.

The library root is a normal folder you choose. Recent files, stars, bookmarks in the library and the display name are stored in small local files; nothing is uploaded.

Reading and navigation

  • Page controls sit in the bottom bar: previous and next page, a page box you can type into, and the zoom menu.
  • Zoom to a percentage, fit page, fit width, or actual size. Rotation is per tab and independent of the page's own /Rotate.
  • The Pages panel lists thumbnails; click one to jump to that page. Switch between list and grid layouts with the layout button.
  • Find searches the document text, highlights every match and scrolls to the current one. Enter moves to the next match and Shift+Enter to the previous match.
  • Choose the text selection tool and drag over page text to select it; Ctrl+C copies the selection.
  • Links inside the document are clickable. The bottom bar reports the page under the pointer and the selected text length.

Comments and review

The comment tools add real PDF annotations: highlight, sticky note, underline, strikeout and squiggly. Pick a tool, then click or drag on the page. The Comments panel lists every annotation with its author, page and text; clicking a row jumps to it. Notes carry replies and status, and the whole set can be exported and imported as XFDF for review.

Annotations are written into the PDF as standard annotation objects, so other readers show them too. A highlight is a real /Highlight annotation, not a painted rectangle.

Fill & Sign

Open the Fill & Sign panel to fill AcroForm fields directly on the page. Text fields, checkboxes, radio groups and choice fields accept edits; read-only fields refuse them with a message. A rejected value is dropped and the committed value stays visible, so the page never shows a value that was not written.

  • Click a field to edit it, or move through fields with Tab and Shift+Tab.
  • Enter commits a text or choice edit; Esc cancels it.
  • Reset restores every mutable field to its default value as one undoable step.
  • Flatten merges field appearances into the page and removes the form. It asks for confirmation first.
  • Form data can be imported and exported as FDF or XFDF; only the form values are exchanged.
PDFXI never runs JavaScript or XFA. A document that contains either is still fillable through its AcroForm fields, and the panel tells you that the script or XFA layer was not executed.

Pages and bookmarks

  • Organize pages rotates, deletes, extracts, inserts and reorders pages. When pages are removed or reordered, bookmarks and page labels that point at surviving pages follow them; dangling targets are pruned instead of left broken.
  • Combine files merges several PDFs into one document. Bookmarks, forms and metadata from the source documents are carried into the result where they still make sense.
  • The Bookmarks section of the Pages panel adds, renames, deletes and reorders outline entries. A row without a resolvable destination is shown muted and explains why it cannot navigate.
  • Document properties shows the values that are really in the file: title, author, subject, keywords, creator, producer, PDF version and page count. Missing values read “not set”.

Convert and export

  • Export writes page images (PNG, JPEG or a multi-page TIFF) or plain text. Choose the page range, resolution and format in the export card.
  • Create PDF builds a PDF from images and text files you choose. PDFXI does not claim scanner or TWAIN/WIA support.
  • Preflight checks a document against PDF/A and PDF/X profiles and can apply the byte-level fixups the profile allows. A report is not a certification; the checks it performs are listed in the report.
  • Compress rewrites the file with object and cross-reference streams and optional image downsampling.

Protect, redact, sanitize

  • Protect encrypts the document with AES-256 and a user (open) password plus an optional owner (permissions) password. Printing, copying and editing rights are enforced from the permission mask.
  • Remove protection requires the owner password. An open password unlocks reading but does not strip the owner's restrictions.
  • Redact permanently removes the marked content, not just the visible paint. After redaction PDFXI re-extracts text and page images; if verification is not clean, no output file is written.
  • Sanitize removes metadata, XMP, embedded files, JavaScript and other optional content. Encrypted documents are refused by both redaction and sanitize: decrypt first, then sanitize.

Signatures and certificates

Digital signatures use a certificate and private key you supply (PKCS#12 or PEM). PDFXI writes a real CMS signature over the signed byte range and verifies it locally, reporting whether the bytes are intact and whether the certificate chain and time are acceptable. A certificate-addressed encryption envelope lets you encrypt a payload for a recipient's public key; the matching private key is required to open it.

A signature request is a local workflow: PDFXI prepares a document and a request file, and the returned signed copy is verified when you add it back. No signature data is uploaded.

Accessibility

Primary controls expose accessible names, so screen readers announce Open, Print, the rail, tool rows, page navigation and thumbnails instead of an unnamed control. Text fields and the on-page form text/choice widgets accept the standard value actions; checkboxes and radios expose their toggle or selection state. The release gate runs a real NVDA 2026.3 session with its Speech Viewer and checks the announcements. If you use a screen reader, turn on its browse or focus mode while the app is in the foreground.

The document canvas is a rendered image; use the Comments and Pages panels, the page box and Find to move around a document without a pointer. The status line above the bottom bar reports the result of the last action.

Privacy and local data

The library, recent files, stars and display name are local files. The AI assistant connects only when you ask it to. Each question is sent with a bounded excerpt of the open document (at most 24,000 characters, with the page range) to the local OpenCode service, and to no other network destination. The assistant session has no shell, file or network tools, and the excerpt is marked as untrusted data. Disconnect at any time from the assistant panel.

Command line

The pdfxi executable exposes the same document engine without a window. Run pdfxi --help for the command list and pdfxi <command> --help for one command. Common groups are info, render, pages, merge, pack, form, preflight, protect, unprotect, redact, sanitize, sign, verify, convert and export.

Commands print either a human-readable report or JSON, depending on the command and its --json flag. Exit status is 0 on success and non-zero with a typed message on failure.
