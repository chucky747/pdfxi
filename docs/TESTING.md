# TESTING

## Test pyramid

| Layer | Location | Budget | Notes |
|---|---|---|---|
| Unit | crate `#[cfg(test)]` | < 30 s total | Pure logic, no I/O |
| Integration | `tests/` per crate | < 60 s total | Generated fixtures |
| Doc tests | rustdoc | < 30 s | Public examples compile |
| Full | `--profile full` | < 15 min | Corpus subsets, OCR, render |
| Nightly | CI | < 2 h | veraPDF, fuzz, mutation, full corpus |
| Release | CI | 24 h fuzz | No panics on malformed corpus |

## Rules

- No network, GUI, sleeps, or secrets in fast tests.
- One behavior per test; the name states the behavior.
- A bug fix adds a regression test that fails without the fix.
- Fixtures are generated by `pdfxi-testkit` where possible.
- Large corpora are fetched by checksum and never committed.
- Flaky tests are quarantined the same day; a quarantine needs an owner and a
  date.

## Corpus

| Corpus | Use | Storage |
|---|---|---|
| Generated minimal PDFs | unit/integration | committed |
| PDF Association examples | feature coverage | fetched |
| pdf.js test suite | rendering/parsing | fetched |
| veraPDF corpus | PDF/A, PDF/X | fetched, CI only |
| SafeDocs malformed set | robustness/fuzz seeds | fetched, CI only |
| Adobe-free real-world set | compatibility | local, gitignored |

`cargo xtask corpus fetch` downloads with SHA-256 verification;
`cargo xtask corpus smoke` runs the committed subset.

## Rendering tests

- Render at 72 and 144 DPI.
- Compare against PDFium baselines with SSIM tolerance.
- Store per-platform baselines only when rendering is deterministic.
- Structural assertions (text runs, page boxes, annotation geometry) are
  preferred over pixel-perfect comparisons.

## Security tests

- Encrypted fixtures for revisions 2–6.
- Signature creation and validation with test certificates.
- Redaction verification: extract text and images after redaction and assert
  the removed content is absent.
- JavaScript sandbox escape attempts (filesystem, network, process, time).
- Path traversal for attachments, exports, and memory.

## Performance budgets

| Operation | Budget |
|---|---|
| Open 50 MB / 500 pages | < 1.5 s full, < 300 ms first page |
| 1080p page render | < 150 ms |
| Scroll | 60 fps |
| Search 500 pages | < 1 s |
| OCR | > 2 pages/s CPU |
| Incremental annotation save | < 2 s on 500 MB |
| Memory | < 1.5× file + 512 MB |
| Batch | linear with cores |

Criterion benchmarks are tracked; >10% regression fails.

## Accessibility tests

- Tag tree and reading order round-trip.
- PDF/UA checker on generated fixtures.
- Keyboard-only smoke for every dialog.
- `accesskit` tree snapshot for main panels.
- Screen-reader smoke on Windows.
