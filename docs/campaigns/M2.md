# Campaign C2 — Authoring (M2)

Status: **in progress** (M1 gate verified; authoring tasks T-0058–T-0064 active)

## Scope

- Create PDFs from images, plain text, and HTML.
- Combine, split, extract, reorder, rotate, and crop pages.
- Page labels and page boxes.
- Annotations and comments with appearance streams.
- Bookmarks, links, and attachments.
- Document metadata (XMP and info dictionary).
- Export pages to images and text.
- Print.

## Exit gate

```text
cargo xtask goal-verify --milestone M2
```

Additional acceptance:

- Every M2 feature row is verified with tests, docs, and evidence.
- Annotation round-trips preserve unknown subtypes.
- Page operations are byte-stable for unchanged pages.

## Lanes

- core: page operations, metadata, save.
- author: annotations, links, bookmarks, attachments.
- app: authoring UI and canvas overlays.
- render: page raster for export and print.
- qa: authoring fixtures and golden baselines.
