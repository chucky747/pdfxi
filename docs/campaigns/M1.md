# Campaign C1 — Vertical slice (M1)

Status: **in progress**

## Scope

- Classic xref table and page tree parsing.
- Deterministic fixture builders.
- Renderer and text-extraction contracts.
- PDFium backend proof of concept.
- Viewer shell: open, page display, zoom, rotate, thumbnails, bookmarks.
- Text extraction, search, select/copy.
- CLI `info`, `text`, and `render`.
- 50 generated fixtures and first benchmarks.

## Exit gate

```text
cargo xtask goal-verify --milestone M1
```

Additional acceptance:

- Open a 500-page PDF in under 1.5 seconds; first page under 300 ms.
- No panic on the malformed fixture set.
- Every M1 feature row is verified with tests, docs, and evidence.

## Lanes

- core: xref/page tree, CLI.
- render: renderer/text contracts, PDFium adapter, search.
- qa: fixtures, golden harness, benchmarks.
- app: viewer shell and canvas.
- docs: viewer/CLI pages.
