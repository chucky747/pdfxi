# T-0378 - VIEW-002 page layout control in the GUI

- Date: 2026-11-24
- Lane: integrator
- Status: verified
- Scope: ADR 0009 row `VIEW-002`. The canvas layout engine and the four
  `ViewMode` variants were real, and `AppCommand::SetViewMode` existed, but the
  GUI exposed no control that reached it. The bottom bar now has one.

## Changes

- `crates/pdfxi-app/src/view.rs` - `ViewMode::ALL` in declaration order, used by
  the picker and the tests.
- `crates/pdfxi-app/src/shell/bottom_bar.rs` - a `Page layout` combo box after
  the zoom controls. It lists Single Page, Continuous, Two Page and Two Page
  Continuous and dispatches `AppCommand::SetViewMode`, so the active tab's
  layout changes through the same typed command as every other view action.
  The control carries an AccessKit label (`Page layout`) like the zoom picker.
- `crates/pdfxi-app/src/ui/widget_tests.rs` -
  `bottom_bar_page_layout_switches_the_view_mode` renders the real bottom bar,
  opens the real combo by its AccessKit label, chooses `Two Page`, and asserts
  the tab's mode changed and the status line reports it.
