# T-0375 - SEC-003 certificate encryption reachable from the CLI

- Date: 2026-11-24
- Lane: integrator
- Status: verified
- Scope: ADR 0009 row `SEC-003`. No code change was needed: `pdfxi recipient
  seal` and `pdfxi recipient open` already implement certificate-addressed
  encryption on real bytes. This records the user-reachable evidence and
  promotes the row on the `cli` host.

## Commands

```text
$ pdfxi recipient --help
Certificate-addressed encryption of real files

Usage: pdfxi.exe recipient <COMMAND>

Commands:
  seal  Encrypt a file to one or more recipient certificates
  open  Decrypt a file with the recipient's private key
```

## Evidence

Sealing a 32-byte file to a real P-256 certificate with `print,modify`:

```text
$ pdfxi recipient seal target\tmp\sec-003\secret.txt --out target\tmp\sec-003\secret.envelope.json --cert target\tmp\recipient\recipient-cert.pem --permissions print,modify --json
{
  "out": "D:\\Documents\\opencode-work\\target\\tmp\\sec-003\\secret.envelope.json",
  "bytes": 764,
  "cipher": "aes256-cbc",
  "plaintext_bytes": 32,
  "recipients": [
    "CN=PDFXI Recipient Evidence,O=PDFXI"
  ],
  "wrapped_lens": [
    105
  ],
  "ciphertext_bytes": 48,
  "permissions": 12,
  "permission_names": [
    "print",
    "modify"
  ]
}
seal_exit=0
```

Opening with the matching private key and requiring `modify`:

```text
$ pdfxi recipient open target\tmp\sec-003\secret.envelope.json --key target\tmp\recipient\recipient-key.pem --cert target\tmp\recipient\recipient-cert.pem --out target\tmp\sec-003\secret.recovered.txt --require modify --json
{
  "out": "D:\\Documents\\opencode-work\\target\\tmp\\sec-003\\secret.recovered.txt",
  "bytes": 32,
  "recipient": "CN=PDFXI Recipient Evidence,O=PDFXI",
  "permissions": 12,
  "permission_names": [
    "print",
    "modify"
  ],
  "required": "modify"
}
open_exit=0
recovered=PDFXI recipient evidence payload
match=True
```

The permission gate refuses a permission the sender did not grant:

```text
$ pdfxi recipient open ... --require copy
Error: permission denied for operation: copy
denied_exit=1
```

## Limits

This is file-level certificate encryption, not PDF Standard Security Handler
encryption with recipient permissions enforced by a PDF reader. Certificate
chain and revocation decisions, hardware keystores, and PDF attachment
integration remain host/CA boundaries and are not claimed. RSA recipient keys
remain unsupported by design (the AES-KW provider is ECDH P-256).
