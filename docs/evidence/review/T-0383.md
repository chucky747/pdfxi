# T-0383 - CREATE-007 WIA scanner acquisition reachable from the CLI

- Date: 2026-11-24
- Lane: integrator
- Status: verified
- Scope: ADR 0009 row `CREATE-007`. The scan assembly pipeline accepted
  caller-supplied PNG pages; no device adapter existed. `pdfxi create scan
  --device` now acquires pages from an attached WIA scanner, and the scan
  assembly, duplex ordering and verification are unchanged.

## Changes

- `scripts/wia-scan.ps1` (new) - WIA COM sidecar. Enumerates `WIA.DeviceManager`
  devices, matches `-DeviceName` by substring, connects, transfers each page and
  writes PNG files. Many WIA drivers ignore the requested PNG format and
  transfer BMP, so the sidecar sniffs the file header and converts BMP to PNG
  with `System.Drawing`; an unsupported transfer is a typed error. No device or
  a busy device exits 3 with a message the CLI reports as a hardware error.
- `crates/pdfxi-cli/src/scan.rs` - the sidecar is embedded with `include_str!`;
  `acquire_wia` writes it to a private temporary directory (or uses the
  `PDFXI_WIA_SCAN_SCRIPT` test seam), runs it, parses its JSON page list, and
  feeds those paths through the existing scan plan, image embed and merge.
  Non-zero sidecar exit 3 becomes `no scanner is available: ...`; other failures
  keep the sidecar's message.
- `crates/pdfxi-cli/src/main.rs` - `create scan --device [NAME]`; `--scan` is no
  longer required, and the command requires at least one source.
- Two CLI tests: a synthetic WIA sidecar copies two real PNGs and reports their
  paths, and the run assembles and verifies a two-page PDF; a sidecar that exits
  3 makes the command fail with `no scanner`.
- `docs/book/src/authoring.md` documents `--device` and the WIA sidecar.

## Limits

WIA only; TWAIN is not spoken directly, though TWAIN drivers usually install a
WIA wrapper. One page per `Items` entry; automatic document feeders are used
only when the driver exposes them as items. Duplex ordering still comes from
`--duplex` and the caller's page order. The device-dependent step was verified
on the HP Officejet Pro 6830 on this host; other devices remain untested.
