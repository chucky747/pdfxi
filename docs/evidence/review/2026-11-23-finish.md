# 2026-11-23 finish review — fixes and verification

Source review: `2026-11-23-pdfxi-finish-review-b1c8ad3a.md` (outside the repo,
under the user's plan directory). Scope: every blocking defect, every high
finding, the medium UI/security items, and the honesty/process items. GitHub CI
is not used; Windows is the only verified support target. The version is
`0.1.3`; tags `v0.1.0`–`v0.1.2` are untouched.

## Blocking defects

- **B1 text selection**: `Toolset::TextSelection` is the default tool; `V`/`T`/
  `H`/`Y`/`F`/`M` select tools when no text field has focus. Selection boxes are
  painted over the page, a release reports `Selected N characters`, and
  `Ctrl+C` copies through `AppCommand::CopySelection`. The clipboard path needed
  one extra fix: `egui-winit` translates the platform copy chord into
  `egui::Event::Copy` and deliberately drops the `C` key event, so the handler
  now consumes that event through `copy_requested` (a focused text field keeps
  its own copy). Tests:
  `ui::tests::copy_event_is_recognized_from_the_platform_chord`,
  `ui::tests::a_focused_text_field_keeps_its_own_copy`,
  `ui::tests::unrelated_events_do_not_copy`.
- **B2 password dialog**: `apply_password_dialog` restores the prompt before
  dispatching `SubmitPassword`/`CancelPasswordPrompt`. Regression test:
  `ui::shell::session::tests::dialog_submission_restores_the_prompt_before_opening`.
- **B3 catalog loss**: `apply_page_plan` carries the source catalog and remaps
  page references for outlines, AcroForm, names/dests, page labels, structure
  tree, MarkInfo, Lang, metadata, OCProperties, viewer preferences and output
  intents; dangling entries are pruned. Tests:
  `pages::tests::rotation_preserves_bookmarks_forms_labels_and_metadata`,
  `pages::tests::removed_pages_prune_outlines_forms_and_page_labels`.
- **B4 window close**: a close request with any dirty tab is cancelled and the
  existing save/discard prompt walks every dirty tab before
  `ViewportCommand::Close`. Test:
  `ui::tests::window_close_prompts_for_each_dirty_tab`.
- **B5 deep page trees**: `MAX_PAGE_TREE_DEPTH = 64` in the page-tree walker
  (now a `PageTreeWalker`), returning a typed `MalformedPageTree` error. Test:
  `crates/pdfxi-core/tests/deep_page_tree.rs` (200 and 20,000 levels on a
  256 KiB stack).
- **B6 form flags**: `/Ff` bit 1 is ReadOnly, bit 2 is Required in
  `field.rs`/`acrofill.rs`. Tests updated in `pdfxi-forms` and the CLI.

## High findings

- **H1 redaction fails open**: `write_redacted` refuses to write when
  verification is not clean, and redaction/sanitize refuse encrypted sessions.
  Verification also drops every marked page's `/Thumb` (pre-rendered content),
  scans UTF-16LE/BE in text-bearing streams, decodes form `/V`, `/DV`, `/RV`,
  and checks bookmark titles. Test:
  `ui::shell::redact_card::tests::a_failed_verification_writes_no_file`.
- **H2 false encryption detection**: `pdfxi_core::is_encrypted` reads the parsed
  trailer `/Encrypt` reference instead of scanning the last 64 KiB. Tests cover
  a file that merely mentions `/Encrypt`.
- **H3 advisories**: `url` 2.5.9 and `p256` 0.14 (with `ecdsa` 0.17 /
  `crypto-bigint` 0.6) removed RUSTSEC-2026-0592 and RUSTSEC-2026-0387.
  `cargo deny check` is green; the existing scoped RSA ignore remains.

## Medium and low items

- `Ctrl+O` opens a document. The status line renders every command result above
  the bottom bar.
- `/EncryptMetadata false` leaves XMP streams in the clear; the `/ID` is random
  when the source has none, never password-derived.
- `pdfxi form list` reads any `pdfxi_core` document, including xref/object
  streams and PDFXI's own `pack` output.
- `unprotect` requires the owner (permissions) password; a user password is
  refused with `SecurityError::OwnerPasswordRequired`. Authentication tries the
  owner entry first so a single-password file still grants owner rights.
- Form editor: the text editor is bound to the widget id (first click focuses
  it) and a rejected value is dropped with a message instead of staying on the
  page.
- Thumbnails preserve the page aspect ratio; the Bookmark section is a resizable
  bottom panel above the storage meter instead of clipping.
- Help opens one rendered `docs/user-guide.html`; raw Markdown and internal
  notes are no longer the user guide. The installer test and package validation
  require that page.
- PDFium failures are described in one sentence (no debug dumps such as
  `PdfiumLibraryInternalError(Unknown)`).
- Accessibility: primary controls (toolbar, icon buttons, caption lights, rail,
  tabs, avatar, thumbnails, title-bar actions) publish accessible names.
- Process: matrix rows overstating reachability were downgraded (`library`,
  `model`, `deferred`); `docs/FEATURES.md` states the honest counts; the ignored
  live test citation was removed from SEC-013; T-0281 and T-0202 record their
  matrix alignment and the unsigned-build limitation; tracked `_fmt.log` and
  `_t.log` were removed.

## Known limits

- Windows x86_64 only; Linux/macOS builds are not supported or claimed.
- The build and installer are unsigned (T-0202); SmartScreen may warn. The real
  AppId setup returned exit 1 on this host when 0.1.3 was already present via the
  portable install; the smoke-identity setup built from the same staging payload
  installed and uninstalled cleanly, and the supported `scripts/install.ps1`
  path was used for the verified installed build.
- A 24-hour fuzz campaign has not run on this host (T-0260A).
- The upgrade install keeps old guide files in `docs\`; a clean install ships
  only `docs\user-guide.html`.
- GitHub CI is not used.
