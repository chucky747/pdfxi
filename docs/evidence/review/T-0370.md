## 1. Canvas form widgets accept AccessKit SetValue

`crates/pdfxi-app/src/shell/forms.rs` now advertises
`accesskit::Action::SetValue` on the text and choice widget nodes, consumes
`ActionData::Value` on the same node id, and dispatches the existing typed
`SetFormText` / `SetFormChoice` command. Checkboxes and radios keep their
standard Toggle/Select patterns; pushbuttons and signatures carry no value.

## 2. Installed-build B1 selection/copy and SetValue

`scripts/ui-smoke.ps1` now generates `selection-content.pdf`, finds the white
page rectangle in a screenshot at runtime, drags across the page with real
input, asserts the `Selected N characters` status, presses Ctrl+C, and reads the
clipboard back. The same section seeds the clipboard with a sentinel so a stale
value cannot pass.

The forms section uses `Set-ElValue` (UI Automation ValuePattern) on
`Form field plain_ff0`, asserts the value was written and the model status
became `Filled plain_ff0`, then discards the now-dirty document on close.


The first installer-test against the release build copied 219 characters: the
page-bounds scan used one row at 55% of the screenshot, which crossed a text line
and returned only the white run to the right of the text. The scan now tries the
50/60/70/80% rows and keeps the widest run. The packaged release then copied all
230 characters with the marker. Debug and packaged-release runs both pass 33/33.

## 4. T-0260B save-budget policy

`docs/TESTING.md` now states that real-file saves use a 25 ms durability floor
before the +25% allowance, because the timed region includes `sync_all` and the
rename. The in-memory harness keeps its 5 ms floor; the 2000 ms absolute row is
unchanged. `T-0260B-measure.rs` applies the floor to `save` only.


run above is from the fixed wrapper.
