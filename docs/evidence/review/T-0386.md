# T-0386 - Add cargo deny to the local CI gate

- Date: 2026-11-24
- Lane: integrator
- Status: verified
- Scope: make `cargo xtask ci` run the license/advisory/ban/source policy gate
  named in the goal end condition.

## Change

- `xtask/src/main.rs`: `ci()` now calls `deny_check()` after `verify(false)` and
  before `docs()`; `deny_check()` runs `cargo deny check`.
- The generated `target/ci/ci-report.md` lists `cargo deny check`, the NVDA
  smoke and the Authenticode check among the steps.
