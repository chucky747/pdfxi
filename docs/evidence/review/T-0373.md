# T-0373 - real NVDA screen-reader gate and ACCESS-006

- Date: 2026-11-24
- Lane: integrator
- Status: verified
- Scope: replace the "no platform screen reader" limitation with a real NVDA
  session and promote ACCESS-006 on the gui host.

## Tool

NVDA 2026.3 (free, open source) was installed as a portable copy under the
untracked build-tools directory with the vendor installer:

```text
NVDA D:\Documents\opencode-work\target\tools\nvda-portable\nvda.exe
```

The smoke uses a dedicated `--config-path` under its output directory with
Speech Viewer enabled, welcome/usage/update dialogs disabled, and no change to
the developer's real NVDA configuration.

## Gate

`scripts/screen-reader-smoke.ps1`:

- starts NVDA with the Speech Viewer;
- starts the installed viewer on `fixtures/realworld/pdfxi-forms-selfmade.pdf`;
- drives 35 Tab presses through the shell with real SendInput;
- focuses the page number, next page, Fill & Sign, and the three form widgets;
- reads the Speech Viewer document through UI Automation;
- asserts names, roles and values; fails closed if NVDA is absent.

`cargo xtask ci` runs it against the installed viewer after installer-test.

## Limits

The smoke requires NVDA on the host. It resolves `-NvdaPath`, `PDFXI_NVDA`, the
portable copy under `target\tools`, the installed Program Files locations, or
PATH; when none exists it exits 2 with a blocker message instead of passing.
Windows is the only verified target.
