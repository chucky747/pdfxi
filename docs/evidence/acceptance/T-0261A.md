### Claims kept explicit

- **Shortcut discrepancy:** the book states the bound shortcut is
  <kbd>Ctrl</kbd>+<kbd>N</kbd> and that the Home/Help `Ctrl+O` hint is stale.
- **Off surfaces:** Edit, Export, Organize Pages, Add page, the page menu, and
  shared review are marked unavailable. Shared is described as a placeholder,
  not a review workflow.
- **Sign is live.** The security table and Sign page describe the **Tools → Sign**
  card, PKCS#12 import, typed appearance plus viewer overlay, incremental
  signature, per-tab verification readout, and the green `✓ E-signed` chip.
  Protect PDF and Redact remain unavailable with T-0263 pending.
- **Encrypted save and encrypted signing** are both refused. The exact save
  refusal text is quoted: `saving an encrypted document is not supported yet`.
- **Signing limits:** no trust anchor, no revocation check, no RFC 3161
  timestamp, no drawn/image placement, no request/tracker. The badge condition is
  `Valid && bytes_match && covers_entire_file && !appended`, and it is an
  integrity/coverage statement, not identity.
- **Assistant:** nothing is sent before Ask; the page names the only connection
  endpoints; the app turn attaches no tool server
  ([ADR 0013](../../decisions/0013-assistant-document-grounding-fallback.md)).
- **Redaction:** vector paths under a mark are not removed; sanitize is
  library-level until T-0257/T-0263; verification is by re-extraction and byte
  scan.
- **Portability:** examples use `~/Documents/PDFXI`, `%APPDATA%`, `%USERPROFILE%`,
  and `$XDG_CONFIG_HOME`, never a machine-specific absolute path.

### 2. Local link check

A PowerShell pass resolved every relative Markdown link in `docs/book/src`,
including the new `security/` subdirectory, against the file system. It ignores
`http(s):`, `mailto:`, and pure `#` anchors:

```powershell
$root='docs/book/src'; $bad=@()
Get-ChildItem $root -Recurse -Filter *.md | ForEach-Object {
  $f=$_; $t=Get-Content -Raw $f.FullName
  [regex]::Matches($t,'\]\(([^)]+)\)') | ForEach-Object {
    $l=$_.Groups[1].Value
    if($l -notmatch '^(https?:|mailto:|#)') {
      $p=$l.Split('#')[0]
      if($p -and -not (Test-Path ([System.IO.Path]::GetFullPath((Join-Path $f.DirectoryName $p))))) {
        $bad += "$($f.FullName.Substring($root.Length+1)) -> $l"
      }
    }
  }
}
if($bad.Count){$bad}else{'ALL LOCAL LINKS RESOLVE'}
```

Result:

```text
ALL LOCAL LINKS RESOLVE
```
