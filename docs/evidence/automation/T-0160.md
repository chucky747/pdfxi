## Scope notes

- AUTO-001: versioned text serialization of the existing `ActionSequence`,
  with lossless round-trip, structural validation, and typed version/syntax
  errors. No UI Action Wizard editor is added (out of this crate's boundary).
- AUTO-002: FIFO batch queue over `ActionSequence` with a validated state
  machine, cooperative cancellation, and byte-stable reports. Step effects stay
  behind an injected runner trait; no I/O or real PDF mutation.
- AUTO-005: typed operation registry mirroring `SUPPORTED_COMMANDS`, with
  argument validation and typed call plans. The CLI crate was not edited; the
  registry is the library-level model a CLI adapter can consume.
