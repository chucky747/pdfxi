## Scope delivered

- **AUTO-003** — new `crates/pdfxi-automation/src/watched_schedule.rs`: host-driven
  `PollSchedule` with `PollInterval` (every-poll / every-N-ticks), bounded
  fixed-point `BackoffPolicy`, `ScheduleDecision` and a byte-stable `status_summary`;
  `MarkerSnapshot` provides a validated, versioned canonical-JSON persistence
  contract for `ProcessedMarkers` (`serialize_markers` / `deserialize_markers`).
  No thread, clock, or OS watcher.
- **AUTO-008** — new `crates/pdfxi-automation/src/plugin_output.rs`: typed
  `PluginValue` / `OutputType`, size-bounded `PluginOutput` with `OutputBudget`
  and typed `PluginOutputError`, and a deterministic non-executing `ExecutionPlan`
  (`build_execution_plan`) with fixed-order `ExecutionStep`s reusing capability,
  ABI, registration, and budget checks from `plan_invocation`. No WASM runtime.

Both rows are closed at the library level. The remaining host/OS boundary (an OS
watcher thread, a WASM runtime with host functions and real budget metering, and
CLI/UI wiring) is explicitly out of scope for this task and is recorded in the
feature-update fragment.
