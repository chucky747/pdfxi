## Reviewer nits closed

1. **Export-path escape.** `resolve_export_target` now rejects absolute targets
   and any `ParentDir`/`RootDir`/`Prefix` component with a typed
   `OperationError` before a path is recorded. The integration test
   `action_run_rejects_escaping_export_targets` covers `../escape.pdf`, an
   absolute Windows path, and a normal relative name; it asserts the two escape
   attempts fail at the `save` step with a clear message and that neither the
   outside sentinel nor the absolute target is created. The normal relative
   name resolves under `--output-dir` and still writes no file.
2. **Unbounded input read.** `MAX_STAGED_INPUT_BYTES` (512 MiB) is checked from
   file metadata by the small `check_input_size(size, display)` helper before
   `std::fs::read`. The unit test exercises 0, the exact boundary, and one byte
   over the limit without allocating a large file.
