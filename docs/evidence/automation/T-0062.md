## Security-review changes (HIGH / MEDIUM / LOW)

### HIGH — cycle-safe, budgeted string conversion

- Replaced the recursive `to_js_string` with `Interpreter::stringify` + `write_string`, which track array identities on the current path and reject a repeated identity with the new typed `JsError::CyclicValue`. A `MAX_STRING_CONVERSION_DEPTH` cap of 32 rejects deep acyclic values with `JsError::ValueTooDeep`. Neither path can overflow the native stack.
- `write_string` and its `push_string` helper call `tick(pos)` for every value and every appended chunk, so conversion charges CPU steps and honours cancellation/wall-clock limits.
- Covered by `self_referential_arrays_are_rejected_by_string_conversion_paths` for all four entry points: `String(a)`, `a.join(',')`, `a.toString()`, and `'' + a`; plus `deeply_nested_values_are_rejected_without_stack_overflow` and `string_conversion_charges_cpu_steps`.

### MEDIUM — incremental size enforcement

- String concatenation (`+`), array `join`/`toString`, and `String(array)` now append into a single buffer via `push_string`, which checks the projected character count against `max_string_len` *before* each append; no full `format!`/`join` allocation happens first. Case-conversion methods check the projected expanded length before allocating, and `split` checks array/string budgets per element.
- Regression: `join_and_concat_enforce_string_size_incrementally` builds a 100-element array of 40-character strings with `max_string_len = 1000` and asserts `StringTooLarge`; also covers `+` and `String([...])`.

### LOW — alignment fixes

- `indexOf` now reports character offsets (matching `length`/`charAt`) instead of UTF-8 byte offsets.
- `substring` swaps reversed arguments; `slice` keeps its previous clamping behaviour.
- Object index reads now use the active `Limits` for key conversion (previously `Limits::default()`); writes already did. Regression: `object_index_operations_use_the_active_limits`.
- Compound assignment resolves its target once into a `Place` before evaluating the right-hand side, so a side-effecting index/object expression is evaluated exactly once for the read and the write. Regression: `compound_assignment_evaluates_index_and_object_expressions_once`.

## Coverage delivered

### JavaScript subset (dependency-free, deterministic)

- Lexer: numbers (integer/decimal/exponent), single- and double-quoted strings with escapes, identifiers, line/block comments, and typed markers for unsupported operators (`===`, `=>`, `**`, `??`, `?.`, `...`, template literals, etc.).
- AST + recursive-descent parser with a documented precedence table: assignment (`= += -= *= /=`), `||`, `&&`, `== !=`, `< <= > >=`, `+ -`, `* / %`, unary `! - +`, postfix call/dot/index. Binary operators are left-associative, assignment is right-associative, `&&`/`||` short-circuit and return operands.
- Statements: `let`/`var`/`const`, expression statements, blocks, `if`/`else`, `while`, `for`, function declarations and calls, `return`, `break`, `continue`. Function declarations are hoisted per scope.
- Values: numbers, strings, booleans, `null`, `undefined`, mutable arrays and objects with dot/bracket reads and writes, user functions, whitelisted built-ins, and host objects.
- Built-in whitelist: free functions `Number`, `String`, `Boolean`, `parseInt`, `parseFloat`, `isNaN`; `Math.abs/floor/ceil/round/min/max/sqrt/pow`; string methods `length`, `toString`, `toUpperCase`, `toLowerCase`, `trim`, `charAt`, `indexOf`, `slice`, `substring`, `split`; array methods `length`, `toString`, `join`, `push`, `pop`, `slice`, `indexOf`, `concat`, `reverse`. All are date-free, random-free, and deterministic.
- Errors: typed `JsError` enum with 1-based line/column and character offset, deterministic messages, and `Display`/`Error` implemented directly (the crate is dependency-free; adding `thiserror` would modify the integrator-owned `Cargo.lock`).

### Budget and cancellation enforcement

- CPU steps (`max_steps`), call depth (`max_call_depth`), total calls (`max_calls`), per-loop iterations (`max_loop_iterations`), total iterations (`max_total_iterations`), string length (`max_string_len`), array length (`max_array_len`), object entries (`max_object_entries`), parser nesting (`max_ast_depth`), and optional wall clock (`wall_clock`).
- Cancellation token checked on every evaluation step and during string conversion; a host call can cancel mid-run.
- No filesystem, network, process, environment, timer, or global-object access; unresolved names are `AmbientAccess` errors.

### Dangerous-global / unsupported-syntax rejection

- `eval`, `Function`, `require`, `import`, `export`, `process`, `globalThis`, `global`, `window`, `self`, `this`, `arguments`, `Reflect`, `Proxy` → `JsError::DangerousGlobal` with source position.
- `new`, `class`, `delete`, `typeof`, `instanceof`, `switch`/`case`, `try`/`catch`/`finally`, `throw`, `async`/`await`, `yield`, `=>`, template literals, `===`, and similar → `JsError::UnsupportedSyntax`.
- Host registry rejects dangerous/reserved/duplicate names, so PDF actions can later expose only an audited fixed set of document operations.
