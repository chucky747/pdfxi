Real invocation:

```text
$ pdfxi search fixtures/minimal.pdf PDFXI
page 1 offset 7 PDFXI

$ pdfxi search fixtures/minimal.pdf PDFXI --json
{"file":"fixtures/minimal.pdf","query":"PDFXI","matches":[{"page":1,"offset":7,"text":"PDFXI"}]}

$ pdfxi search fixtures/minimal.pdf absent
no matches
```

Exit code is 0 on a successful search with zero matches; usage and I/O failures
exit non-zero with an actionable message. Offsets are character offsets, ordered
by page then offset.
