# T-0023 — FlateDecode and stream filters

Status: verified (task); STD-002 stays in-progress until xref streams land.

## Files

- `crates/pdfxi-core/src/filter.rs` — dependency-free, cap-bounded inflater
  (stored, fixed Huffman, dynamic Huffman), zlib header and Adler-32 validation,
  raw-DEFLATE fallback, PNG predictors 10–15, explicit unsupported-filter
  errors.
- `crates/pdfxi-core/src/lib.rs` — `page_content`/`page_text` decode Flate
  streams transparently and name unsupported filters.
- `crates/pdfxi-core/src/parser.rs` — `/Filter` and `/DecodeParms` parsing.

## Verification

```text
$ . .\scripts\env.ps1 -Lane core
$ cargo test -p pdfxi-core
48 passed; 0 failed; 0 ignored
$ cargo clippy -p pdfxi-core --all-targets --all-features -- -D warnings
clean
$ cargo fmt -p pdfxi-core -- --check
clean
$ RUSTDOCFLAGS="-D warnings" cargo doc -p pdfxi-core --no-deps
clean
```

Coverage includes known zlib and fixed/dynamic Huffman vectors, raw deflate,
stored blocks, all PNG predictors, truncated streams, wrong headers, bad
Adler-32, unsupported filters, the 64 MiB decode cap, and a real Flate-compressed
fixture whose text is extracted through `page_text`.

No new dependency; `#![forbid(unsafe_code)]` remains, and all failure paths are
structured `thiserror` variants.

## Limits

Xref streams and object streams are separate work (T-0031). TIFF predictor 2 and
non-byte-aligned predictor components are rejected explicitly rather than
decoded incorrectly.
