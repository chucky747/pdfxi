## XMP

`/Metadata` on the catalog is located, Flate-decoded, and parsed for
`dc:title`, `dc:creator`, `dc:description`, `dc:subject`, `pdf:Producer`,
`xmp:CreateDate`, and `xmp:ModifyDate`. Writing updates or creates the packet
with a deterministic layout. Prefix handling is namespace-tolerant; malformed
XML returns a structured error.
