## What changed

- `crates/pdfxi-core/src/printer_marks.rs`
  - New public `PrinterMarkApplication` report type (rustdoc on the type and
    every field).
  - New `Document::apply_printer_marks(index, options)` application API: derives
    page boxes from the real page, generates deterministic marks, wraps them in
    a self-contained Form XObject (`/BBox` + font `/Resources`), installs a
    collision-free `/XObject` resource after materialising inherited resources,
    appends a `q /Name Do Q` invocation stream to the page's `/Contents`
    (single ref -> two-element array, existing array -> appended, absent ->
    one-element array), and stages every edit with copy-on-write `set_object`.
  - Bounded helpers: change-aware object reader, cycle-checked `/Parent` walk,
    `u32`-bounded object-number allocator, `MAX_RESOURCE_SUFFIX` name search.
    No `unwrap`/`expect`/`panic!`/`unsafe` in non-test code.
  - New `t0128_tests` module: 13 tests.
- `crates/pdfxi-core/src/lib.rs`: re-export `PrinterMarkApplication`.
- No changes to `pdfxi-cli`, `docs/features.toml`, `orchestration/BOARD.md`,
  manifests, or any other lane's crate. No new dependencies.
