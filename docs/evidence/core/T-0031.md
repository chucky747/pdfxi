# T-0031 — Xref streams, object streams, and the predictor fix

Status: verified (task); STD-003 stays in-progress until linearization is
implemented.

## Files

- `crates/pdfxi-core/src/parser.rs` — `/Type /XRef` detection at startxref,
  `/W`, `/Index`, `/Size`, `/Root`, `/Prev`, `/DecodeParms`; variable-width
  field decoding including type-2 compressed entries; `/Prev` chains with
  newest-wins merging and cycle detection; `/Type /ObjStm` expansion with
  `/N`/`/First` and on-demand object extraction.
- `crates/pdfxi-core/src/xref_tests.rs` — xref-stream and object-stream tests.
- `crates/pdfxi-core/src/filter.rs` — bound the PNG predictor row allocation by
  the decoded length, rejecting hostile `/Columns` before allocating, with a
  regression test.
- `crates/pdfxi-core/src/lib.rs` — structured errors and module wiring.
