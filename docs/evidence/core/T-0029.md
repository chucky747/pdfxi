## Verification

```text

$ cargo clippy -p pdfxi-core --all-targets --all-features -- -D warnings
clean
$ RUSTDOCFLAGS="-D warnings" cargo doc -p pdfxi-core --no-deps
clean
```

Save preserves object numbers and copies unchanged objects byte-for-byte through
their xref offsets, so Flate payloads are never re-compressed. Incremental save
keeps the original bytes as an exact prefix and appends a new xref section whose
trailer `/Prev` points at the original startxref. Encrypted documents and
xref-stream documents return `UnsupportedState` instead of guessing.

## Limits

Classic-table documents only. Non-zero generations and non-finite reals are
rejected. Full preservation and object-stream rewriting are later work.
