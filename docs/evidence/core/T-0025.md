Status: verified (task); AUTO-005 remains in-progress until every scriptable

- `crates/pdfxi-cli/src/image.rs` — pure-Rust PNG encoder (stored-deflate zlib,

- `crates/pdfxi-cli/tests/cli.rs` — feature-gated render integration tests.

Real invocation:

```text
$ pdfxi render fixtures/minimal.pdf --page 0 --scale 1.0 --out page.png
$ pdfxi render fixtures/minimal.pdf --page 0 --scale 1.0 --out page.ppm --format ppm
```

The PNG decodes as a 612×792 RGBA image (validated with .NET System.Drawing).

## Notes

PNG output is intentionally uncompressed (stored deflate blocks): valid, simple,
and dependency-free, at the cost of size. Page numbers are zero-based in the
command, matching the `Renderer` contract; the reference documents this.
