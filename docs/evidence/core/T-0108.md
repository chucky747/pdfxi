## Scope of the change

- `crates/pdfxi-core/src/incremental.rs` (new): `IncrementalSaveOptions`,
  `IncrementalSaveResult`, `PreservationReport`, `first_id_element`, and
  `Document::{save_incremental_with, allocate_object_number,
  assert_object_number_unused, is_object_number_used}`. Writes a classic table
  or a `/Type /XRef` stream per caller, preserves the original bytes as an exact
  prefix, chains `/Prev` to the prior `startxref`, carries `/Root`, `/Info` and
  the first `/ID` element, regenerates the second `/ID` element deterministically,
  and reports preserved vs regenerated parts.
- `crates/pdfxi-core/src/lib.rs`: module declaration, public re-exports and four
  typed error variants (`EncryptedDocument`, `MalformedPriorXref`,
  `ObjectNumberInUse`, `ObjectNumberExhausted`).
- No other crate, shared file, dependency, or `docs/features.toml` row was edited.
