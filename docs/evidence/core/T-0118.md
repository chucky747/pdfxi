## STD-004 — font embedding model (11 new tests)

`font.rs` adds: `FontProgram` (validated opaque program bytes + declared
format), `FontProgramFormat`, `EmbeddingPolicy`, `EmbeddingDecision`,
`decide_embedding` (EmbedFull / SubsetThenEmbed / Standard14), `GlyphWidth` and
`validate_metrics`, `ToUnicodeEntry` and `generate_tounicode` (sorted BFChar
CMap with UTF-16 surrogate pairs), `CidFontOptions`, `CidFontPlan` and
`build_cid_font` (Type0 + CIDFont + FontDescriptor + FontFile stream + ToUnicode
object graph, identity encoding, `/W` run grouping, deterministic subset tag),
`is_standard14`, hard caps, and typed `FontError`.

Honest scope: the model decides and *stages* embedding for a supplied program;
it does not binary-subset the program or wire these objects into `Document::save`
(the producer supplies already-subset bytes). No conformance claim is made.

New tests:

