## EDIT-015 — files and behaviour

- `crates/pdfxi-cli/src/repair.rs` (new): `run_repair(input, output, json)` calls
  `pdfxi_core::repair_document`, validates the output path (rejects `..`
  traversal), refuses to overwrite the input (canonicalized, symlink-aware
  comparison), writes to a distinct output, reparses the written bytes, and
  emits stable text or JSON. `EXIT_REPAIR_FAILED = 3` for unrecoverable input;
  CLI/I/O errors propagate through `anyhow` as exit 1. Typed warnings map to
  stable codes (`startxref_missing`, `xref_rebuilt_by_scan`,
  `wrong_xref_offsets`, `stream_length_corrected`, `truncated_object_end`,
  `truncated_eof`, `duplicate_object`, `header_normalized`, and the header/
  offset variants).
- `crates/pdfxi-cli/src/main.rs`: `mod repair;`, `Command::Repair { input,
  output, json }` with full Clap help text, dispatch, and module-level docs.
- `crates/pdfxi-cli/README.md` (new): command synopsis, safety behaviour and
  exit-code table.
- `crates/pdfxi-cli/tests/cli.rs`: six integration tests build a damaged PDF
  in-test (startxref removed from a one-page fixture) and exercise repair,
  JSON warnings, overwrite refusal, traversal refusal, exit 3 with a typed
  report, and exit 1 for a missing input.

Verified end-to-end: damaged fixture → `pdfxi repair in.pdf out.pdf` → exit 0 →
output reparses with 1 page and text `Hello, repair CLI!`; the input bytes are
unchanged.

## PLAT-007 — files and behaviour

- `crates/pdfxi-core/src/unicode.rs` (new): dependency-free Unicode text model.
  `Script` (Latin/CJK/Hebrew/Arabic/Other), `Direction` (Ltr/Rtl),
  `TextError`, `BidiRun`, `ShapingPlan`, `classify_char`, `dominant_script`,
  `is_strong_direction`, `resolve_base_direction`, `bidi_runs`, `shaping_plan`,
  `validate_utf8`, `validate_grapheme_boundaries` and
  `shaping_plan_with_boundaries`.
- `crates/pdfxi-core/src/lib.rs`: `pub mod unicode;` plus public re-exports.

Chosen contract, documented in the module: UTF-8 validation makes scalar-level
handling surrogate-safe; caller-provided grapheme boundaries are checked for
char-boundary safety and strict increase (no external segmentation crate);
base direction uses a documented first-strong heuristic; the RTL plan reverses
whole runs at paragraph level (a stable shaping-free ordering plan, not full
UAX #9 embedding resolution and not glyph shaping). PLAT-007 therefore advances
to `in-progress`: the core text model for the listed items is complete and
tested, while font fallback, real shaping and viewer integration remain out of
this task's scope.

Eight unit tests cover CJK detection, Arabic/Hebrew bidi runs, mixed-direction
ordering, invalid/empty input, surrogate/char-boundary safety, determinism,
script classification and direction resolution.
