## Reviewer follow-up (three low-severity nits)

1. **Literal-string escaping.** `page_info_label_escapes_literal_string_specials`
   generates marks with label `A(B)\C` and asserts the stream contains the
   escaped form `A\(B\)\\C 552x732 pt`, exercising `(`, `)` and `\` in
   `escape_literal_string`.
2. **Sheet fit.** The required TrimBox margins are now documented in module and
   option rustdoc: `mark_gap + mark_length` on every edge (21 pt default), plus
   `6 + color_bar_height` on the bottom for the colour bar (18 pt) and
   `6 + color_bar_height + 10` for page information (28 pt). A new typed
   `Error::PrinterMarksOutOfSheet { what, required, available }` is returned by
   `generate_printer_marks` when a layout cannot fit. `marks_stay_on_sheet_at_the_documented_minimum_margin`
   proves every crop endpoint, swatch corner and page-info baseline is inside
   the MediaBox at exactly those minimums; `tight_trim_margins_are_rejected_with_a_typed_error`
   verifies a 24 pt bottom margin is rejected for page information with
   `required = 28` and `available = 24`. Registration marks remain centred on
   MediaBox corners and are documented as deliberately straddling the edge, so
   they are excluded from the fit check. Page information is now positioned
   from the TrimBox rather than the BleedBox, keeping it on-sheet.
3. **Precision floor.** `fmt_num` documents and enforces a `1.0e-4` floor:
   non-zero magnitudes below it (and `-0.0`) emit `0`.
   `PrinterMarkOptions::validate` rejects such option values so precision is
   never silently lost. `sub_precision_options_are_rejected` covers both
   `line_width` and a non-zero `mark_gap`. Output remains deterministic.
