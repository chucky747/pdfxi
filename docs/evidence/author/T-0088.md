## Notes

- New module `crates/pdfxi-accessibility/src/checker.rs`, re-exported from
  `crates/pdfxi-accessibility/src/lib.rs`; a small additive public helper
  `is_standard_pdf_role` was added to `crates/pdfxi-accessibility/src/structure.rs`
  so the checker can classify non-standard structure roles without duplicating
  the ISO 32000 role-name table.
- Twelve stable rules `UA-0001..UA-0012` cover title, language, tagged content,
  alt text, heading skips, list/table structure, form labels, reading order,
  empty links, unknown roles, and duplicate role-map entries. Findings carry
  severity, node/page context, and are sorted by
  `(rule, severity, page, node, message)`.
- `Summary::passed` is `errors == 0` and is explicitly documented as a
  heuristic approximation, not a PDF/UA certification claim.
- `suggest_fixups` is read-only and covers missing alt text, missing language,
  heading-level skips, and empty link text.
- All traversals use `A11yTree::traversal` (explicit stack); a 10,000-node deep
  chain is covered by `deep_tree_is_safe_and_iterative`. No unsafe code, no new
  dependencies, and no `unwrap`/`expect`/`panic` in non-test code.
- ACCESS-003 stays `in-progress`: the headless checker is complete, but no CLI
  subcommand, UI surface, or veraPDF cross-validation exists yet.
