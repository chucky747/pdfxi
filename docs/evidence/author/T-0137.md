## Scope / honesty note

EDIT-001 and EDIT-002 are implemented as library-level **models**. The paragraph
edit model produces a deterministic, ordered, idempotent `EditPlan` (steps +
reflowed lines) that a host writer can serialize; it deliberately does **not**
rewrite PDF content streams, and the text-style model likewise emits resolved
style data rather than operators. This matches the task's "model only" boundary.
Both rows are therefore reported `verified` at the library-model level; a host
adapter that serializes these plans into content streams is out of scope for
this task.
