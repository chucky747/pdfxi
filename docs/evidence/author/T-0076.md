## Security-reviewer fixes

1. `'` / `"` now apply their implicit `T*` before the rectangle overlap test;
   `quote_operator_is_removed_by_rectangle_at_its_rendered_line` and
   `double_quote_operator_is_removed_by_rectangle_at_its_rendered_line` prove it.
2. Verification now scans form streams referenced by each page (`form_pages`
   is tracked during recursion). `residual_inside_form_xobject_fails_strict_verification`
   proves a leftover form label fails strict mode through `check`, `verify_scan`,
   and a supplied extractor.
3. An inline image whose CTM-mapped unit square overlaps a rectangle is removed
   from the stream and recorded as `InlineImageRemoved`;
   `inline_image_overlapping_rectangle_is_removed_and_boxed` proves it while
   `inline_image_is_untouched` proves non-overlapping images are preserved.
4. `read_array` accepts whitespace/comments before `]`;
   `whitespace_before_array_close_is_accepted` covers `[(a) -50 (b) ] TJ`.
5. Text extents are transformed through `Tm` and the CTM, so `cm` scale and
   rotation are honored; `ctm_scale_and_rotation_are_honored_for_rectangle_text`
   covers both. Vertical extent remains the baseline only (no font metrics at
   this layer), which is documented in the module docs. A `Tf` operand-order bug
   uncovered by the scale test was fixed.
6. Cancellation is checked while collecting page/form text and inside the
   residual/occurrence loops; `cancellation_is_checked_during_verification`
   proves it.
7. Hostile-input regressions cover unterminated strings, arrays and images,
   stray delimiters, non-finite numbers, 64-deep nested arrays, comments and
   escaped names; all return typed errors or parse without panicking.

## Notes

- Implementation lives entirely in `crates/pdfxi-edit/src/redaction.rs` and is
  re-exported from `crates/pdfxi-edit/src/lib.rs`. The crate stays dependency-free:
  the T-0052 plan model is re-expressed locally rather than adding a cross-crate
  dependency (the workspace root `Cargo.toml` is integrator-owned).
- `apply` tokenizes content streams into byte-preserving operations and **drops**
  the `Tj`/`TJ`/`'`/`"` operators whose decoded text matches a `TextPattern` or
  whose CTM-transformed bounding box overlaps a `RedactionRect` — the content is
  removed, not merely covered. An opaque `0 0 0 rg … re f` box is appended for
  each rectangle. Form XObjects are followed with a bounded depth and cycle
  check; inline images are preserved unless they overlap a rectangle.
- Page dictionaries lose annotations/links whose `/Rect` intersects a rectangle
  or whose `/Contents`, `/T`, or link `/URI` matches a pattern, plus `/PieceInfo`
  and `/Metadata` when text redaction is requested.
- Verification reports typed `Residual`s and `RedactionReport::check` enforces
  strict mode. Copy-on-write inputs; no `unwrap`/`expect`/`panic` in non-test
  code, no unsafe, no new external deps.
- EDIT-013 stays `in-progress`: text content removal is proven here, but
  rasterised image removal requires the render lane's image extraction and there
  is still no UI/CLI exposure.
