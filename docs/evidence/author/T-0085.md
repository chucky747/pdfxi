## Reviewer findings addressed

1. **HIGH — page `/Rotate` removed from annotation placement.**
   `placement_matrix` no longer takes a page box or rotation and no longer calls
   `rotation_about_center` (that helper and `default_box_rect` were deleted).
   The emitted `cm` now maps appearance `/BBox` → annotation `/Rect` using only
   the appearance `/Matrix` and annotation `/Matrix`, all in default user space;
   the viewer applies `/Rotate` to the whole page. `/Rotate` is still validated
   as 0/90/180/270 for diagnostics. `PageBox` docs were corrected accordingly.
   Regression coverage: `rotation_and_matrix_are_folded_into_placement` (now
   asserts an identity `cm` under `/Rotate 90`; name retained because the merged
   feature row references it) and the new
   `page_rotate_does_not_change_placement_and_appearance_maps_into_rect`, which
   uses `/Rotate 90`, a known `/Rect` of `[100 200 300 320]`, and `/BBox`
   `[0 0 50 30]`, proves the emitted `cm` is identical to the `/Rotate 0` case,
   and transforms all four BBox corners into the rectangle. Both tests fail
   against the pre-fix code, which folded in a rotation about the page centre.
2. **MEDIUM — AcroForm gating made document-wide.**
   `flatten` now counts widgets on *all* pages (including pages outside the
   requested subset) and only removes `/AcroForm` when at least one widget
   existed, none survive, the run is not a dry run, and an AcroForm was present.
   New test `acroform_is_kept_when_an_untargeted_page_still_has_a_widget`
   flattens a widget on page 1 while page 2 keeps an untouched widget; the
   AcroForm and page 2's dictionary are unchanged. This test fails against the
   pre-fix `total_widget_flattened > 0` gating.
3. **LOW — emitted `Do` resources now expose their bytes.**
   New public `AppearanceResource { page, resource_name, appearance_key, content }`
   and `FlattenReport::unresolved_appearances()` list every emitted XObject with
   its key into `FlattenInput::appearances` and the exact stream bytes a writer
   must install. Re-exported from `lib.rs`. New test
   `report_lists_unresolved_appearance_resources_with_bytes` checks all fields.
4. **Evidence corrections.**
   `flatten.rs` had **16** tests before this pass (not 17); the earlier count of
   17 conflated the 16 flatten tests with the one new `redaction` test. This pass
   adds three tests, so `flatten::tests::*` now has **19** tests and the crate has
   **158** unit tests. The feature fragment `orchestration/feature-updates/T-0085.toml`
   is **not delivered by this pass**: it was consumed/merged by the integrator
   (the file no longer exists; EDIT-012 is present in `docs/features.toml`).
   The integrator-owned matrix was not edited.
