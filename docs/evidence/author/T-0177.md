## Scope delivered (library level, `crates/pdfxi-accessibility/**` only)

- `structure.rs`: writer now emits `/ActualText`, `/E`, `Alt`, and the `XI_ActualText` /
  `XI_Expansion` / `XI_Artifact` round-trip extensions; reader restores them.
- `structure.rs`: artifact nodes are excluded from `/StructElem` objects, `/K` kids,
  and `/ParentTree`; their marked-content sequences are emitted as
  `/Artifact << /MCID n >> BDC … EMC` in the page overlay (`PageTagInfo.artifact_mcids`).
- `structure.rs`: new deterministic object-level projection (`project_structure`,
  `StructureProjection`, `StructureEntry`, `StructEntryType`, `StructKid`) with
  byte-stable `to_canonical_bytes()` and `validate_consistency()` (no dangling
  parents, no cycles, no duplicate MCIDs, consistent `/StructTreeRoot` and
  `/ParentTree` references).
- `structure.rs`: typed semantic validation (`validate_structure_semantics`,
  `role_forbids_expansion`) rejects ActualText on a non-leaf, empty/blank
  ActualText, artifacts containing structure kids, expansions on forbidden
  roles, and duplicate MCIDs.
- `authoring.rs`: `export_reading_order` excludes artifact nodes/subtrees; the
  structure round-trip projection now covers alt, ActualText, and expansion.

15 new tests were added to `structure::tests` (116 total unit tests pass).

## Honest remaining scope

This task delivers the **library-level** tagged-structure projection only:

- It does **not** implement or claim a concrete PDF object writer in
  `pdfxi-core` (xref/object-stream emission, incremental save, byte offsets).
  The projection returns ordered dictionaries plus page overlays for a caller to
  serialize.
- It does **not** provide a UI tag tree / reading-order editor (an app-lane
  concern).
- Marked-content overlay bytes are additive: the host must merge them into each
  page content stream via `compose_page_content`.
- The canonical projection format is a stable intermediate for callers/tests; it
  is not a PDF file format.
