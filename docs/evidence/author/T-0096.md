- New module `crates/pdfxi-accessibility/src/editor.rs`: 22 tests covering
  insert/remove/move, reparent cycle rejection, role change, alt set/clear,
  actual-text/expansion, artifact marking, move-before/after, invalid moves,
  promote/demote, page-order normalization, coverage report, TH/TD table model,
  undo/redo round-trip, bounded journal, determinism, and duplicate-id rejection.

  `A11yNode::new` initializes them to `None`/`None`/`false`, preserving all
  existing constructor call sites and structure-tree round trips.
- No non-test `unwrap`/`expect`/`panic`/`todo`/`unimplemented`, no `unsafe`, and
  no new dependencies.
