## Scope note

Both features are delivered at the library-model level. `find_replace` searches
caller-supplied extracted text with literal-only matching (no regex, no pattern
engine) and emits a deterministic, non-overlapping, capped `ReplaceAllPlan`.
`image_edit` models placements and emits a deterministic `ImageEditPlan`. Neither
module reads, decodes, or writes PDF content streams or image data; host
serialization into content streams, image XObjects, and the UI remains future
work. No new dependencies were added.
