## Notes on an intermediate failure (fixed)

First build failed with `E0507: cannot move out of *stamp` because
`BatesDateStamp::format(self)` took its receiver by value while called through
`Option<&BatesDateStamp>`. Changed the getter to `format(&self)`.

First clippy run failed on `clippy::derivable_impls` for the manual `Default`
impl of `BatesPageSet`; replaced with `#[derive(Default)]` and `#[default]` on
the `All` variant. Both fixes are reflected in the green results above.

## Scope boundary

This is a library-model deliverable. `BatesPlan` is consumed by a host writer;
this crate does not paint stamps into content streams or mutate PDF bytes, and
there is no desktop UI/CLI exposure in this task. Determinism is guaranteed for
a given (config, page bounds, caller time) triple: stamps are sorted by page
index, deduplicated, and formatted with fixed integer/string arithmetic.
