## Bookmarks panel

`crates/pdfxi-app/src/shell/bookmarks_panel.rs` holds `BookmarksPanelState`
(`open`, `outline`, `issues`, `selected`, `draft_title`, `renaming`, `error`).
It renders as a collapsible **Bookmarks** group at the bottom of
`pages_panel_ui` (`side_panel.rs`) when `Capability::Bookmarks` is enabled and a
document is open.

Loading uses `pdfxi_edit::navigation::read_outline(&Document) -> OutlineRead` on
document open, tab activation (`on_active_tab_changed`) and every
`after_session_edit`. `outline` becomes the tree, `issues` supply destination-less
row tooltips, and a typed `OutlineReadError` becomes the section error with an
empty tree. A missing and an empty `/Outlines` both render "No bookmarks".

Rows flatten the tree in display order with one 12 pt indent per depth. A row
with a destination shows "Page N" and navigates by dispatching the same command
the thumbnail list dispatches, `AppCommand::SelectThumbnailPage(page)`, which
calls `PdfxiApp::select_thumbnail_page` (`DocumentTab::set_current_page`, scroll,
page box). The library `Destination::page` is a zero-based
`pdfxi_edit::geometry::PageIndex`, so the value is used unchanged.

A row with `destination: None` is weak-styled, non-navigating, and explains the
matching `OutlineIssue` reason by title (`MissingDestination`, `NonGoToAction`,
`UnresolvedNamedDestination`, `InvalidDestination`, `DanglingPageReference`) or
"no destination". It stays selectable so Rename/Delete can reach it; a strictly
disabled row would make those actions unreachable. Matching is by title because
`Bookmark` does not carry the item's `ObjectId`.

### Actions

Enabled only for an active writable tab:

- **Add bookmark** inserts a root bookmark at the current page with
  `Destination::new(PageIndex::new(current_page), FitType::Fit)` and title
  `Bookmark N` (N = root count + 1), selects it and starts inline rename.
- **Rename** edits the selected row inline; Enter while focused or Save commits,
  Cancel closes. Empty titles are rejected before touching the document.
- **Delete** removes the selected node and its children.
- **Move up** / **Move down** reorder among siblings with `move_bookmark`
  (`index - 1` / `index + 2`, accounting for same-parent removal) and are
  disabled at the first/last sibling. Nesting never changes.

### Persistence and failure

Each mutation clones the session `Document`, edits a cloned `Outline` with
`insert_bookmark` / `rename_bookmark` / `remove_bookmark` / `move_bookmark`,
calls `write_outline`, commits with
`session.edit(|document| { *document = candidate; Ok(()) })`, then
`after_session_edit(id)` - the `comments.rs::commit_annotation` pattern. The tab
is dirty and save/reopen preserves the tree. A `write_outline` or `SessionError`
sets `self.status = "Bookmarks: <error>"` and the panel error; the previous
outline is left untouched.

## Document properties

`AppCommand::DocumentProperties` (`label = "document-properties"`) opens the
**Document properties** window from `bookmarks_panel.rs`. The Tools row is gated
by `Capability::Documents` (the crate has no `Core`) and hidden while no
document is open.

Rows read only real session/document values: file name from the session path (or
`untitled`), page count (`Document::page_count`), file size (session byte
length), PDF version (`Document::version`), `/Info` Title/Author/Subject/
Keywords/Creator/Producer/CreationDate/ModDate (`Document::info`), encrypted
yes/no (session decryption report), XMP present yes/no (`xmp_metadata`). Absent
`/Info` values read **"not set"**; a failed metadata read reads "unavailable".
Dates show the stored raw `PdfDate` text. Nothing is invented or defaulted.

## Limits

- No drag-reorder, drag-to-nest, multi-select, cut/copy/paste or nesting change.
- Destinations are editable only as "current page + Fit" on add; existing
  bookmarks cannot be retargeted or change fit.
- Issue reasons match by title; duplicate titles can show the first issue.
- Destination-less rows are selectable (weak-styled), not strictly disabled.
- The properties dialog is read-only; `/Info`/XMP editing is T-0255A's write
  layer, and the section's expand state is not persisted.
- No capture is claimed; the reviewer/T-0262 captures the installed build.

## API notes

- `Destination::page` is a zero-based `PageIndex`, not a 1-based `NonZeroUsize`.
- `Bookmark::new` is fallible.
- The outline read/write items are public under `pdfxi_edit::navigation` only.
