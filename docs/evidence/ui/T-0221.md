# T-0221 Round A - home, library, recents, stars, identity, storage, help

Date: 2026-11-20. Lane: app. Status: review (Round A complete; shared folder and
notifications are Round B).

The local equivalents are real files, not a service: the library folder,
recents, stars, display name and storage total all live on this machine. No
account, server or network call is involved.

## Settings keys

| Key | Type | Default |
|---|---|---|
| `theme` | string (`light`/`dark`/`system`) | `system` |
| `window_controls` | string (`windows`/`macos`) | platform default |
| `display_name` | string | OS account name (`USERNAME`/`USER`/`LOGNAME`), fallback `Reader` |
| `library_root` | path string | `%USERPROFILE%\Documents\PDFXI` |
| `shared_folder` | path string or absent | none |

Paths are stored as strings, expand `~`, `%VAR%`, `$VAR` and `${VAR}` on load,
and relative paths are rejected. Old settings files without the new keys load
with defaults. `Settings` is now `Clone` rather than `Copy` because it carries
strings and paths; `with_overrides` borrows it.

## Storage locations

- `%APPDATA%\PDFXI\settings.toml` - theme, controls, display name, folder paths.
- `%APPDATA%\PDFXI\library.toml` - recent entries and starred paths.
- `%APPDATA%\PDFXI\shell.toml` - tools-panel open state (from T-0220).
- Default library: `%USERPROFILE%\Documents\PDFXI` (created on first refresh).
- macOS/Linux equivalents: the platform config directory (`$XDG_CONFIG_HOME` or
  `~/.config`, `~/Library/Application Support`) and `~/Documents/PDFXI`.
- The optional shared folder is a user-configured absolute path; there is no
  default and no network location.
