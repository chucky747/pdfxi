## Organize Pages

`crates/pdfxi-app/src/shell/organize_card.rs` holds `OrganizeUiState` and
`handle_organize_command`. `AppCommand::Organize` (`label = "organize"`) says
`Open a document to organize` without a document and otherwise opens the
**Organize Pages** window. While it is open, a thumbnail click toggles the page
in the selection (ctrl) or selects a range (shift); outside the card a click
navigates as before.

The card has Rotate left/right, Delete, Move up/down, Extract selected, Split
each page, and Combine Files. Every mutation clones the session `Document`,
builds a `pdfxi_core::pages::PagePlan` and applies it with
`apply_page_plan(&plan)`, parses the bytes back with `Document::from_bytes`,
commits through `session.edit(|document| { *document = candidate; Ok(()) })`,
then calls `after_session_edit(id)` - the `comments.rs::commit_annotation`
pattern:

- **Rotate** uses `PagePlan::rotate(RotationTarget::Indices(selection), -1/+1)`;
  left is counter-clockwise.
- **Delete** uses `PagePlan::extract` of the complement in original order.
- **Move up/down** uses `PagePlan::reorder` with the selected index swapped with
  its neighbour; moving the bottom page down is a no-op.
- **Extract selected** writes `<stem>-extract.pdf` and opens it; the source tab
  is untouched.
- **Split each page** uses `PagePlan::split` into one-page plans, writes
  `<stem>-page-N.pdf` beside the source, and reports the count.

## Combine Files

`AppCommand::CombineFiles` (`label = "combine-files"`) opens the **Combine
Files** window: **Add files** (rfd, PDF multi-select), a list with Remove, an
output path (default `combined.pdf`), and **Combine**.
`combine_to_path(sources, output)` reads each PDF into a `Document`, builds
`PagePlan::merge(documents[1..])`, applies it to the first document, writes the
bytes and opens the result, returning the page count. Fewer than two sources is a
typed error that writes nothing.

## Limits

- Drag reorder is a button-based move up/down; there is no pointer drag-and-drop
  between thumbnails.
- Insert blank page and add page from file are not exposed in this card (the
  existing Add Page command remains); the page plan has no blank-page operation.
- Rotate/extract/split write new files; undo covers the session edit but not the
  files already written.
- Split always writes one file per page; custom chunk sizes are not exposed.
- No multi-document combine preview, page-range selection for combine, or image
  sources in Combine Files.
- No capture is claimed; T-0262 captures the installed build.

## API notes

`PagePlan`, `PageOperation` and `RotationTarget` live in `pdfxi_core::pages` and
are re-exported by `pdfxi_edit`. `PagePlan::merge` takes the extra documents as
`Vec<Document>` and is applied to the primary document.
