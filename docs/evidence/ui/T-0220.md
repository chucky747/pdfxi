## Tests added (5)

- `ui::tests::capability_registry_gates_command_bar_commands` - capability gating
  of the command-bar feature commands.
- `ui::tests::tools_search_filters_enabled_rows_by_substring` - `"sign"` keeps
  Fill & Sign; `"zzz"` is empty; today's capabilities produce no rows.
- `ui::tests::page_number_box_validates_without_changing_the_page` - `"3"` moves
  to page 3; `"0"`, `"abc"` and `"13"` leave the page unchanged.
- `ui::tests::bottom_bar_zoom_choices_apply_through_dispatch` - Fit width and
  Actual size update the tab zoom through `AppCommand`.
- `ui::tests::tools_panel_state_round_trips_through_shell_settings` - drives
  `ToggleTools`, then reads the persisted `shell.toml`; the default is open.
