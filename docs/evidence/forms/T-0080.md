## Reviewer-requested fixes (T-0080 review round)

1. **MEDIUM — page index overflow.** `FieldSpec::validate` now rejects a page
   index whose one-based object number cannot be represented, returning the new
   typed `CreationError::PageOverflow(u32)`. The internal widget builder uses
   `page.checked_add(1)` and propagates the same typed error, so no debug panic
   or release wrap is possible. Regression:
   `build::tests::maximum_page_index_is_a_typed_error` asserts `u32::MAX` is a
   typed error from `validate`, `to_field`, `field_dictionary` and
   `widget_annotation`.
2. **LOW — derived rectangle edges.** `validate` now checks the computed
   `right()` and `top()` edges in addition to the raw components, so finite
   inputs whose sum overflows to infinity are rejected with
   `CreationError::NonFiniteRect` before `PdfValue::Number` emission. Regression:
   `build::tests::overflowing_rect_edges_are_rejected` uses
   `x = width = f32::MAX`.
3. **LOW — escaped trailing `$` in patterns.** Trailing-anchor detection is now
   escape-aware: a final `$` preceded by an odd number of backslashes is a
   literal, not an anchor. Regression:
   `rules::tests::escaped_trailing_dollar_is_a_literal` covers `x\$`, plain
   `x$`, and `x\\$` (escaped backslash followed by a real anchor).

## Corrected wording (scope honesty)

The earlier phrase "valid AcroForm dictionaries" overstated the emission model.
The crate now documents that it produces **well-formed dictionary models** in
`PdfValue`, not a complete PDF field tree or serialised objects:
- `/P` is a placeholder indirect reference derived from the zero-based page
  index; a host writer must substitute the real page object reference.
- A radio group is one merged field/widget node with `/Opt` options and one
  widget annotation, not one widget annotation per radio option; a host writer
  must attach per-option appearance states.
- Appearance streams are produced separately by `build_appearance`.

Both feature rows keep `status = "in-progress"` in the matrix. The matrix row
prose for FORMS-002/003 is integrator-owned (`docs/features.toml`), so it was
**not** edited by this lane; the integrator is requested to apply the same
"dictionary model / placeholder page reference / single radio widget" wording
when merging this evidence.
