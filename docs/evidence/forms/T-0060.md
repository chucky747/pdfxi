## Reviewer fixes applied

1. **AcroForm removal** — `flatten_document` now sets `acroform_removed` only
   when `document.has_acroform && flattened_widgets > 0`, not merely when the
   form is non-empty. Regression test
   `flatten::tests::flatten_keeps_acroform_when_no_widgets_were_flattened`
   supplies a non-empty form and pages with no widgets; it asserts the pages,
   content, annotations and form dictionary are all untouched (`changed() ==
   false`, `acroform_removed == false`), so widgets on other pages are not
   orphaned.
2. **Choice/radio value mapping** — removed literal "off"/"no"/"false"/"0"/
   empty inference. `is_declared_choice` now selects only values that are exact
   members of the field's declared choices/states (fields with no declared
   choices preserve values literally). Options named `No`, `Off`, `0`, `False`
   now round-trip; an undeclared `Off` radio value deselects. Tests:
   `xfdf_preserves_off_like_option_names`,
   `xfdf_ignores_radio_value_outside_declared_choices`.
3. **Namespace prefix validation** — `check_namespace` (root only) was replaced
   by `check_namespaces`/`validate_namespaces`, which walk every element and
   attribute: each qualified name must use `xml` or a prefix bound on that
   element or an ancestor to the XFDF namespace, and any `xmlns`/`xmlns:*`
   declaration must be empty or the XFDF namespace. Foreign-prefixed
   `f:field`/`f:name` are rejected as `UndeclaredPrefix` (or
   `UnexpectedNamespace` when bound to a foreign URI), while an explicitly
   resolved `f:` is accepted. Tests: `xfdf_rejects_foreign_prefixed_elements_and_attributes`
   plus the extended `xfdf_accepts_default_and_prefixed_namespaces`.
4. **`strip_slash` rustdoc** — now states that surrounding whitespace and *all*
   leading slashes are trimmed, matching `trim_start_matches('/')`; the
   `to_fdf` docs were aligned.
5. **Counts** — corrected in this document and in the restored
   `orchestration/feature-updates/T-0060.toml`: originally 16 XFDF + 17 flatten
   = 33 new; finally 19 XFDF + 18 flatten = 37 new; 122 total.

## Scope notes

- XFDF import is a model-level subset: field names/values, all five predefined
  entities, numeric character references, XFDF namespaces and nested field
  names are handled, but not XFDF `<annots>` or rich-text markup. Type mapping
  uses the target `Form`, required because XFDF has no field-type attribute.
- Flattening operates over a documented adapter model. Arbitrary `/Matrix`,
  `/Rotation`, and a concrete PDF writer belong to a host crate.
