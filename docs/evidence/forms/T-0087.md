## Reviewer fix — DocMDP `/P` mapping (ISO 32000-1 Table 254)

`CertPermission::bits()` now returns the exact standard values, with variant
names and rustdoc updated accordingly (the inaccurate "Acrobat convention"
comment was removed):

| Variant | `/P` | Meaning (Table 254) |
|---|---|---|
| `NoChanges` | 1 | No changes to the document are permitted |
| `FormAndSigning` | 2 | Form fill-in and signing are permitted |
| `AnnotationsAndSigning` | 3 | Form fill-in, signing and annotation changes are permitted |

The new test `signature::tests::cert_permission_maps_to_exact_iso_values` asserts
`1`, `2`, `3` for every variant and checks that each emitted `/TransformParams /P`
carries that exact integer. The DocMDP transform dictionary is produced by
`Certification::reference_array()` (`/TransformMethod /DocMDP`,
`/TransformParams { /Type /TransformParams, /P <n>, /V 1.2 }`).
