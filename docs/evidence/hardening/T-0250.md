# T-0250 - OpenCode connection spike and ADR 0011 confirmation

Date: 2026-11-20
Host: Windows, single user session, OpenCode Desktop running
Task: T-0250, lane `automation`
Evidence for: `docs/decisions/0011-ai-assistant-through-opencode.md`
No source code was changed. The deliverables are this evidence file, the
ADR 0011 amendment, and the feature-update fragment.

Secret handling: the service password and the MCP ticket were read in memory
only. This file contains no token, no password, no full `Authorization`
header, and no tunnel route. Redacted values are `<password>`, `<ticket>`,
`<route>`.

## 1. Result

ADR 0011 moves from `proposed` to `accepted` against OpenCode **2.3.2**.
Discovery, authentication, `/api/info`, provider and model listing, session
create, one prompt, message read, model switch, the event stream, the
client-MCP WebSocket attach, and the generic RPC route were all exercised.
Exactly one generation call was made, on `opencode-go/hy4-flash-free`, and it
returned `pong`.

Not exercised: the pairing flow, `tools/list` after the MCP handshake, tool
invocation, cancellation, and the permission round-trip. Section 12 lists each
one and why.

## 4. Authentication matrix

Header built as `Basic base64("opencode:" + password)`.

```text
GET /api/info
  no header                        -> 401
  Authorization: Bearer <password> -> 401
  Basic base64(":password")        -> 401
  Basic base64("opencode:password")-> 200
  x-opencode-password: <password>  -> 401
  password: <password>             -> 401
```

The service accepts HTTP Basic only, with the literal username `opencode`.
The password is the value in the registration file; it is not an API key and
must not be sent to any host other than the registered loopback endpoint.

## 10. Client MCP attach

`GET /api/experimental/client-mcp` is a WebSocket upgrade (`x-websocket:
true`); a plain GET returns `400` with the server log line
`RequestParseError: not an upgradeable ServerRequest`.

Token creation (browser path):

```text
POST /api/experimental/client-mcp/token?name=pdfxi-spike&location[directory]=<dir>
  without x-opencode-ticket header -> 403 (empty body)
  with    x-opencode-ticket: 1     -> 200
{"location":{"directory":"D:\\Documents\\opencode-work\\target\\tmp\\t0250-spike"},
 "data":{"ticket":"<ticket>","expires_in":60}}
```

Ticket length 36, single use, 60 s. The browser opens
`ws://.../api/experimental/client-mcp?name=pdfxi-spike&ticket=<ticket>`, which
cannot carry an `Authorization` header.

Native path, used by PDFXI:

```text
ws://127.0.0.1:28894/api/experimental/client-mcp?name=pdfxi-spike&location[directory]=<dir>
  Authorization: Basic <redacted>
  -> state Open
  <- {"method":"initialize","params":{"protocolVersion":"2025-11-25",
       "capabilities":{"elicitation":{"form":{},"url":{}},"roots":{}},
       "clientInfo":{"name":"opencode","version":"2.3.2"}},
      "jsonrpc":"2.0","id":0}
  -> {"jsonrpc":"2.0","id":0,"result":{"protocolVersion":"2025-11-25",
       "capabilities":{"tools":{"listChanged":false}},
       "serverInfo":{"name":"pdfxi-spike","version":"0.0.0"}}}
  <- {"jsonrpc":"2.0","method":"notifications/initialized"}
  (no tools/list within 5 s)
```

Basic auth alone is sufficient for a native WebSocket client; no ticket is
needed. This confirms client-MCP as the primary design.

## 11. RPC fallback

```text
POST /api/rpc/pdfxi_spike/probe
{"input":{}}

400  (empty body, no plugin implements this RPC)
```

`Rpc.Input` / `Rpc.Output` are `{input?}` / `{output?}` with any JSON value.
A plugin must be installed and configured to implement the RPC; the generic
route only dispatches to an existing handler. `/api/plugin` reported 98
plugins (94 builtin, 4 local) and none implemented `pdfxi_spike`.

## 13. Reproduction

```powershell
# 1. endpoint
& "$env:LOCALAPPDATA\Programs\ai.opencode.desktop\resources\opencode-cli.exe" service status

# 2. registration (do not print password)
$svc = Get-Content "$env:USERPROFILE\.local\state\opencode\service.json" -Raw | ConvertFrom-Json

# 3. auth header, in memory only
$b64 = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes("opencode:$($svc.password)"))
$h = @{ Authorization = "Basic $b64" }

# 4. read-only probes, always with a timeout
Invoke-WebRequest "$($svc.url)/api/info"  -Headers $h -TimeoutSec 3 -UseBasicParsing
Invoke-WebRequest "$($svc.url)/api/model" -Headers $h -TimeoutSec 10 -UseBasicParsing
```

Every request in this spike used `-TimeoutSec`; the service does not answer
unauthenticated requests, and a plain `Invoke-RestMethod` without a timeout
can hang on the 401 path.

## 14. Redaction check

- Password: never echoed. Length and equality only.
- `Authorization` header: never printed, not even truncated.
- MCP ticket: length and TTL only; the WebSocket URL is shown with
  `ticket=<ticket>`.
- Tunnel route: shown as `<route>`; the host suffix is genericized.
- Host name and user name in paths: `<host>`, `<user>`.
