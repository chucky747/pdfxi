## Coverage

- Request/response round-trip through the bridge (request JSON written to stdin,
  strict response JSON parsed back into `OcrPage`).
- Typed errors: spawn failure, non-zero exit with stderr, malformed JSON,
  version mismatch, oversized stdout, timeout, cancellation.
- Timeout and cancellation kill a hanging child and return promptly (250 ms
  timeout; 60 ms cancel delay; 5 ms watchdog poll).
- Unsupported language rejected before spawn via `LanguageRouter` strict
  routing; trait impl maps it to `OcrError::UnsupportedLanguage`.
- Arguments passed verbatim with `$(...)`, `;`, `&&`, `*` — no shell
  interpretation; validator rejects NUL/newline/overlong arguments.
- No ambient secret forwarded: pure allowlist filter test injects a secret and
  asserts it is dropped; process test confirms the child sees no ambient
  `PDFXI_TEST_SECRET` or `AWS_SECRET_ACCESS_KEY`.
- Fixed working-directory policy applied to the child.
- Public API documented; `cargo doc` clean with warnings denied.
