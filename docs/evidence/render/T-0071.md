## Review fixes

1. **MEDIUM — stdin deadlock.** The supervisor is now spawned before the stdin
   write, and the write runs in its own thread with the request bytes owned by
   that thread. A child that never drains stdin can no longer block the caller:
   the deadline/cancellation is already active and kills the child, after which
   the blocked write returns. Regression test
   `child_that_never_drains_stdin_still_times_out` uses a 256x256 grayscale
   image (131,072 hex characters, larger than the OS pipe buffer) and asserts a
   typed `Timeout` within 3 s.
2. **MEDIUM — feature fragment.** `orchestration/feature-updates/T-0071.toml`
   restored with the same in-progress CREATE-008 row and corrected
   evidence/tests.
3. **LOW — executable path.** Absolute path, existing regular file, no `..`/`.`
   components, no symlink at the leaf; bare names are never searched on `PATH`.
   `SidecarConfig::validate` re-checks everything. Working directories get a
   separate "existing directory" validation.
4. **LOW — child reaping / pipe errors.** `capture_bounded` sets the abort flag
   on read errors as well as overflow; the caller collects all pipe results,
   joins the supervisor (which kills and reaps on abort/timeout/cancel) and the
   stdin writer before returning. A non-fatal `BrokenPipe` from a child that
   closes stdin early is tolerated so a non-zero exit is reported correctly.
   Regression test `early_nonzero_exit_with_partial_response_is_typed`.
5. **LOW — JSON surrogate pairs.** The strict codec now combines a `\uD83D\uDE00`
   high/low pair into one scalar and rejects lone surrogates or malformed pairs.
   Test `sidecar_json_accepts_surrogate_pairs_and_rejects_lone_surrogates`.
