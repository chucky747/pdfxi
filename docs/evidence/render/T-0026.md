## Contracts

- `SearchIndex::find` returns matches ordered by page, then character offset;
  the overlap policy is leftmost-first and non-overlapping.
- Case folding is ASCII-only; non-ASCII passes through unchanged and this is
  documented on `fold_char`.
- The pre-existing single-page `search()` keeps its byte-offset contract; the new
  APIs use character offsets.
- Copy rules: newline between baselines, space between same-line runs.
