# T-0049 — Print raster pipeline

Status: verified (task); VIEW-001 stays in-progress because the platform printer
adapter is not implemented.

## Files

- `crates/pdfxi-render/src/print.rs` — `PrintSettings` (page selection, copies,
  scale mode, orientation, duplex, paper, margins), `PrintJob`/spooling through
  `&dyn Renderer` into ordered `PrintPage` rasters, page-range parsing
  (`"1-3,5,7-"`, 1-based, duplicate suppression), and `SpoolSummary`.
- `crates/pdfxi-render/src/lib.rs` — module wiring.

Coverage: range parsing with open ranges and duplicates, fit/actual/percent
scaling, orientation and margin math, copy expansion, cancellation before and
between pages, out-of-range rejection, empty selection, summary stability, and
deterministic page order.

## Notes

This produces rasters and job metadata only; handing pages to a Windows printer
is a later adapter. The matrix has no dedicated print-raster row, so the
fragment updates VIEW-001 (in-progress) and documents the gap.
