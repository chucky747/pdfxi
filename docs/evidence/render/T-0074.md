## Coverage

- Simple Type1 `/FirstChar` + `/Widths` lookup and text-space scaling.
- TrueType width indexing from `/FirstChar`, including first/last boundaries.
- Type0 `/W` CID-list and CID-range forms plus `/DW` fallback.
- `Identity-H` CID advances and a custom `/FontMatrix` horizontal scale.
- `/ToUnicode` `bfchar` and both `bfrange` forms (sequential and array),
  including non-BMP destinations (`<D83DDE00>` → U+1F600 😀) across surrogate
  pairs, sequential low-surrogate increment, and a typed rejection of unpaired
  surrogates in both `bfchar` and `bfrange`.
- `/MissingWidth` fallback for out-of-table codes.
- Embedded-font flag gating of standard-14 fallback.
- `/CIDToGIDMap` identity and explicit big-endian streams.
- Malformed width tables, negative `/DW`, unterminated CMap hex, and a missing
  `/FirstChar` all produce typed errors without panicking.
- Documented standard-14 fallback for non-embedded base fonts (with subset
  prefix stripping), AFM vertical metrics and bounding boxes.
- Public API documented; `cargo doc` clean with warnings denied.
