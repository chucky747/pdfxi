## Contracts

- Rendering is RGBA, tightly packed, with explicit scale (1.0 = 72 DPI),
  progress, and cancellation.
- Text extraction returns spans with byte offsets and a deterministic search
  helper; offsets are stable for the same input.
- PDFium is not a dependency yet. The next render task implements the backend
  behind the trait.
