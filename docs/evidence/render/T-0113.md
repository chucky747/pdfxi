## Honest scope boundary

All three modules produce deterministic, validated *plans* only. Actual trap
painting/transparency flattening (PRINT-006), folder watching and preflight
execution (PRINT-008), and pixel compositing (STD-005) are delegated to native
or host backends and are explicitly flagged in each plan via
`needs_backend_prepress`/`needs_backend_cmm`/`needs_backend_alpha` plus warnings.
The three feature rows therefore stay `in-progress` rather than `verified`.
