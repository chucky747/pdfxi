## Summary of implementation

- New `crates/pdfxi-render/src/export.rs` (pure Rust, no new dependencies,
  `#![forbid(unsafe_code)]`, no `unwrap`/`expect`/`panic` in library code).
- `ImageFormat::{Png, Jpeg, Tiff}`, `ColorMode::{Grayscale, Rgb, Rgba}`,
  `AlphaPolicy::{Preserve, Flatten}`, `FitMode::{Actual, Scale, FitWithin}`,
  `ExportOptions`, `ExportError`, `ExportedImage`, `encode_image`,
  `export_pages`, and `MAX_EXPORT_DPI`/`DEFAULT_EXPORT_DPI`.
- DPI 1..=12000 validated; DPI→scale = `dpi / 72`, reusing the existing
  `print::PrintSpooler` for page ranges, fit-to-box, progress, and cancellation.
- PNG: deterministic stored-deflate stream, IHDR colour types 0/2/6, `pHYs`
  DPI metadata, CRC-32 per chunk.
- JPEG: baseline 4:4:4, documented Annex K quantization/Huffman tables, IJG
  quality scaling, JFIF density, 2-byte SOF0 dimensions, byte stuffing.
- TIFF: little-endian, uncompressed, multi-page IFD chain, `ExtraSamples` for
  RGBA, `XResolution`/`YResolution` rationals; one file for all pages.
- 15 new unit tests + 1 PDFium-gated integration smoke test.
- Two bugs were found and fixed by these tests: a TIFF header first-IFD pointer
  aimed at pixel data, and a JPEG SOF0 that wrote 4-byte instead of 2-byte
  dimensions.
