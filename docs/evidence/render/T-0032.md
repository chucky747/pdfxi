# T-0032 — Page thumbnails

Status: verified (task); VIEW-007 stays in-progress until the navigation-pane UI
consumes the engine.

## Files

- `crates/pdfxi-render/src/thumbnail.rs` — `ThumbnailSpec` (contain fit),
  nearest-neighbor `resize_rgba`, `Thumbnail`, `ThumbnailGenerator`, and an LRU
  `ThumbnailCache`.
- `crates/pdfxi-render/src/lib.rs` — module registration.
- `crates/pdfxi-render/tests/thumbnail_pdfium.rs` — PDFium-backed integration
  tests.

## Verification

```text
$ . .\scripts\env.ps1 -Lane render
$ cargo test -p pdfxi-render --features pdfium
... 2 thumbnail integration tests passed; 0 failed
$ cargo test -p pdfxi-render
all unit tests passed
$ cargo clippy -p pdfxi-render --all-targets --features pdfium -- -D warnings
clean
```

Generation is a deterministic cover-and-downscale strategy: render at scale 1.0
to measure, render again at a scale that covers the box, then downscale with
nearest-neighbor sampling. Cancellation is checked before, between, and inside
both phases. Cache keys are `(page, spec)` with documented LRU eviction.
