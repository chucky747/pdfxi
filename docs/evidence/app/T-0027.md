# T-0027 — Canvas layout, hit testing, and text selection

Status: verified (task); VIEW-002 and VIEW-003 stay in-progress until real raster
integration lands.

## Files

- `crates/pdfxi-app/src/canvas.rs` — `PageGeometry`, `CanvasLayout` for
  single/continuous/two-page/two-page-continuous modes, `CanvasHit`/`page_at`,
  `page_point`, scroll clamping, fit resolution.
- `crates/pdfxi-app/src/selection.rs` — `SelectableTextPage` trait,
  `SelectionModel` with two-way drag normalization and Unicode-safe cross-page
  copy, `OwnedTextPage` for tests.
- `crates/pdfxi-app/src/ui.rs` — canvas draws page rectangles from the layout,
  reports the page under the cursor, shows selection text, and clears on Escape.

The crate stays dependency-light: `selection.rs` defines a local
`SelectableTextPage` trait instead of depending on `pdfxi-text`; consumers can
implement it for `pdfxi_text::TextPage`.
