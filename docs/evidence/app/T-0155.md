## Honest scope / boundary

- All three modules are **model + plan only**. There is no `egui` widget, no
  embedded-file extraction, no filesystem walk, and no network code. The host
  owns rendering the tree, invoking/applying manage plans, enumerating the
  shared folder, and extracting embedded-file bytes.
- MANAGE-006 follows ADR 0008: it is a local, file-based stand-in for a
  SharePoint-style library. UNC/URI roots are explicitly rejected.
- Non-test code uses no `unwrap`, `expect`, `panic!`, `todo!`, `unimplemented!`,
  or `unsafe`. The crate denies `missing_docs` and forbids `unsafe_code`.
- Feature rows are reported as `in-progress`: the model-level scope is complete
  and tested, but the user-facing UI/host-integration boundary remains, so the
  rows are not overstated as `verified`.
