# T-0111 evidence — app lane

Task: `T-0111` — home/recents/favorites, cross-file search, version compare.
Lane: `app`. Target dir: `target/lanes/app` (via `. .\scripts\env.ps1 -Lane app`).

## Scope note (honest deviation)

The task text named `crates/pdfxi-app/**` **and** `crates/pdfxi-text/**` as the
editable area. The app lane's edit permissions (`.opencode/agents/lane-app.md`)
allow only `crates/pdfxi-app/**`, `docs/evidence/app/**`, and
`orchestration/feature-updates/**`; a `write` to `crates/pdfxi-text/**` was
rejected with `Permission denied: edit`. Rather than circumvent the permission
system, all three features were implemented inside `crates/pdfxi-app/**` using
self-contained, dependency-free page-text types (`PageText`). No dependency was
added and `Cargo.toml`/`Cargo.lock` were not modified. `pdfxi-text` is still
built and tested by the acceptance command and remains untouched.
