## Scope and host boundary

- open.rs is window-free: DocumentOpenPipeline checks cancellation before and
  after load, records OpenResult per TabId, records metadata (page count, title,
  encryption state) in a plain OpenedDocument, and maintains a bounded,
  most-recent-first RecentFiles list. Failures are typed OpenErrors.
  MockDocumentOpener is deterministic and used by default; PdfiumDocumentOpener
  (feature pdfium) validates with real PDFium and reads metadata through
  PdfiumRenderer::document_meta added to pdfxi-render.
- print.rs models all/current/selection/custom page ranges, copies,
  orientation, fit/actual/custom scale, duplex, and named/custom paper. It
  validates with typed PrintModelErrors and resolves a deterministic PrintPlan
  through pdfxi_render::print::PrintJob.
- ui.rs (feature ui) adds a Print dialog and open-error window driven by
  window-free helpers. Submitting a plan contacts no printer.
- Host boundary: this task produces rasters/plan data only. A platform printer
  adapter that sends pdfxi-render::print rasters to a driver is still future
  work, so VIEW-001 remains in-progress.
