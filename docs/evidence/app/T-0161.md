## Honest scope / host boundary

- Both modules are **model + plan only**. No `egui` widget, renderer, font
  rasterizer, OS speech call, or filesystem access is present.
- `reflow`: the host draws wrapped lines, drives scroll/page events, and
  forwards the existing `SpeechRequest`s to a `SpeechSink`. Rendered column
  fidelity against a real font engine is not measured here. Read-aloud chunking
  is reused from `crate::read_aloud::build_chunks` rather than duplicated.
- `compare_view`: the host renders the row plan, colors markers, and translates
  scroll events through `ScrollSync`. This complements (does not replace) the
  existing page-level `compare` module.
- Geometry uses integer hundredths of a point (`FontMetric`, `ReflowLine`
  edges) and scroll sync uses global flat line indices, so output is fully
  deterministic and multi-page safe.
- Non-test code uses no `unwrap`, `expect`, `panic!`, `todo!`,
  `unimplemented!`, or `unsafe`. The crate denies `missing_docs` and forbids
  `unsafe_code`.
- Feature rows are reported as `in-progress`: model-level scope is complete and
  tested, but the user-facing UI/host-integration boundary remains, so the rows
  are not overstated as `verified` (consistent with the sibling VIEW-014 row).
