## Notes / host boundary

Every planner returns a fully resolved, deterministic plan (page order,
destination cells, transforms, production marks) with typed `ImposeError`
validation for invalid counts, non-finite geometry, and unsupported options.
Nothing in this module opens, contacts, or drives an OS printer. Executing a
plan — painting rasters, marks and bleed, feeding trays, flipping duplex sheets,
and validating ICC profiles with a real CMM — remains the explicit host print
backend boundary. The rows are therefore `verified` at the model level only.
