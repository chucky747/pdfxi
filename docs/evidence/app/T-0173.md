## Code changes (all inside `crates/pdfxi-app/**`)

- `src/presentation.rs`: `PresentationModel::from_slides` now re-validates every
  slide duration (finite and non-negative) with a typed
  `PresentationError::InvalidDuration(page, duration)`. `Slide` has public
  fields, so a host can bypass `Slide::new` with a struct literal; a `NaN`
  duration previously made the `tick` comparisons always false and corrupted the
  deterministic remainder carry. Added 5 tests: bypass validation, chunked vs
  single-tick determinism and `TIME_EPSILON` boundary, manual navigation while
  playing, exit from `Finished`/repeated exit, and width-limited fit layout.
- `src/portfolio.rs`: `PortfolioPath::validate_component` now rejects an embedded
  `/` (`PortfolioPathError::InvalidCharacter`). Folder paths are split on `/`
  before component validation, so this closes the case where a slashed entry
  *name* produced the same display path as a genuinely nested file and fooled
  duplicate detection. Added 5 tests: slashed-name alias rejection, direct
  component/`join` slash validation, triple-duplicate reporting, duplicate after
  a rejected first entry, and depth/length boundaries.
- `src/loupe.rs`: added `LoupeModel::reset_accumulated_drag()` so a host can start
  a fresh gesture sequence instead of letting the bounded drag total saturate for
  the session; panning/zoom state is unchanged. Added 4 tests: accumulator reset,
  half-open rectangle / closed-radius circle hit-test boundaries,
  `screen_to_page` corner inversion, and scroll-vs-drag accumulator distinction.
