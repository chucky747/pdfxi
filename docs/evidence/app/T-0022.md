# T-0022 — egui viewer shell behind the `ui` feature

Status: verified (task); VIEW-002 and VIEW-005 remain in-progress until the
canvas arranges real rendered pages and dock widgets land.

## Files

- `crates/pdfxi-app/Cargo.toml` — optional `ui` feature, optional `eframe` /
  `egui` 0.33 dependencies, `pdfxi-ui` binary with `required-features`.
- `crates/pdfxi-app/src/ui.rs` — `run()`, `PdfxiApp` (`eframe::App`), toolbar,
  tab strip, status header, placeholder canvas, keyboard chords.
- `crates/pdfxi-app/src/bin/pdfxi-ui.rs` — thin binary entry point.

## Verification


The default build keeps `default = []` and stays dependency-light. eframe/egui
were added as optional dependencies, which is why `Cargo.lock` grew.

## Limits

The canvas is a placeholder that reports page count and the active page. The
real page raster comes from the PDFium backend (T-0021) and the page-arrangement
layer.
