## What was delivered

- `crates/pdfxi-app/src/nav.rs` (ACCESS-004): focus order with wrap and
  disabled skipping, navigation shortcut map and stable labels, WCAG contrast
  tokens/themes with audited pairs, and reflow metrics.
- `crates/pdfxi-app/src/read_aloud.rs` (ACCESS-005): sentence/word chunking with
  page breaks, voice settings, and a deterministic play/pause/step state
  machine behind a `SpeechSink` host boundary; no OS speech calls.
- `crates/pdfxi-app/src/a11y.rs` (ACCESS-006): accessibility role/node tree from
  app state, focus announcements, host trait, and a `ui`-gated AccessKit bridge
  registered with egui via `egui::accesskit` (no new dependency).

## Notes
