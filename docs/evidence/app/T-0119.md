## Change under test

`crates/pdfxi-app/src/layers.rs`:

- `LayerState::new` normalizes hostile `/OCProperties` summaries so no radio
  group ever shows two members. Winner: first declared locked-and-visible
  member, else first declared visible member, else first declared member; all
  other members are hidden. Declaration order uses `LayerModel::position`.
- `show_all` gives priority to a currently visible locked member. That member
  owns its group; no unlocked member is enabled alongside it. Otherwise the
  first unlocked member in display order is shown.
- `set_visible` refuses to enable a second member while a locked member of the
  same group is visible. The member stays hidden and the effective value
  `false` is returned (documented in rustdoc).

Three negative tests were added. Each fails without the fix: with the old
code, construction left three members visible, `show_all` enabled `b`, and
`set_visible("b", true)` enabled the second member.
