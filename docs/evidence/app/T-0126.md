## What was delivered

`crates/pdfxi-app/src/split.rs` (new):
- `PanePoint`/`PaneRect` geometry, `DividerAxis`, `Divider`, `SplitDirection`.
- `SplitLayout` horizontal/vertical with ratio clamping and minimum pane sizes,
  `SplitGeometry` that tiles the viewport with a divider.
- `TileGrid` (rows × columns) with row-major deterministic pane rects.
- `PaneViewState` per-pane scroll/zoom/page with clamping, mirror-tab sharing of
  view state across panes on the same tab, per-tab isolation, focus next/previous
  with wrap, close-pane promotion, tab-close cleanup, and typed `SplitError`.
- `ui`-gated split/tile commands and shortcut map.

## Tests

17 new `split::tests::*` cases cover geometry tiling, extreme-ratio clamping,
small viewports, invalid ratios/grids, 1×2 / 2×1 / 2×2 grids, per-pane
isolation, mirror sharing, per-tab isolation, focus wrap, scroll/page clamping,
close promotion, tab-close cleanup, empty tab sets, determinism, tile rebinding,
and shortcut stability.
