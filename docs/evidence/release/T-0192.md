# T-0192 — R3 portable package and user-scope install

Date: 2026-11-20. Lane: integrator. Target dir: `target/integration`.

## Delivered

- `scripts/package.ps1` now stages and hashes **both** binaries:
  `pdfxi.exe` (CLI) and `pdfxi-ui.exe` (desktop viewer, `ui,pdfium`). The
  allowlist, source map, build step, `-SkipBuild` requirement, `-Check` output
  and the self-test stub were extended together, so layout/notice/secret
  validation covers the GUI binary too.
- `scripts/install.ps1` installs both binaries from an explicit allowlist and
  creates user-scope shortcuts without elevation or registry writes:
  `PDFXI.lnk` -> `pdfxi-ui.exe`, `PDFXI CLI.lnk` -> `pdfxi.exe`, plus an
  optional `-DesktopShortcut` switch for a Desktop link.
