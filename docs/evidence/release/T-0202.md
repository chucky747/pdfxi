## R2 - one manifest, fetch pinning, packaging

R2.1: the second manifest came from winlibs GCC's link spec
`%{!shared:%:if-exists(default-manifest.o%s)}`, whose
`x86_64-w64-mingw32\lib\default-manifest.o` declares only `longPathAware` and
`asInvoker`. `build.rs` now compiles a manifest-free COFF object to
`OUT_DIR\default-manifest-shim\default-manifest.o` and links with `-B<dir>/` so
the spec finds the shim first.

### R4.3 Fixes found by the smoke

1. `package.ps1`/`New-Installer` did not pass the `.iss` script path to ISCC and
