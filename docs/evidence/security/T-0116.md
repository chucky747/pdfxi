## Honest scope / limitations

- **SEC-008**: applies to classic-cross-reference, unencrypted PDFs. Xref-stream,
  linearized, and encrypted inputs are rejected with a typed
  `UnsupportedDocumentStructure`/`SanitizationCoreFailed` error. Detached
  objects (annotations, embedded-file/JS streams, XMP) are nulled rather than
  renumbered away; their content bytes are gone, but empty placeholder objects
  remain. Verification is structural on the re-parsed output bytes.
- **SEC-010**: local, tamper-evident file envelope — integrity plus a declarative
  recipient/permission description. Payload is stored verbatim (no
  confidentiality). No Adobe server / Rights Management format, no network, no
  host clock.
- **SEC-011**: purely local, offline policy model. No rights-management server,
  no network, no cryptography. Time is caller-supplied; enforcement is a local
  reader decision.
- All three rows remain `in-progress` at the library boundary: no host UI/CLI
  exposure, and reviewer sign-off / integrator snapshot are external steps.
