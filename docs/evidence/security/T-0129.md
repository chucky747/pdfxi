## Honest scope limits

- SEC-003 is a clean-room *model*: the content cipher uses the existing AES-CBC
  and SHA-256 primitives; key wrapping is delegated to the caller's
  `KeyWrapProvider`. The bundled `InMemoryKeyWrapProvider` is a documented XOR
  test double, not production RSA/ECDH. No `/Encrypt` dictionary integration, no
  real private keys, and no UI/CLI.
- SEC-007 never fetches CRLs or reads the host clock: callers supply every CRL
  and a pinned evaluation time. CRL signature verification, distribution-point
  fetching, trust-manager UI, and wiring into the signature workflow are out of
  scope for this task.
- No Adobe proprietary handlers were reused; no secrets or document contents
  are logged and `Debug` redacts byte fields.
- Reviewer sign-off and integrator snapshot are external orchestration steps.
