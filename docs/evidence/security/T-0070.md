## Files

- `crates/pdfxi-security/src/x509/mod.rs` — signature-algorithm OIDs, `Clock` /
  `FixedClock`, `AlgorithmIdentifier`, critical-extension policy.
- `crates/pdfxi-security/src/x509/name.rs` — RDN/AVA parsing, deterministic RFC
  4514 display with escaping (UTF-8 octet hex form for control characters).
- `crates/pdfxi-security/src/x509/extension.rs` — basic constraints, key usage,
  SAN, EKU, unknown extensions, duplicate-OID rejection.
- `crates/pdfxi-security/src/x509/certificate.rs` — DER `Certificate`/TBS,
  validity with inclusive boundaries, SPKI, extension accessors, SHA-256
  fingerprint, duplicate optional-field rejection, redacting `Debug`.
- `crates/pdfxi-security/src/x509/verify.rs` — `TrustStore`,
  `ValidationPolicy`, `CertificateVerifier`, backtracking `build_path` with
  signature-first candidate selection, chain-wide EKU intersection, issuer
  signature-algorithm guard, and all CA/KU/path-length/time/critical checks.
- `crates/pdfxi-security/src/x509/digital_id.rs` — `KeyHandle`,
  `OpaqueKeyHandle`, `DigitalId`, metadata-only export/import,
  `DigitalIdStore` with duplicate detection and lookups. No private-key bytes
  are stored.
- `crates/pdfxi-security/src/der.rs`, `error.rs`, `lib.rs` — BOOLEAN/BIT STRING
  and implicit OID support, typed errors (including duplicate-field variants),
  module wiring and re-exports.

## Reviewer findings addressed

1. **MEDIUM — same-subject decoys aborted path building.** Path construction is
   now a recursive, backtracking search. Signature verification runs before any
   local constraint; a candidate that fails CA/KU/critical/time/EKU/path-length
   checks, or that leads to a dead end, is skipped in favour of the next
   same-subject candidate. Tests: `verify_chain_skips_decoy_candidate_and_uses_valid_issuer`,
   `verify_chain_accepts_cross_signed_path`.
2. **MEDIUM — EKU enforced only on the leaf.** `check_eku_intersection` is applied
   to every certificate in the path (leaf, intermediates, anchors) when a
   required purpose is configured. Test: `verify_chain_intersects_eku_constraints_from_cas`.
3. **LOW — unsupported signature algorithm only checked on the leaf.**
   `check_signature_algorithm` now runs for every certificate in the path and
   for every issuer candidate. Test: `verify_chain_rejects_issuer_with_unsupported_signature_algorithm`.
4. **LOW — duplicate fields accepted.** Repeated `[1]`/`[2]`/`[3]` TBS fields
   and duplicate extension OIDs now return `CertificateDuplicateField` and
   `CertificateDuplicateExtension`. Tests: `parse_certificate_rejects_duplicate_optional_tbs_fields`,
   `parse_certificate_rejects_duplicate_extension_oids`.
5. **LOW — RFC 4514 control escaping.** Control characters are escaped per UTF-8
   octet, e.g. U+0085 becomes `\C2\85`. Test: `name_display_hex_escapes_utf8_bytes`.
6. **LOW — evidence count.** Counts corrected from 20/21 and 127 to 28 new tests
   and 134 total, with the full test list above.
