  supplied TSA token model (imprint/nonce/validity/policy, deterministic report)
  and detached-signature verification wiring against a supplied certificate.
  All 9 module tests pass. No network, no wall clock, no hidden trust store.
- No `unsafe`, `unwrap`, `expect`, `panic!`, `todo!`, or `unimplemented!` in the
  new non-test code; all new public items are rustdoc'd under `#![deny(missing_docs)]`.
