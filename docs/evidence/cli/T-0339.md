# T-0339 — Deployment-preferences host (`PLAT-006`)

Row promoted: `PLAT-006` (Deployment preferences and customization) `model` ->
`verified`.

`pdfxi_core::preferences` already modelled the validated deployment document
(base preferences, toggles, allowed paths, update channel) with deterministic
serialization and merge. Its notes recorded a host boundary: "no installer and
no registry policy application." This task adds the deployment-tool host the
model describes: `pdfxi policy`.

## 1. Host

```text
pdfxi policy show <FILE> [--json]
pdfxi policy write --out FILE [--theme system|light|dark] [--locale TAG]
    [--recent-count N] [--show-toolbar true|false] [--zoom PCT] [--autosave SECS]
    [--channel stable|beta|nightly|off] [--toggle NAME=true|false ...]
    [--allow-path PATH ...] [--json]
pdfxi policy merge BASE OVERLAY [--out FILE] [--json]
pdfxi policy check FILE [--theme T] [--channel C] [--toggle NAME ...]
    [--path PATH ...] [--json]
pdfxi policy preferences <FILE> [--json]
```

- `write` validates through `Preferences::new`, `DeploymentPreferences::new`
  (toggle names, rooted allowed paths) and writes the sorted `key=value`
  document.
- `show` parses it back and reports every field, including the raw document.
- `merge` applies `DeploymentPreferences::merge` (overlay base/channel win,
  toggles union with overlay precedence, paths union/sort/dedupe).
- `check` enforces the policy on requested settings: theme must equal the
  deployment theme, channel must equal, named toggles must be enabled, and each
  path must be inside an allowed prefix. Failures are listed and exit non-zero
  (also in JSON mode).
- `preferences` parses a plain runtime preferences document.

Malformed input:

```text
> policy write --toggle telemetry=yes
Error: toggle "telemetry" has invalid boolean "yes"; use true or false

> policy write --allow-path relative/dir
Error: deployment preferences: invalid allowed path: relative/dir

> policy show bad.txt            (missing required base keys)
Error: parse policy ...: missing preferences key: ...

> policy show unknown.txt        (extra key)
Error: parse policy ...: unknown preferences key: surprise
```

## Scope

The host reads, writes, merges and enforces the validated document. It does not
touch the registry, an MSI transform, group policy, the GUI settings store or an
installer, and `check` reports policy mismatches only (it does not apply or
repair values).
