# T-0340 — Shell association host (`PLAT-005`)

Row promoted: `PLAT-005` (Shell integration and file associations) `model` ->
`verified`.

`pdfxi_core::association` owned the validated descriptor model and its
deterministic export, with a recorded boundary: "no registry writes and no
process spawning; the dry-run plan is applied by the host installer." This task
adds that host: `pdfxi shell`.

## 1. Host

```text
pdfxi shell plan [--exe PATH] [--json]
pdfxi shell register [--root KEY] [--exe PATH] [--json]
pdfxi shell status [--root KEY] [--exe PATH] [--json]
pdfxi shell unregister [--root KEY] [--exe PATH] [--json]
```

The descriptor registry is built from the model: `.pdf` -> `PDFXI.pdf` with the
command template `"<exe>" "%1"`, and `pdfxi` -> `PDFXI.protocol` with the same
template. `plan` prints `export_descriptors`.

`register` writes, with `reg.exe`:

```text
<root>\.pdf                           (Default) = PDFXI.pdf
<root>\PDFXI.pdf                      (Default) = PDF document
<root>\PDFXI.pdf\shell\open\command   (Default) = "<exe>" "%1"
<root>\pdfxi                          (Default) = URL:PDFXI Protocol
<root>\pdfxi                          URL Protocol = ""
<root>\pdfxi\shell\open\command       (Default) = "<exe>" "%1"
```

`status` reads those defaults and reports `association_installed`,
`association_command_installed` and `protocol_installed`. `unregister` removes
the ProgID and protocol keys and clears `.pdf` only when it still points at
`PDFXI.pdf`. Safety:

- the root must start with `HKCU\Software\` (HKLM is refused);
- the executable must exist (default: the running binary);
- the root must not contain quotes.

sandbox root that was removed afterwards.

## Scope

Per-user registry installation only, and only under an `HKCU\Software\` root.
No HKLM/machine-wide install, MSI, default-app UI automation (`SHChangeNotify`),
icon/thumbnail handlers, or process spawning for the handler. `unregister`
does not restore a previous association beyond clearing a `.pdf` default that
still names `PDFXI.pdf`.
