# T-0288 — `pdfxi api`: local JSON request/response host (AUTO-006)

Row promoted: `AUTO-006` (Local JSON API for automation) `model` -> `verified`.

The host already existed in the CLI; the row had never been evidenced or
promoted. This task runs it against real bytes, records the output, and pins the
protocol with the existing unit and integration tests.

## Protocol

One request line in, one canonical response line out, both over stdio:

```json
{"version":1,"id":"...","command":"<name>","params":{...}}
{"error":null|{code,message},"id":"...","ok":bool,"result":...,"version":1}
```

`--once` answers exactly one line and exits; without it every non-blank line is
answered in order and the process stays alive across errors. Commands:
`version`, `commands`, `list-actions`, `show-action`, `dry-run`, `run-batch`,
`list-toolsets`, `show-toolset`, `validate-toolset`, `run-toolset`. Runs are the
documented staging path (`DocumentExecutor`), so a batch reports what it *would*
write and writes nothing.

`run-batch` over the real fixture (119,341 bytes), staged:

```json
{"error":null,"id":"b","ok":true,"result":{"action":"nightly","run":{"action":"nightly","jobs":[{"id":"job-0","input":"D:\\Documents\\opencode-work\\fixtures\\realworld\\powerpoint-slides.pdf","outcome":{"completed_steps":["load","save"],"failed_step":null,"message":null,"state":"succeeded","steps":[{"artifact":"bytes(119341)","artifact_kind":"bytes","kind":"import","message":"staged powerpoint-slides.pdf (119341 bytes)","step_id":"load"},{"artifact":"out.pdf","artifact_kind":"path","kind":"export","message":"export staged to 'out.pdf' (no write)","step_id":"save"}],"summary":"succeeded steps=2"},"state":"succeeded"}]}},"version":1}
```

Errors are typed and non-fatal, so a stream keeps flowing:

```text
{"error":{"code":"unknown_command","message":"unknown command 'nope'; supported commands: version, commands, list-actions, show-action, dry-run, run-batch, list-toolsets, show-toolset, validate-toolset, run-toolset"},"id":"e","ok":false,"result":null,"version":1}
{"error":{"code":"invalid_json","message":"invalid JSON at byte 32: expected a JSON value, found end of input"},"id":"","ok":false,"result":null,"version":1}
```

Both requests were answered and the process exited `0`.

## Scope

Local stdio only: no socket, no network transport, no HTTP server. Runs are
staged, not applied, which is the documented behaviour of the sharing executor.
