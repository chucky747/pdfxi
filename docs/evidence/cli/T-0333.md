# T-0333 — Geospatial host (`MEDIA-004`)

Row promoted: `MEDIA-004` (Geospatial PDF support) `model` -> `verified`.

`pdfxi_render::geospatial` already validated `/VP` viewports, `/GPTS` bounds,
measure scale and `/GCS`, and mapped PDF/geo coordinates affinely. Nothing
exposed it over a real page. This task adds `pdfxi geo`.

## 1. Host

```text
pdfxi geo info <INPUT.pdf> [--page N] [--json]
pdfxi geo to-geo <INPUT.pdf> --x X --y Y [--viewport N] [--json]
pdfxi geo to-pdf <INPUT.pdf> --lon DEG --lat DEG [--viewport N] [--json]
```

- `info` reads the page dictionary `/VP` array, each entry's `/BBox` (falling
  back to the page media box), the `/Measure` dictionary (`/Subtype`, `/GPTS`,
  `/LPTS`, `/XStep`, `/YStep`, `/Units`) and the `/GCS` dictionary
  (`/Type`, `/EPSG`), then parses `GeospatialDocument` and reports the plan.
- `to-geo` maps a PDF point inside the selected viewport to lon/lat.
- `to-pdf` locates the containing viewport by `/GPTS` (or uses `--viewport`) and
  maps lon/lat back to PDF space.
- Unsupported projections (Web-Mercator/unknown) are reported, and mapping
  returns a typed error instead of extrapolating.

## 2. Evidence

Fixture: one page, `/VP [4 0 R]`, `/BBox [0 0 612 792]`,
`/Measure << /Subtype /GEO /GPTS [-10 40 -5 45] /XStep 1 /YStep 1
/Units (degree) /GCS << /Type /GEOGCS /EPSG 4326 >> >>`.

```text
> pdfxi geo info target\tmp\geospatial.pdf
file: target\tmp\geospatial.pdf  page: 1  gcs: EPSG:4326  epsg: 4326  projection: geographic
viewports: 1  supported: true  plan: geospatial-plan/v1|supported=1|viewports=1|projection=geographic|unit=degree|notes=no-local-points
  0: pdf [0.0, 0.0, 612.0, 792.0]  geo lon -10.000000..-5.000000 lat 40.000000..45.000000  linear "degree" steps 1/1
EXIT=0

> pdfxi geo to-geo target\tmp\geospatial.pdf --x 306 --y 396 --json
{ "page": 1, "viewport": 0, "input": [306.0, 396.0],
  "output": [-7.5, 42.5], "direction": "pdf-to-geo" }
EXIT=0

> pdfxi geo to-pdf target\tmp\geospatial.pdf --lon -7.5 --lat 42.5
lon -7.500000000, lat 42.500000000 -> PDF (306.000, 396.000) on page 1 viewport 0
EXIT=0
```

The centre of the geo bounds maps to the centre of the page and back exactly.

Rejections:

```text
> pdfxi geo info <plain text PDF>
Error: page 1 declares no /VP viewports

> pdfxi geo to-geo ... --x 700 --y 396
Error: map (700, 396) to geo: point (700, 396) is outside the selected viewport

> pdfxi geo to-pdf ... --lon 10 --lat 10
Error: locate (10, 10): no viewport contains geo point (10, 10)

> pdfxi geo info FILE --page 2
Error: --page 2 is outside 1..=1
```

## Scope

Read and map only. No map imagery, tile rendering, reprojection of content
streams, geospatial measure-tool UI or document rewriting. Only affine
geographic (`/GEOGCS`/EPSG:4326-style) viewports map; Web-Mercator and unknown
projections are reported as unsupported with the plan notes preserved.
