# T-0307 — measurement host (`REVIEW-009`)

Row promoted: `REVIEW-009` (Measurement distance area and perimeter)
`model` -> `verified`.

The row computed validated geometry, unit conversion and a deterministic
appearance, but had no caller. This task adds the page-aware CLI measurement
tool and fixes area unit conversion.

## 1. Host

```text
pdfxi measure <FILE> --points "x,y;x,y[;x,y...]"
    [--page N] [--unit pt|in|mm|cm|ft] [--dpi D] [--decimals N] [--json]
```

- Reads the real page and its media box; every supplied point must lie inside
  it. `--page` is one-based and must exist.
- Two points produce a `Measurement::distance`; three or more produce polygon
  `area` (shoelace) and `perimeter`, both in one run.
- The display scale is `MeasureScale::for_unit` for `--unit`, `from_dpi` for
  `--dpi` (inches), or identity points by default. `--unit` and `--dpi` are
  mutually exclusive; unknown units, non-positive DPI and precision above 6 are
  rejected.
- Each result reports the rounded value, unit, stable appearance summary and
  vector-command count.

### Area conversion fix

`Measurement::value` previously multiplied polygon area by the linear factor,
so a 10x10 pt square reported `72 in²` instead of `1 in²`. Area is now scaled by
the square of the linear factor. A regression test asserts a 72x72 pt square is
exactly `1.0000 in²` while its perimeter stays `4.0 in`.

## 2. Evidence

```text
> pdfxi measure fixtures\minimal.pdf --points "0,0;3,4"
file: fixtures\minimal.pdf
page: 1
page_box: 0 0 612 792
unit: pt  units_per_point: 1
points: 2
distance: distance 5.00 pt
```

```text
> pdfxi measure fixtures\minimal.pdf --points "100,100;200,100;200,150" --unit in --json
  "page_box": [0.0, 0.0, 612.0, 792.0],
  "points": 3,
  "unit": "in",
  "units_per_point": 0.013888888888888888,
  "results": [
    { "kind": "area", "value": 0.48, "unit": "in²",
      "summary": "area 0.48 in²", "commands": 4 },
    { "kind": "perimeter", "value": 3.64, "unit": "in",
      "summary": "perimeter 3.64 in", "commands": 4 }
  ]
```

A 150-pt distance at `--dpi 150` reports `distance 1.00 in`. On the real
landscape `powerpoint-slides.pdf`, a 100-pt span reports `3.53 cm`, and the
reported page box is wider than it is tall.

Rejected:

```text
> pdfxi measure fixtures\minimal.pdf --points "0,0;900,0"
Error: point (900, 0) lies outside the page box [0, 0, 612, 792]

> pdfxi measure fixtures\minimal.pdf --points "0,0;1,1" --unit parsec
Error: unknown --unit "parsec"; expected pt, in, mm, cm or ft

> pdfxi measure fixtures\minimal.pdf --points "0,0;1,1" --unit in --dpi 72
Error: --unit and --dpi are mutually exclusive
```

## Scope

Measurements are computed from coordinates, not from picking existing page
graphics: the user supplies the points (as a GUI measure tool would) and the PDF
supplies the page box. There is no persisted measurement annotation, no snapping
and no angle/arc measurement beyond distance/area/perimeter.
