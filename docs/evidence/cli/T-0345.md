# T-0345 — Conformance validation with PDF/VT-1 (`PRINT-002`)

Row promoted: `PRINT-002` (PDF/A PDF/X PDF/E and PDF/VT validation)
`model` -> `verified`.

The preflight engine and the `pdfxi preflight` host for PDF/A-1b/2b/3b,
PDF/X-1a/4, PDF/E-1 and PDF/UA-1 already existed, but the row name also covers
PDF/VT and `pdfxi-standards` had no VT target at all. This task adds a real
PDF/VT-1 target (ISO 16612-2) and extracts the document-part facts from the
document, so the existing CLI host validates every family named by the row.

## 1. Model

- `Standard::PdfVt1` (`PDF/VT-1`, minimum PDF 1.6, `StandardFamily::PdfVt`).
- `PdfVt1Profile` runs the same decidable PDF/X-4 checks (version, encryption,
  output intent subtype `GTS_PDFX`, XMP, embedded fonts, print boxes,
  annotations, forbidden entries, ICC header) and adds two document-part rules:
  - `PDFVT1.DPART_ROOT_MISSING` when the catalog has no `/DPartRoot`;
  - `PDFVT1.DPART_PAGE_UNASSIGNED` when the number of pages carrying `/DPart`
    differs from the page count.
- `PreflightInput` gains `catalog.has_dpart_root` and `page.has_dpart`;
  `ConformanceProfile::PdfVt1` resolves the label, and the fixup helpers treat
  PDF/VT-1 like PDF/X-4 (a `GTS_PDFX` output intent is allowed/required).
- `pdfxi_convert::preflight::build_preflight_input` reads `/DPartRoot` from the
  catalog and `/DPart` from each page dictionary.

## 2. Host

The command that existed for the other profiles now serves VT without a new
surface:

```text
pdfxi preflight PDF/VT-1 FILE [--json] [--fix] [--output PATH]
```

The VT fixture is a real 1.6 PDF with XMP, a `GTS_PDFX` output intent, all five
page boxes, a catalog `/DPartRoot` and a page `/DPart`; it also passes PDF/X-4
and is correctly rejected by PDF/A-2b.

## Scope

PDF/VT-1 is validated as PDF/X-4 plus the decidable document-part rules
(`/DPartRoot` presence and a `/DPart` association on every page). DPart record
levels, DPart metadata streams, the DPart tree shape, and multi-file PDF/VT-2
packaging are not checked; PDF/VT-2 is an explicit typed error. As with the
other profiles this is a deterministic subset preflight, not a certification.
