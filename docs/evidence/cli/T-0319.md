# T-0319 — Static form recognition host (`FORMS-005`)

Row promoted: `FORMS-005` (Automatically recognize static form fields)
`model` -> `verified`.

The heuristic recognition pass existed but produced no PDF and had no host.
This task adds the manifest and real AcroForm output.

## 1. Host

```text
pdfxi form recognize <HINTS.json> --out FORM.pdf [--json]
```

```json
{ "hints": [
    { "kind": "label", "page": 0, "x": 40,  "y": 700, "width": 80,  "height": 14, "text": "Name" },
    { "kind": "input", "page": 0, "x": 130, "y": 698, "width": 200, "height": 18 } ] }
```

- `kind` is `label`, `input`, `checkbox`, `radio` or `choice`; `name` overrides
  the generated field name, `text` is the visible label/prompt.
- `recognize` pairs each control with at most one nearby label on the same page,
  assigns stable names and confidence, and orders fields by reading rank.
- `conversion_plan` yields `FieldSpec`s; `field_dictionary`/
  `widget_annotation` build the dictionaries and `serialize_form_pdf` writes a
  one-page US-Letter AcroForm PDF.
- The bytes are reloaded through `pdfxi-forms::load_acroform` and
  `pdfxi_core::Document`; field count, page count and names must agree before
  the file is written. `--json` reports hints, recognized controls, orphan
  labels, rects, confidence, rank and loaded fields.

## Scope

Hints are caller-classified; this command does not inspect page content, images
or fonts and performs no OCR. It writes a fresh one-page form rather than
overlaying fields on an existing PDF, and radio groups receive a single `On`
option.
