# T-0328 — Unicode analysis host (`PLAT-007`)

Row promoted: `PLAT-007` (Unicode CJK and right-to-left text) `model` ->
`verified`.

The script/bidi/fallback model existed with a recorded host boundary: "no
rasterizer and no external shaper backend; the plan is consumed by the render
lane". This task adds the CLI that produces the plan from real text.

## 1. Host

```text
pdfxi unicode analyze <FILE.pdf> [--font FAMILY=SCRIPTS ...] [--json]
pdfxi unicode analyze --text TEXT [--font ...] [--json]
```

- Extracts every page's real text with `pdfxi-core` (or uses `--text`).
- Runs `analyze_text` for the dominant script, base direction and logical bidi
  runs.
- With `--font FAMILY=script1,script2` candidates, runs
  `fallback_plan_from_text` and reports the ordered chain per run.
- `--json` emits bytes/characters, runs (offsets, script, direction, text) and
  the fallback summary/steps. No shaping or rasterization is performed.

## Scope

Analysis and fallback planning only. The command does not shape glyphs, select
or load a font file, reorder visual text, rasterize, or inject CJK/RTL content
into a PDF. Whitespace/neutral characters form an `other` run in the model, so
a neutral candidate is required when the text contains them.
