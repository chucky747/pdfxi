# T-0277 — Crop and resize pages (EDIT-006 completes)

## What changed

`EDIT-006` ("Reorder rotate crop and resize pages") had reorder and rotate but no
box editing. This task adds two real page operations to the core plan and two CLI
commands:

- `PageOperation::SetBoxes { target, media_box, crop_box }` — writes `/MediaBox`
  and/or `/CropBox` on the selected pages. Boxes are `[left, bottom, right, top]`
  in points, validated for finiteness and non-degeneracy.
- `PageOperation::Resize { target, width, height }` — replaces the media box with
  `[0 0 width height]`, sets the crop box to the same rectangle, and scales the
  page content to fit, centred. The transform is written as two uncompressed
  content streams (`q … cm` before, `Q` after) wrapped around the original
  `/Contents`, so compressed source streams stay byte-for-byte untouched.

```text
pdfxi pages crop   <FILE> [--pages SPEC] --bounds left,bottom,right,top --out OUT
pdfxi pages resize <FILE> [--pages SPEC] --size WIDTHxHEIGHT          --out OUT
```

Files: `crates/pdfxi-core/src/pages.rs` (operations, rendering, three core
tests), `crates/pdfxi-cli/src/pages.rs` (commands and parsers),
`crates/pdfxi-cli/src/main.rs`, `crates/pdfxi-cli/tests/cli.rs` (three CLI
tests).

## Real-document run

`fixtures/realworld/powerpoint-slides.pdf` (3 pages, 792 x 612 pt):

```text
$ pdfxi pages crop … --bounds 10,20,700,560
file: target\tmp\pages-crop.pdf
pages: 3
bytes: 121136
  => /CropBox [ 10 20 700 560 ] on all three pages

$ pdfxi pages resize … --size 400x300
file: target\tmp\pages-resize.pdf
pages: 3
bytes: 121775
  => /MediaBox [ 0 0 400 300 ] on all three pages
  => three `cm` content transforms
  => extracted text still returns all three slide markers
```

Counts were checked in the output bytes (`crop_boxes=3`, `resize_media=3`,
`transforms=3`, `resize_text_pages=3`), and both outputs reparse with `pages: 3`.

## Honest scope

- `Resize` scales content; it does not reflow text or re-embed fonts.
- `Crop` sets `/CropBox` only. It does not remove cropped content from the file
  (that is redaction/sanitisation, a different row).
- Box coordinates are absolute points; the CLI does not convert units.
- Reorder and rotate were already reachable through `pages move/reorder/rotate`;
  with crop and resize, every word in the row title is now a reachable action.
