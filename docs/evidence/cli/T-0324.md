# T-0324 — PostScript export host (`EXPORT-009`)

Row promoted: `EXPORT-009` (Export to PostScript) `model` -> `verified`.

The DSC PostScript writer existed but nothing mapped a real PDF into it. This
task adds `pdfxi export postscript` over the geometry-aware text model.

## 1. Host

```text
pdfxi export postscript <FILE.pdf> --out OUT.ps [--json]
```

- Loads the PDF and reads each page's media size from `Document::page_frame`.
- `pdfxi_edit::text_blocks` supplies every text run with its page coordinates
  and font size; each non-empty run becomes a `PsContent::Text` (`PsText`) with
  Helvetica.
- `export_postscript_with_report` writes deterministic DSC PostScript
  (`%!PS-Adobe-3.0`, `%%BoundingBox`, `%%Pages`, `%%DocumentFonts`, escaped
  strings).
- The command verifies the output starts with the DSC header and reports pages,
  runs, bytes and the omitted content classes (vector art, images,
  annotations).

## Scope

This is the positioned text subset of the exporter's text/vector model. Vector
paths, images, annotations, transparency and colour are not mapped, and no
PostScript interpreter is bundled. Page rotation is not applied to run
coordinates.
