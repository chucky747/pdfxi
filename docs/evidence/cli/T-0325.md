# T-0325 — Transparency inspection host (`STD-005`)

Row promoted: `STD-005` (Transparency and blend modes) `model` -> `verified`.

The transparency model existed with a documented host boundary: "pixel
compositing and colour management stay render-backend responsibilities". This
task adds the document-byte host that inspects real groups and graphics states.

## 1. Host

```text
pdfxi transparency inspect <FILE.pdf> [--json]
```

- Reads each page dictionary's real `/Group` dictionary; when `/S` is
  `/Transparency`, parses `/BM`, `/I` and `/K` into `TransparencyGroup`.
- Resolves `/Resources /ExtGState`, reads every state that declares `/BM`,
  `/ca` or `/CA`, parses the mode, converts alpha to the model's 256-step scale,
  and validates a `BlendSpec`.
- Prints canonical descriptors (`Isolated|NonKnockout|Screen`,
  `Multiply ca=128 CA=256`) and a mode summary. `--json` emits stable rows.
- An unknown blend mode is a typed error; a document with no transparency
  reports zero groups/states.

## 2. Evidence

```text
> pdfxi transparency inspect target\tmp\watermarked.pdf --json
{
  "pages": 1,
  "groups": 0,
  "states": 1,
  "modes": ["Normal"],
  "rows": [
    { "source": "ExtGState /GS1", "mode": "Normal",
      "source_alpha": 38, "backdrop_alpha": 38,
      "descriptor": "Normal ca=38 CA=38" }
  ]
}
```

A test PDF carrying a page `/Group` with `/BM /Screen /I true` and an
`/ExtGState /GS1` with `/BM /Multiply /ca 0.5 /CA 1` reports:

```text
pages: 1  groups: 1  states: 1  modes: Multiply,Screen
page 1  group  Screen  Isolated|NonKnockout|Screen
page 1  ExtGState /GS1  Multiply  Multiply ca=128 CA=256
```

A plain text PDF reports `groups: 0  states: 0  modes: none`.

Rejections:

```text
> ... /BM /Bogus
Error: blend mode "Bogus": unknown blend mode 'Bogus'

> pdfxi transparency inspect missing.pdf
Error: read missing.pdf
```

## 3. Tests

```text

test transparency_inspect_rejects_unknown_modes_and_missing_files ... ok
```

The first builds a real PDF with a page group and a blend-mode graphics state
and checks every reported field. The second injects an unknown mode and checks
the typed error, plus a missing input.

## Scope

Inspection and validation only: the command does not apply or author blend
modes, perform compositing, manage colour spaces, or flatten transparency. It
reads direct or referenced page groups and graphics states; soft masks and
colour-managed backdrops are not evaluated.
