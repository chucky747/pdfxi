# T-0315 — PDF Portfolio assembly host (`CREATE-010`)

Row promoted: `CREATE-010` (Create and customize PDF Portfolios)
`library` -> `verified`.

The library already assembled real `/EmbeddedFile` streams, `/Collection` and a
sorted name tree, but nothing collected files from disk or wrote the result.
This task is the host.

## 1. Host

```text
pdfxi create portfolio <MANIFEST.json> --out PDF [--json]
```

```json
{ "title": "Case file",
  "entries": [
    { "name": "docs/brief.txt", "description": "Case brief", "order": 0,
      "file": "brief.txt" }
  ] }
```

- `name` is the in-portfolio path: relative, traversal-free, forward slashes.
  `file` is read from disk and resolved against the manifest directory when it
  is relative.
- Per-file (`64 MiB`) and total (`256 MiB`) byte budgets are checked before the
  package is built.
- `PortfolioManifest` is validated, then `build_portfolio_package` writes the
  `/Collection` dictionary and the `/EmbeddedFiles` name tree in sorted order.
- The written PDF is reopened: `is_portfolio` must be true, the item count must
  match the manifest, and each `attachment_bytes(key)` must equal the source
  file exactly. `--json` reports counts, bytes, descriptions and the verified
  total. Empty collections are valid and produce a collection with no files.

## 2. Evidence

```text
> pdfxi create portfolio target\tmp\pf\manifest.json --out target\tmp\pf\case.pdf --json
{
  "manifest": "target\\tmp\\pf\\manifest.json",
  "out": "target\\tmp\\pf\\case.pdf",
  "title": "Case file",
  "entries": 2,
  "embedded_bytes": 30,
  "pdf_bytes": 1188,
  "collection": true,
  "items": 2,
  "verified_files": 2,
  "files": [
    { "name": "docs/brief.txt", "file": "target\\tmp\\pf\\brief.txt",
      "bytes": 16, "description": "Case brief" },
    { "name": "docs/notes.txt", "file": "target\\tmp\\pf\\notes.txt",
      "bytes": 14, "description": null }
  ]
}

> pdfxi info target\tmp\pf\case.pdf
pdf_version: 1.7
bytes: 1188
pages: 1

> pdfxi portfolio target\tmp\pf\case.pdf
collection: yes
  brief.txt  size: 16  type: application/octet-stream  description: Case brief
  notes.txt  size: 14  type: application/octet-stream  description:

> pdfxi portfolio target\tmp\pf\case.pdf --extract target\tmp\pf\out
extracted: 2 files
  target\tmp\pf\out\docs\brief.txt  Case brief body.
  target\tmp\pf\out\docs\notes.txt  Hearing notes.
```

Rejections:

```text
> ... {"name":"../evil.txt","file":"brief.txt"}
Error: portfolio manifest: portfolio entry 0: name contains an empty, current, or parent component

> ... {"name":"docs/a.txt","file":"absent.txt"}
Error: read portfolio file target\tmp\pf\absent.txt
```

An empty `entries` list is accepted and writes a collection with `items: 0`.

## Scope

The manifest is caller-supplied; there is no file dialog or folder picker.
Media types default to `application/octet-stream` unless the package declares
one, descriptions and order are stored, and no thumbnails, cover pages, custom
column layouts or editing of an existing portfolio are produced.
