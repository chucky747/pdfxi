# T-0320 — Text restyle host (`EDIT-002`)

Row promoted: `EDIT-002` (Edit fonts size spacing and color) `model` ->
`verified`.

The style model existed and its notes recorded that "emitting PDF text operators
is a host adapter responsibility". This task adds the emitter and CLI.

## 1. Library

`pdfxi_edit::restyle_run_text(document, page, run, &RunStyleOverride)`:

- `RunStyleOverride` carries optional font size, horizontal scaling, character
  spacing, word spacing and RGB fill colour, with typed validation
  (`InvalidFontSize`, `InvalidStyle`).
- The run selects its paragraph block; every show operator in the block is
  replaced with one re-emitted text object using the requested
  `Tc`/`Tw`/`Tz`/`rg`/`Tf`, the block's reading baselines and reflow width.
- The font family is unchanged: the existing simple font is reused when it can
  encode the text, otherwise the bundled fallback font is embedded.
- Existing non-text operators are preserved by span splicing; saving produces a
  full PDF whose text still extracts.

## 2. Host

```text
pdfxi restyle <FILE.pdf> --out OUT.pdf [--page N] [--run N]
    [--size PT] [--scale PCT] [--char-spacing PT] [--word-spacing PT]
    [--color R,G,B] [--json]
```

At least one style option is required. The command loads the document, resolves
the run in the geometry-aware text model, applies the override, saves, reopens
the output, extracts the page and requires the target's leading token. `--json`
reports the block, text, requested values, reflowed lines, font resource/base
font/embedded flag, extracted characters and bytes.

## Scope

Restyling is paragraph-level: the run identifies the block and all of its text
receives the override. Font family changes, per-glyph styling, alignment and
line-height changes are not applied. Text is reflowed at the original block
width, so line breaks can change. The fallback font inflates the file when the
original font cannot encode the text.
