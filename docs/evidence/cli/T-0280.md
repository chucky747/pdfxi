# T-0280 — `pdfxi layers`: optional-content layers and default visibility

## What changed

`VIEW-010` ("Optional content layers") was `model`: the compatibility scanner
knew the `/OCProperties` token, but nothing read the layers. This task adds the
reader and a CLI surface.

```text
$ pdfxi layers <FILE> [--json]
layer: 1  Background  visible: yes
layer: 2    Watermark  visible: no
layer: 3    Notes  visible: yes
layers: 3
```

`pdfxi-core::layers` reads the catalog's `/OCProperties`:

- `/OCGs` — every layer with its `/Name`.
- `/D` default configuration — `/OFF`, `/ON`, `/BaseState` (default `/ON`) and
  `/Order`, including nested arrays (depth is reported and indented in text).
- Layers missing from `/Order` are appended at depth 0 so none disappear.

`--json` emits `file`, `count` and one row per layer with `index`, `name`,
`visible` and `depth`.

Files: `crates/pdfxi-core/src/layers.rs` (reader, two tests),
`crates/pdfxi-core/src/lib.rs`, `crates/pdfxi-cli/src/layers.rs`,
`crates/pdfxi-cli/src/main.rs`, `crates/pdfxi-cli/tests/cli.rs` (two tests),
`crates/pdfxi-testkit/src/lib.rs` (`layered_pdf()` fixture builder).

## Live run

Generated document with three layers, `/BaseState /ON`, `Watermark` in `/OFF`,
`Notes` in `/ON`, and a nested `Watermark, Notes` group in `/Order`:

```text
$ pdfxi layers layers-demo.pdf
layer: 1  Background  visible: yes
layer: 2    Watermark  visible: no
layer: 3    Notes  visible: yes
layers: 3
EXIT=0

$ pdfxi layers layers-demo.pdf --json
{
  "file": "target\\tmp\\layers-demo.pdf",
  "count": 3,
  "layers": [ { "index": 1, "name": "Background", "visible": true, "depth": 0 }, ... ]
}
```

## Tests

```text
cargo test -p pdfxi-core --lib layers::   -> 2 passed
cargo test -p pdfxi-cli --test cli layers -> 2 passed
```

- `layers_report_names_visibility_and_nesting` (core) — `/OFF` hides, `/ON`
  shows, `/BaseState` decides the rest, nested `/Order` reports depth 1.
- `documents_without_ocproperties_have_no_layers` (core).
- `layers_report_visibility_and_nesting` and `layers_json_has_stable_fields`
  (CLI), including the two-space indentation of nested layers.

## Honest scope

- Reads the default configuration only. Alternate `/Configs` (per-user layer
  sets) and the `/AS` usage dictionary are not exposed yet.
- Reports visibility; it does not toggle layers, rewrite them, or render a page
  with layers hidden.
- OCGs referenced but not present in `/OCGs` are skipped rather than guessed.
