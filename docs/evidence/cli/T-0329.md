# T-0329 — Home state host (`MANAGE-002`)

Row promoted: `MANAGE-002` (Home recents favorites and collections) `model` ->
`verified`.

The headless `pdfxi_app::home::HomeModel` existed with no persistence host. This
task adds a CLI state-file host and links the app crate without its GUI feature.

## 1. Dependency decision

`pdfxi-cli` now depends on `pdfxi-app` with default features (no `ui`). The
dependency direction is host → app model; no feature crate depends on the app,
and no egui/eframe/winit code enters the CLI. This is the linkable-crate route
the plan anticipated for app-model rows.

## 2. Host

```text
pdfxi home list --state STATE.txt [--json]
pdfxi home add FILE --state STATE.txt [--json]
pdfxi home favorite FILE [--remove] --state STATE.txt [--json]
pdfxi home collection NAME --state STATE.txt [--add FILE] [--remove FILE]
    [--delete] [--json]
```

- `add` normalizes the path through `DocumentKey::from_path`, records the file
  stem as the title and moves it to the front of recents.
- `favorite` toggles a favorite by key.
- `collection` creates, adds/removes a member, or deletes a named collection.
- The state file uses `HomeModel::serialize`, a bounded escaped newline format;
  a missing file starts empty and a malformed file is a typed error.
- `--json` reports recents (with ordinals), favorites and collections with
  member keys.

## 3. Evidence

```text
> pdfxi home add target\tmp\ps-src.pdf --state target\tmp\home-state.txt --json
"recents": [ { "key": "target/tmp/ps-src.pdf", "title": "ps-src", "ordinal": 0 } ]

> pdfxi home add target\tmp\restyled.pdf --state target\tmp\home-state.txt
recents: 2
  restyled	target/tmp/restyled.pdf
  ps-src	target/tmp/ps-src.pdf

> pdfxi home favorite target\tmp\ps-src.pdf --state target\tmp\home-state.txt
favorites: 1
  ps-src	target/tmp/ps-src.pdf

> pdfxi home collection "Case files" --add target\tmp\ps-src.pdf --state target\tmp\home-state.txt
collections: 1
  Case files	1 member(s)

> pdfxi home list --state target\tmp\home-state.txt --json
{
  "recents": [ {"title":"restyled","ordinal":1}, {"title":"ps-src","ordinal":0} ],
  "favorites": [ {"key":"target/tmp/ps-src.pdf","ordinal":2} ],
  "collections": [ {"name":"Case files","members":["target/tmp/ps-src.pdf"]} ]
}
```

Removing the favorite and deleting the collection reports `favorites: 0` and
`collections: 0`; the recents persist across invocations.

Rejections:

```text
> pdfxi home add target\tmp\missing.pdf --state ...
Error: document target\tmp\missing.pdf does not exist

> pdfxi home collection "" --state ...
error: the following required arguments were not provided: <NAME>

> pdfxi home list  # after writing "garbage"
Error: parse state ...: home serialization line 1 is malformed
```

## Scope

Home is a state file, not a GUI home screen: it does not open documents, render
thumbnails or read file metadata beyond the path. Recents are capped by the
model (50), favorites 200, collections 64 and members 500.
