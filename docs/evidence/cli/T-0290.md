# T-0290 — pencil, stamp and file-attachment annotations (`REVIEW-003`)

Row promoted: `REVIEW-003` (Pencil stamp and file attachment annotations)
`model` -> `verified`.

Pencil (`add_ink`) and stamps (`add_stamp`) already had document writers; the
missing piece was an embedded-file annotation, and none of the three had a host.
This task adds the writer and exposes all three through `pdfxi annotate`.

## 1. File-attachment writer

```rust
pub fn add_file_attachment(
    document, page_index, rect, name, bytes, author
) -> Result<AnnotationRef>
```

- Stages four objects: an `/EmbeddedFile` stream (`/Params /Size /ModDate`), a
  `/Filespec` (`/F`, `/UF`, `/EF /F`, `/Desc`), the annotation and its
  appearance.
- The annotation is `/Subtype /FileAttachment`, `/Name /Paperclip`, `/FS` ->
  the file specification, `/Contents` = the attachment name, plus `/T`, `/NM`,
  `/M`, `/F 4` and the paperclip `/AP /N`.
- The name must be a single reference (no `/`, `\`, control characters or empty
  text), and the payload is capped at `MAX_ATTACHMENT_BYTES` (64 MiB) with a
  typed error. New errors: `InvalidAttachmentName`, `AttachmentTooLarge`.
- Because `/FS` carries the name, the annotation is discoverable through
  `pdfxi_core::Document::attachments()` — the same reader `pdfxi attachments`
  uses.

## 2. Host

`pdfxi annotate add --kind ...` now accepts six kinds:

```text
--kind free-text --rect x0,y0,x1,y1 --text T       (REVIEW-002)
--kind callout   --rect ... --anchor x,y --text T  (REVIEW-002)
--kind cloud     --rect ...                        (REVIEW-002)
--kind pencil    --ink "x0,y0 x1,y1; x2,y2" --stroke-width W [--text T]
--kind stamp     --rect ... --stamp-name Approved --text T
--kind file-attachment --rect ... --attachment PATH [--name NAME]
```

`--rect` is optional in the parser and required per kind (pencil derives its
bounds from the stroke set). `annotate list` prints each annotation with its
`/NM` id, subtype, text, author, rect and date.

## 3. Real evidence

```text
> pdfxi annotate add authoring-page-boxes.pdf --out target\tmp\pencil.pdf --kind pencil --ink "72,600 120,620 160,600; 80,560 140,560" --stroke-width 3 --text "Pencil note" --author Dana
added: pdfxi-ink-7

> pdfxi annotate add target\tmp\pencil.pdf --out target\tmp\stamp.pdf --kind stamp --rect "400,600,560,650" --stamp-name Approved --text "Approved 2026" --author Eve
added: pdfxi-stamp-9

> pdfxi annotate list target\tmp\stamp.pdf
pdfxi-ink-7  Ink  "Pencil note"  by Dana  rect: 70 558 162 622
pdfxi-stamp-9  Stamp  "Approved 2026"  by Eve  rect: 400 600 560 650
annotations: 2
```

```text
> pdfxi annotate add authoring-page-boxes.pdf --out target\tmp\with-attach.pdf --kind file-attachment --rect "72,700,96,724" --attachment target\tmp\evidence.bin --author Alice
added: pdfxi-attachment-7

> pdfxi attachments target\tmp\with-attach.pdf
name: evidence.bin  size: 22  page: 1  description: Alice
attachments: 1

> pdfxi attachments target\tmp\with-attach.pdf --extract target\tmp\attach-out
extracted: 1 files
> Get-Content target\tmp\attach-out\evidence.bin
attachment payload 123

> pdfxi annotate list target\tmp\with-attach.pdf --json
"subtype": "FileAttachment", "contents": "evidence.bin", "author": "Alice"
```

The pencil rectangle `70 558 162 622` is the stroke bounds expanded by half the
3-point stroke width, and the attachment is readable through the same CLI
command that lists document-level attachments.

## Scope

Pencil, stamp and file attachment annotations are all reachable and survive a
save/reopen. Stamp presets and styles are the library defaults; the interactive
pencil tool and UI drawing surface remain app-level and are not claimed here.
