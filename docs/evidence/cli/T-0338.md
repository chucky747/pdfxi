# T-0338 — Ink manager and overprint-preview host (`PRINT-005`)

Row promoted: `PRINT-005` (Ink manager and overprint preview) `model` ->
`verified`.

The separations host from T-0337 now also resolves each spot's alternate process
space and tracks overprint graphics states. This task adds the `pdfxi ink`
ink-manager view and the overprint counts that an overprint preview needs.

## 1. Host

```text
pdfxi ink <INPUT.pdf> [--json]
```

- Reads `/Resources /ExtGState` entries with `/op`, `/OP` and `/OPM`, and
  records the overprint states the document declares.
- Tracks `gs` in the content stream so paint operators after a `gs` are counted
  as overprint operations for the painted plates.
- Resolves the alternate process space of `/Separation` and `/DeviceN` colour
  spaces (the second element of the array), reported as each spot's
  `alternate`.
- Reports every plate with process/spot class, paint operations, overprint
  operations and alternate, plus the overprint states and the stable plan
  descriptor.

`pdfxi separations` gained the same additive fields (per-plate overprint counts,
alternates and the state list); its existing output and tests are unchanged.

## Scope

An inspection/manager view only: no overprint simulation, no ink editing or
aliasing, no ink-limit computation and no rendered proof. Overprint is taken
from explicit `/ExtGState` states selected by `gs`; implicit overprint
inheritance across forms/xobjects and `OPM` blending are not simulated.
