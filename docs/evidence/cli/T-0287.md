# T-0287 — `pdfxi decorate bates`: sequential Bates numbering

Row promoted: `EDIT-010` (Bates numbering) `model` -> `verified`.

## What ships

```text
pdfxi decorate bates <FILE> --out PATH [--prefix TEXT] [--suffix TEXT]
    [--start N] [--digits N] [--increment N] [--corner bottom-right|bottom-center|bottom-left|top-right|top-center|top-left]
    [--font-size N] [--margin N] [--json]
```

- `pdfxi_edit::build_bates_plan` builds the plan from `BatesConfig` and one
  `BatesPageBounds` per page (from `Document::page_frame`, so the media box
  origin is preserved).
- Each `BatesStamp` is rendered at `stamp.position()` into a content stream and
  wrapped in `transform_for_page(geometry)`, the same display-to-page matrix the
  header/footer renderer uses, so rotated pages get an upright number in the
  requested corner.
- The text is escaped with `pdfxi_edit::escape_literal` and drawn with a
  standard `/Helvetica` font, merged into the page resources by the
  `PageOperation::StampPages` path added in T-0286.
- `--start` must be at least 1, `--increment` at least 1, `--digits` 1..=20 and
  `--font-size` 4..=200; each violation is a clear error.
- The clock value passed to the plan is a constant because the CLI configures no
  date stamp, so the output is deterministic.

## Real-document evidence

```text
> pdfxi decorate bates fixtures\realworld\powerpoint-slides.pdf --out target\tmp\slides-bates.pdf --prefix "EX-" --start 1 --digits 6 --corner bottom-right
file: fixtures\realworld\powerpoint-slides.pdf
out:  target\tmp\slides-bates.pdf
pages: 3
stamped: 3
numbers: EX-000001 .. EX-000003

> pdfxi text target\tmp\slides-bates.pdf
Lantern Slide•The lantern slide marker is the first landscape page.EX-000001
Harbor Slide•The harbor slide marker is the second landscape page.EX-000002
Meadow Slide•The meadow slide marker is the third and final landscape page.EX-000003
```

  "stamped": 3,

- `decorate_bates_honours_start_increment_and_suffix` pins `B-0010-A`,
  `B-0015-A`, `B-0020-A` on the three pages with `--start 10 --increment 5
  --digits 4 --suffix=-A`.
- `decorate_bates_places_number_on_a_rotated_page` proves the transform path on
  a rotated fixture: the original page text is unchanged and the number is
  extractable.
- `decorate_bates_rejects_invalid_configuration` covers zero digits and
  `--start 0`.

## Scope

One number per page with prefix, suffix, zero padding, increment and six anchor
corners; no date stamp, no separate first-page style, and no per-page ranges —
those are further `BatesConfig` options and are not claimed.
