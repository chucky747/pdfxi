# T-0327 — Portfolio management host (`MANAGE-004`)

Row promoted: `MANAGE-004` (PDF Portfolio management) `model` -> `verified`.

The app model validated add/remove/rename/move/describe plans but had no host
that read or wrote a real portfolio. This task adds the edit flags to
`pdfxi portfolio`.

## 1. Host

```text
pdfxi portfolio <FILE.pdf> --out OUT.pdf
    [--add LOCAL=NAME] [--rename OLD=NEW] [--describe NAME=TEXT]
    [--remove NAME] [--json]
```

- Loads every `/Names /EmbeddedFiles` entry and its bytes through
  `portfolio_items` + `attachment_bytes`.
- Applies additions (reading `LOCAL`), renames/moves (`OLD=NEW`), description
  changes (`NAME=TEXT`) and removals in that order.
- Validates the resulting `PortfolioManifest` and rebuilds the collection with
  `build_portfolio_package`, preserving each entry's bytes.
- Reopens the output, checks the count and path set, and compares every embedded
  stream with the source bytes.
- With no edit flag, the existing list/`--extract` behavior is unchanged.

## Scope

Edits are applied to the embedded-file collection only. The rebuilt collection
uses the title `portfolio`, keeps entry bytes exactly, and does not preserve
custom cover images, thumbnails, column layouts or the original `/Collection`
display schema. Listing/extraction behavior is unchanged.
