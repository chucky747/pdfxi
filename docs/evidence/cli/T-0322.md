# T-0322 — Alt text and table editor host (`ACCESS-002`)

Row promoted: `ACCESS-002` (Alt text and table editor) `model` -> `verified`.

The row's recorded tests were navigation-only, but the title's alt-text and
table editor had no host. `pdfxi structure apply` already writes `/XI_NodeId`
on every structure element; this task addresses those ids directly.

## 1. Host

```text
pdfxi accessibility alt <FILE.pdf> --out OUT.pdf --node N
    (--text TEXT | --clear) [--json]

pdfxi accessibility table <FILE.pdf> --out OUT.pdf --node N
    [--scope row|column|both] [--json]
```

- The catalog `/StructTreeRoot` is walked through its `/K` references (visited
  set and a 200000-element cap) to the element whose `/XI_NodeId` matches.
- `alt` sets `/Alt` and the `/XI_Alt` mirror to the PDF text string, or removes
  both with `--clear`.
- `table` requires a `TH`/`TD` role and writes `/Scope /Row`, `/Column` or
  `/Both`; omitting `--scope` removes the entry.
- The document is saved, reopened, and the element is resolved again; the stored
  value must equal the requested value before the command succeeds.

## 2. Evidence

```text
file: fixtures\minimal.pdf

> pdfxi accessibility alt target\tmp\a11y-tagged.pdf --out target\tmp\a11y-alt.pdf --node 2 --text "Updated paragraph alt" --json

  "node": 2, "role": "paragraph", "field": "alt",
  "value": "Updated paragraph alt", "bytes": 2476

> pdfxi accessibility table target\tmp\a11y-tagged.pdf --out target\tmp\a11y-scope.pdf --node 4 --scope column --json
{
  "node": 4, "role": "tableheader", "field": "scope",
  "value": "Column", "bytes": 2459

```

The saved alt bytes contain the hex string
`557064617465642070617261677261706820616C74` and no longer contain the old
`4F6C6420706172616772617068`; the scoped bytes contain `/Scope /Column`.

Rejections:

```text
> ... --node 99 --text x
Error: no structure element with /XI_NodeId 99

> accessibility table ... --node 2 --scope row
Error: node 2 has role paragraph, not a table header or data cell

> accessibility table ... --node 4 --scope sideways
Error: unknown scope "sideways"; expected row, column or both

> accessibility alt fixtures\minimal.pdf ... --node 1 --text x
Error: the catalog has no /StructTreeRoot reference
```

## Scope

The editor addresses tagged PDFs whose structure elements carry `/XI_NodeId`
(the shape written by `pdfxi structure apply`). It edits `/Alt` and `/Scope`
only; it does not create or reorder the tree, add table cells, or edit headers
associations, and it does not provide a GUI editor.
