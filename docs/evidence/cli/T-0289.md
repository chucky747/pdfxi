# T-0289 — free text, callout and cloud annotations (`REVIEW-002`)

Row promoted: `REVIEW-002` (Free text callout line arrow shape and cloud)
`model` -> `verified`.

The row's model already covered typed options, leader/arrowhead/polygon/cloud
geometry and the dictionary round-trip, but had no document writer and no host.
This task adds both.

## 1. Document writers (`pdfxi-edit::document_annotations`)

```rust
pub fn add_free_text(document, page_index, rect, text, font_size, author) -> Result<AnnotationRef>
pub fn add_callout(document, page_index, rect, anchor, text, font_size, author) -> Result<AnnotationRef>
pub fn add_cloud(document, page_index, rect, author) -> Result<AnnotationRef>
```

- `add_free_text` stages `/Subtype /FreeText` with `/DA (/Helv <size> Tf 0 g)`,
  `/Contents`, `/T`, `/NM`, `/M`, `/F 4` and an `/AP /N` form that draws a thin
  border and greedily wrapped text lines. Font size is validated to 4..=72, the
  text must not be blank, and the rectangle must lie on the page.
- `add_callout` is the same writer with `/IT /FreeTextCallout` and
  `/CL [anchor, nearest box edge]`, and the appearance also strokes the leader
  line. The anchor must be finite and on the page.
- `add_cloud` stages `/Subtype /Polygon`, `/IT /PolygonCloud`, `/Vertices` and a
  scalloped appearance made of overlapping stroked circles (four cubic Beziers
  each) along the rectangle perimeter, with the annotation `/Rect` expanded by
  the bump radius so the border is fully inside its own bounding box.
- Three new typed errors (`InvalidFontSize`, `EmptyText`, `InvalidAnchor`) keep
  the failure modes explicit.

## 2. Host (`pdfxi annotate`)

```text
pdfxi annotate add <FILE> --out PATH --kind free-text|callout|cloud
    --page N --rect x0,y0,x1,y1 [--text TEXT] [--anchor x,y]
    [--font-size N] [--author NAME] [--json]
pdfxi annotate list <FILE> [--page N] [--json]
```

`add` stages one annotation, saves a standalone document and reports the new
`/NM` identifier; `list` reads the page back through `list_annotations` so the
evidence is the file, not the command's own claim.

## Scope

Free text, callout and cloud are reachable and round-trip through a full save.
The line/arrow and rectangle/oval/polygon tools were already available as
library functions and are not exposed as CLI flags yet, and vector/text styles
beyond the validated default (colour and opacity options) remain model-level.
