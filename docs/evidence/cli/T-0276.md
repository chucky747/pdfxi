# T-0276 — `pdfxi pages`: page surgery on real documents

## What changed

`EDIT-005` (insert/delete/extract/replace) and `EDIT-007` (split and merge) had a
complete library model (`PagePlan`, `PageOperation`, `Document::apply_page_plan`
with typed errors) but no user could reach it. This task adds the CLI group:

```text
pdfxi pages extract <FILE> --pages 3,1          --out OUT
pdfxi pages delete  <FILE> --pages 2            --out OUT
pdfxi pages move    <FILE> --from 1 --to 3      --out OUT
pdfxi pages reorder <FILE> --order 3,1,2        --out OUT
pdfxi pages rotate  <FILE> --pages 1 --angle 90 --out OUT
pdfxi pages insert  <FILE> --after 1 OTHER      --out OUT
pdfxi pages replace <FILE> --page 2 OTHER --source-page 3 --out OUT
pdfxi pages merge   A.pdf B.pdf                 --out OUT
pdfxi pages split   <FILE> --every 1 --out-dir DIR
```

`--pages` accepts `all`, lists (`1,3`) and ranges (`2-4`); page numbers are
one-based; zero and out-of-range values are rejected with typed errors. Every
command writes a standalone PDF built from the source page objects, reparse-
checked before it reports `file`, `pages` and `bytes`.

Files: `crates/pdfxi-cli/src/pages.rs` (new, documented, two unit tests),
`crates/pdfxi-cli/src/main.rs` (subcommands), `crates/pdfxi-cli/tests/cli.rs`
(eight integration tests).

## Real-document run

`fixtures/realworld/powerpoint-slides.pdf` (3 pages: Lantern, Harbor, Meadow):

```text
$ pdfxi pages extract … --pages 3,1
pages: 2
  => Meadow Slide, Lantern Slide        (order preserved)

$ pdfxi pages delete … --pages 2
pages: 2
  => Lantern Slide, Meadow Slide        (Harbor gone)

$ pdfxi pages replace … --page 2 … --source-page 3
pages: 3
  => Lantern, Meadow (replacement), Meadow (original page 3)

$ pdfxi pages rotate … --pages 1 --angle 90
pages: 3
  => output contains /Rotate 90

$ pdfxi pages move … --from 1 --to 3
  => Harbor, Meadow, Lantern

$ pdfxi pages merge … …
pages: 6

$ pdfxi pages split … --every 1 --out-dir target\tmp\pages-split
parts: 3
  powerpoint-slides-01.pdf  120,333 bytes
  powerpoint-slides-02.pdf  120,334 bytes
  powerpoint-slides-03.pdf  120,334 bytes
```

## Tests

```text
cargo test -p pdfxi-cli --test cli pages
test result: ok. 8 passed; 0 failed; 0 ignored
```

- `pages_extract_keeps_real_world_pages_in_order`
- `pages_delete_removes_a_real_world_page`
- `pages_move_reorders_real_world_pages`
- `pages_rotate_writes_rotation_on_the_selected_page`
- `pages_insert_places_every_page_of_the_other_document`
- `pages_replace_swaps_one_page`
- `pages_merge_concatenates_documents`
- `pages_split_writes_numbered_parts`
- `selection_parses_all_lists_and_ranges`, `selection_rejects_zero_and_out_of_range_pages`

Ordering is asserted by extracting text from the produced PDFs, not by trusting
the command's own report.

## Honest scope

- `EDIT-005` and `EDIT-007` are verified by this command group.
- `EDIT-006` also requires **crop and resize**; `move`, `reorder` and `rotate`
  are reachable now, but the row stays `library` until crop and resize exist and
  are tested. Not claimed here.
- Merge/split copy page objects with remapped numbers and unchanged stream
  bytes; they do not optimise or subset shared resources.
- Split overwrites `<stem>-NN.pdf` in the chosen directory; it does not version
  or refuse existing files.
