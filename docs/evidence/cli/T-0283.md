# T-0283 — `pdfxi compare`: content-aligned side-by-side revision compare

Row promoted: `VIEW-015` (Side-by-side compare view) `model` -> `verified`.

## What ships

`pdfxi compare <LEFT> <RIGHT> [--json] [--lines] [--fail-on-difference]`.

Pages are aligned by their **normalised extracted text** (trimmed lines, empty
lines dropped), not by page number. That is the host work the row was missing:
the existing model only paired strictly increasing page numbers, which labels an
insertion at the front as "last page added" and a deletion as "page N changed
and the last page deleted". Alignment is an LCS with a deterministic tie-break,
followed by a block pass that zips deletions and insertions in place into
*changed* pairs, so two unrelated single-page documents are one changed pair
rather than one deletion plus one insertion. Unpaired leftovers stay
insertions/deletions.

Aligned pairs whose text differs are `changed` and carry removed/added line
counts (line-level LCS). `--lines` prints the differing lines as two columns,
capped at 20 rows per page. `--fail-on-difference` prints the report and then
exits `1`, so scripts can gate on it. `--json` emits stable fields:
`left`, `right`, `left_pages`, `right_pages`, `identical`, `summary` and
`pages[]` rows with `kind`, `left`, `right`, `changed`, `removed_lines`,
`added_lines`.

Limits are explicit: alignment is quadratic and refuses more than 4,000,000
page or line pairs with a typed error instead of allocating unbounded memory.

## Real-document evidence

All commands below ran against check-in fixtures:

- `fixtures/realworld/powerpoint-slides.pdf` — 3 pages (Lantern/Harbor/Meadow)
- `fixtures/authoring/authoring-page-boxes.pdf` — 1 page, "All five page boxes"
- `fixtures/minimal.pdf` — 1 page, "Hello, PDFXI!"
- `target\tmp\slides-minus-p2.pdf` — produced by
  `pdfxi pages delete fixtures\realworld\powerpoint-slides.pdf --pages 2`.

### Identical documents

```text
> pdfxi compare fixtures\realworld\powerpoint-slides.pdf fixtures\realworld\powerpoint-slides.pdf
left:  fixtures\realworld\powerpoint-slides.pdf (3 pages)
right: fixtures\realworld\powerpoint-slides.pdf (3 pages)
aligned  left 1  right 1  same
aligned  left 2  right 2  same
aligned  left 3  right 3  same
summary: aligned 3, changed 0, inserted 0, deleted 0
identical: true
```

### Deleted page in the middle

```text
> pdfxi compare fixtures\realworld\powerpoint-slides.pdf target\tmp\slides-minus-p2.pdf
left:  fixtures\realworld\powerpoint-slides.pdf (3 pages)
right: target\tmp\slides-minus-p2.pdf (2 pages)
aligned  left 1  right 1  same
deleted  left 2
aligned  left 3  right 2  same
summary: aligned 2, changed 0, inserted 0, deleted 1
identical: false
```

Page 3 is still paired with right page 2 and reported `same`: content alignment,
not page numbers.

### Inserted page (same files, reversed)

```text
> pdfxi compare target\tmp\slides-minus-p2.pdf fixtures\realworld\powerpoint-slides.pdf
left:  target\tmp\slides-minus-p2.pdf (2 pages)
right: fixtures\realworld\powerpoint-slides.pdf (3 pages)
aligned  left 1  right 1  same
inserted right 2
aligned  left 2  right 3  same
summary: aligned 2, changed 0, inserted 1, deleted 0
identical: false
```

### Changed page with side-by-side lines

```text
> pdfxi compare fixtures\authoring\authoring-page-boxes.pdf fixtures\minimal.pdf --lines
left:  fixtures\authoring\authoring-page-boxes.pdf (1 pages)
right: fixtures\minimal.pdf (1 pages)
aligned  left 1  right 1  changed  -1 +1
page 1 | page 1  changed  -1 +1
  - All five page boxes | + Hello, PDFXI!
summary: aligned 1, changed 1, inserted 0, deleted 0
identical: false
```

### Exit status for scripts

```text
> pdfxi compare fixtures\authoring\authoring-page-boxes.pdf fixtures\minimal.pdf --fail-on-difference
...
identical: false
Error: the documents differ
exit=1
```

`--fail-on-difference` on the same file returns `0`.

## Scope

No pixel-level visual diff and no compare UI widget, as the row states. The GUI
side-by-side model in `pdfxi-app` is unchanged; the reachable host is this CLI,
which performs the same alignment/classification and prints the panes as text.
