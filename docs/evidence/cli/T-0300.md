# T-0300 — version snapshots and history (`MANAGE-005`)

Row promoted: `MANAGE-005` (Version compare and history)
`model` -> `verified`.

The row's model compared text snapshots in `pdfxi-app`. This task gives the CLI
a persistent version store and diffs snapshots with the bounded
`pdfxi_edit::compare` hunk model already used by `compare --hunks`.

## 1. Host

```text
pdfxi versions snapshot <FILE> --store PATH [--label L] [--json]
pdfxi versions list --store PATH [--json]
pdfxi versions diff <LEFT> <RIGHT> [--store PATH] [--json]
pdfxi versions remove <ID> --store PATH [--json]
```

- **Store**: JSON `{ "version": 1, "next_id": N, "snapshots": [...] }` with one
  snapshot per revision (id, label, source path, pages of normalised lines).
  Written through a sibling temporary file and renamed, so a failed write cannot
  truncate the store. An unknown `version` is refused, ids are never reused, and
  at most 256 snapshots are kept.
- **Snapshot**: opens the PDF with `pdfxi-core`, extracts each page's text,
  trims and drops empty lines, and validates page/line/byte counts against
  `CompareOptions::default()`.
- **Diff**: each side is either a snapshot id (resolved through `--store`) or a
  PDF path (extracted live). Pages are matched by index and compared with
  `compare_documents`, producing `added`/`removed`/`changed` hunks with
  one-based page, old/new line numbers and both texts, plus a stable summary.
- The store holds text only: no PDF bytes, secrets or binary payloads.

## 2. Evidence

```text
> pdfxi versions snapshot target\tmp\ver1.pdf --store target\tmp\versions.json --label "draft"
store: target\tmp\versions.json
id: 1
label: draft
source: target\tmp\ver1.pdf
pages: 1
lines: 4

> pdfxi versions snapshot target\tmp\ver2.pdf --store target\tmp\versions.json
id: 2
pages: 1
lines: 5

> pdfxi versions list --store target\tmp\versions.json
#1  target\tmp\ver1.pdf  1 pages  4 lines  "draft"
#2  target\tmp\ver2.pdf  1 pages  5 lines
snapshots: 2

> pdfxi versions diff 1 2 --store target\tmp\versions.json
left:  draft (snapshot)
right: target\tmp\ver2.pdf (snapshot)
changed  page 1  old 2  new 2
  - bravo
  + BRAVO
added  page 1  old -  new 5
  + extra
summary: added 1, removed 0, changed 1, pages 1, hunks 2
identical: false

> pdfxi versions diff target\tmp\ver2.pdf 1 --store target\tmp\versions.json
...
summary: added 0, removed 1, changed 1, pages 1, hunks 2

> pdfxi versions remove 1 --store target\tmp\versions.json
removed: 1
snapshots: 1

> pdfxi versions diff 9 2 --store target\tmp\versions.json
Error: no snapshot 9 in target\tmp\versions.json (known: 2)
```

A real 3-page `powerpoint-slides.pdf` snapshot reports `pages: 3`, and diffing
it against the same file is `identical: true` with zero hunks.

- `versions_snapshot_list_diff_and_remove` builds two real text PDFs, snapshots
  both, checks the JSON store version, lists both ids and labels, diffs id/id and
  file/id, verifies an identical file/id diff, removes an id and re-lists,
  rejects an unknown id with the known-id list, and lists an absent store as
  empty.
- `versions_snapshot_real_world_document` snapshots the real PowerPoint fixture
  (3 pages, non-zero lines) and asserts a self-diff is identical with no hunks.

## Scope

Version snapshots, listing, diffing and removal are reachable on real PDFs with
a persistent store. History is text-only (no binary revisions), diffs match
pages by index, and there is no merge or restore operation.
