# T-0314 — Office conversion host (`CREATE-006`)

Row promoted: `CREATE-006` (Create PDF from Microsoft Office via adapter)
`model` -> `verified`.

The row validated an already-extracted Office bundle and produced a
deterministic conversion plan targeting the Office adapters, but wrote no PDF.
This task is the host that turns the imported model into a real PDF.

## 1. Host

```text
pdfxi create office <BUNDLE.json> --out PDF [--strict] [--json]
```

```json
{ "kind": "word", "title": "Quarterly Report",
  "markup": "<h1>Quarterly Report</h1><p>Hello PDFXI.</p>" }
```

- `kind` accepts `word`/`excel`/`powerpoint` plus the usual extensions
  (`docx`, `xlsx`, `pptx`, …).
- The bundle is validated by `validate_office_envelope` and planned by
  `build_office_conversion_plan` (or the strict variant), which names the
  canonical adapter target and deterministic output part.
- `import_office_bundle_with_report` produces the shared `OfficeDocument`.
  Paragraphs, list items, table rows (`cell | cell`) and text boxes are laid out
  as text in a page of the model's exact width/height; unsupported blocks are
  skipped but reported by the plan.
- Each model page becomes one PDF page (empty pages become a blank page) and the
  pages are merged in order with `PagePlan::merge`.
- The output is reopened, text is extracted, and every normalized expected line
  must be found. `--json` reports the plan, counts, unsupported kinds, PDF page
  count, verified lines and bytes.

The bundle contains a heading, a paragraph, a two-row table and a page break;
`pdfxi text` returns `Quarterly Report`, `Hello PDFXI.`,
`Region | Sales`, `West | 42` and `Second page body.`.

## Scope

The Office extractor (OOXML/COM/LibreOffice to HTML/XML markup) remains a host
adapter: this command consumes markup the caller has already produced. Output is
text-only — images, charts, exact fonts, colours, inline styles and positioned
layout are not reproduced, and unsupported constructs are reported rather than
approximated. Page size comes from the bundle model (A4), not the source
document.
