# T-0293 — linearization and object-stream layout hosts (`STD-003`)

Row promoted: `STD-003` (Object streams and linearization)
`library` -> `verified`.

Both writers already lived in `pdfxi-core` (`save_linearized` and
`save_with_object_streams`), and the row's test list covers their layouts. There
was no user-reachable path, so this task adds two commands and verifies the
written files by reopening them.

## 1. Hosts

```text
pdfxi linearize <FILE> --out PATH [--version 1.7] [--json]
pdfxi pack <FILE> --out PATH [--no-compress] [--max-objects N] [--json]
```

- `linearize` calls `Document::save_linearized`, reopens the output, reads the
  `/Linearized` dictionary, rejects it unless the declared `/L` equals the
  written byte count and `/N` equals the page count, checks that the hint range
  lies inside the file, and compares every page's text with the source. It
  reports the first-page object, first-page-section end, main xref offset and
  hint range.
- `pack` calls `Document::save_with_object_streams` with the requested
  compression and `/ObjStm` member limit, reopens the output, checks for both an
  `/ObjStm` and a `/XRef` stream, and compares every page's text with the
  source. `--max-objects` is rejected outside 1-65535.

## 3. Tests

```text
> cargo test -p pdfxi-cli --test cli linearize
test linearize_writes_a_valid_and_deterministic_file ... ok
test linearize_and_pack_handle_a_hybrid_source ... ok
test result: ok. 2 passed
```

- `linearize_writes_a_valid_and_deterministic_file` runs twice on
  `fixtures/minimal.pdf`, compares the two outputs byte-for-byte, checks the
  declared length, one verified page, the first-page object and hint range, and
  compares `pdfxi text` before and after.
- `linearize_and_pack_handle_a_hybrid_source` runs on the real Excel hybrid
  fixture: linearization declares the right length, two pages and two verified
  text pages; packing reports both object and xref streams and two verified text
  pages; both outputs extract the same text as the source; `--max-objects 0` is
  refused.

## Scope

Linearized and object-stream/xref-stream output are reachable and verified for
text and page structure. Incremental object-stream appends
(`save_object_stream_increment`) are exercised by core tests but are not exposed
as a separate CLI command; `pdfxi update` uses the classic/xref-section writer
that matches its source.
