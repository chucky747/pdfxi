# T-0323 — Tag tree and reading order editor host (`ACCESS-001`)

Row promoted: `ACCESS-001` (Tag tree and reading order editor) `model` ->
`verified`.

The authoring model and reading-order export existed, but the row's own note
recorded "no tag-tree/reading-order editor UI and no PDF byte writer". This task
adds the CLI editor.

## 1. Host

```text
pdfxi accessibility order <FILE.pdf> [--json]
pdfxi accessibility move <FILE.pdf> --out OUT.pdf --node N [--before M] [--json]
```

- `order` walks the catalog `/StructTreeRoot` `/K` arrays in pre-order and
  prints one `(node id, role)` row per `/XI_NodeId` element.
- `move` finds the node's owning element (or the tree root), removes it from the
  parent `/K` array, and reinserts it before the named sibling, or at the end
  when `--before` is omitted.
- The document is saved, reopened, and the order is recomputed; the moved node
  must appear before the target. `--json` reports the full new order.

## 2. Evidence

```text
> pdfxi accessibility order target\tmp\a11y-tagged.pdf --json
{"count": 5, "order": [
  {"node":1,"role":"document"}, {"node":2,"role":"paragraph"},
  {"node":3,"role":"table"}, {"node":4,"role":"tableheader"},
  {"node":5,"role":"tabledata"}]}

> pdfxi accessibility move target\tmp\a11y-tagged.pdf --out target\tmp\a11y-moved.pdf --node 3 --before 2 --json
{
  "before": 2, "node": 3, "position": 1,
  "order": [1, 3, 4, 5, 2], "bytes": 2444
}

> pdfxi accessibility order target\tmp\a11y-moved.pdf
0	1	document
1	3	table
2	4	tableheader
3	5	tabledata
4	2	paragraph
nodes: 5
```

Moving node 4 to the end of its table yields order `[1, 3, 5, 4, 2]` with
`position: 3`.

Rejections:

```text
> ... --node 99
Error: no structure element with /XI_NodeId 99

> ... --node 2 --before 4     # 4 is nested under the table
Error: node Some(4) is not a sibling

> pdfxi accessibility order fixtures\minimal.pdf
Error: the catalog has no /StructTreeRoot reference
```

## Scope

The editor reorders existing `/XI_NodeId` structure elements in tagged PDFs (the
shape written by `pdfxi structure apply`). It does not create/delete nodes,
change roles, add marked-content associations, or provide a GUI tree view.
