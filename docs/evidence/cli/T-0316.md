# T-0316 — Office integration plan/execute host (`PLAT-003`)

Row promoted: `PLAT-003` (Microsoft Office integration) `model` -> `verified`.

The library already planned and executed both directions (`import-to-pdf`,
`pdf-to-office`) but had no CLI host. This task exposes the contract and
re-reads the produced output.

## 1. Host

```text
pdfxi office plan <MANIFEST.json> [--json]
pdfxi office convert <MANIFEST.json> --out <OUTPUT> [--json]
```

Import manifest:

```json
{ "family": "word", "flow": "import-to-pdf", "name": "Report",
  "markup": "<h1>Report</h1><p>Hello integration.</p>" }
```

Export manifest:

```json
{ "family": "excel", "flow": "pdf-to-office", "name": "Book",
  "pages": [ { "width": 595, "height": 842,
               "runs": [ { "text": "Region", "x": 40, "y": 800, "font_size": 11 } ],
               "tables": [ { "name": "Data", "rows": [["Region","Sales"],["West","42"]] } ] } ] }
```

- `family` accepts `word`/`excel`/`powerpoint` and the usual extensions.
- `plan` builds `OfficeIntegrationEnvelope`, calls `plan_office_integration`,
  and prints the family, flow, sanitized output name, page/block counts, typed
  unsupported findings and the ordered adapter steps. Nothing is written.
- `convert` executes the plan. It enforces the extension produced by the flow,
  writes the bytes, then re-reads them:
  - `import-to-pdf` must start with `%PDF-`, parse through `pdfxi-core`, and
    have non-empty extracted text.
  - `pdf-to-office` must start with `PK\x03\x04` and contain the family's
    required part (`word/document.xml`, `xl/workbook.xml` or
    `ppt/presentation.xml`).
- `--json` reports the plan plus the verification counts. No Office process,
  COM object or OOXML reader is involved.

## Scope

This is a file-level integration: no COM add-in, Office ribbon, external
Office/LibreOffice process, file-drop event, or archive reader beyond the
in-process writer. Import output is a text-flow PDF (`create_from_text`), so it
does not preserve the bundle's page boundaries or styling. Export accepts only
run/table content supplied in the manifest.
