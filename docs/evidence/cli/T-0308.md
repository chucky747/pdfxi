# T-0308 — scriptable-operation registry host (`AUTO-005`)

Row promoted: `AUTO-005` (CLI for every scriptable operation)
`model` -> `verified`.

The row delivered `OperationRegistry` with typed descriptors and call plans but
explicitly left the CLI adapter out. This task adds it.

## 1. Host

```text
pdfxi ops list [--json]
pdfxi ops resolve <NAME> [NAME=VALUE ...] [--json]
```

- `list` builds `OperationRegistry::with_defaults()` and prints every operation
  in deterministic alphabetical order with its parameters. Optional parameters
  are marked `?` and every parameter carries a stable type (`string`, `bool`,
  `integer`, `path`). JSON shape: `{ "operations": [{ "name", "params": [...]
  }], "count" }`.
- `resolve` prepends the operation name and calls `registry.resolve`, which
  validates the operation, parameter names, required values, duplicates and
  typed values. Output is alphabetical by parameter and includes each value and
  its type plus the plan's stable `summary`.
- Resolution is pure: it never runs an action, opens a file, or touches the
  network.

```text
> pdfxi ops resolve run-batch action=batch.act input=in.pdf overwrite=true --json
{
  "operation": "run-batch",
  "arguments": [
    { "name": "action", "ty": "string", "value": "batch.act" },
    { "name": "input", "ty": "path", "value": "in.pdf" },
    { "name": "overwrite", "ty": "bool", "value": "true" }
  ],
  "summary": "run-batch\taction=batch.act\tinput=in.pdf\toverwrite=true"
}

> pdfxi ops resolve run-toolset name=demo limit=3
operation: run-toolset
limit	integer	3
name	string	demo
arguments: 2
summary: run-toolset	limit=3	name=demo
```

Rejections are typed:

```text
> pdfxi ops resolve run-batch input=x
Error: operation 'run-batch' requires parameter 'action'

> pdfxi ops resolve nope
Error: unknown operation 'nope'

> pdfxi ops resolve run-batch action=a colour=red
Error: operation 'run-batch' has no parameter 'colour'

> pdfxi ops resolve run-toolset name=t limit=abc
Error: parameter 'limit' expects an integer, got 'abc'

> pdfxi ops resolve run-batch action=a overwrite=maybe
Error: parameter 'overwrite' expects true or false, got 'maybe'
```

## Scope

This exposes the registry contract, not a generic `ops run` executor:
execution stays with the existing `action`, `droplet` and `api` commands, which
the registry descriptors mirror. Path values are validated as strings by the
model; file existence and safety remain the executing command's responsibility.
