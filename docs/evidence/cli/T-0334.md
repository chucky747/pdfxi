# T-0334 — 3D annotation host (`MEDIA-003`)

Row promoted: `MEDIA-003` (U3D and PRC 3D viewing) `model` -> `verified`.

`pdfxi_render::three_d` already modelled the `/3DD` stream reference, format,
named views, activation event/state, animation and the backend plan. It had no
host. This task adds `pdfxi media3d`, which reads real `/3D` annotations and
extracts the payload for a native 3D viewer.

## 1. Host

```text
pdfxi media3d <INPUT.pdf> [--extract PAYLOAD.u3d|.prc] [--json]
```

- Scans every page `/Annots` for `/Subtype /3D`.
- Reads `/3DD` (must be an indirect object or bounded name), its stream
  `/Subtype` (`U3D`/`PRC`) and the decoded payload length.
- Reads `/3DV`: one view dictionary or an array; each view's `/XN` name and
  `/IN true` default flag. A missing `/3DV` degrades to a single `Default` view.
- Reads `/3DA`: `/A` activation event, `/D` activation state, `/AN` animation.
- Validates through `ThreeDAnnotation::parse` and prints the active view, the
  backend requirements and the stable plan descriptor.
- `--extract` writes the fully decoded `/3DD` bytes (filter chain applied).

## 2. Evidence

Fixture: one page, `/Annots [4 0 R]`, annotation `/3D` with `/3DD 5 0 R`,
`/3DV [6 0 R 7 0 R]` (Overview default, Close-up) and
`/3DA << /A /PI /D /L /AN true >>`; object 5 is a 27-byte `/U3D` stream.

```text
> pdfxi media3d target\tmp\threed.pdf
file: target\tmp\threed.pdf  pages: 1  annotations: 1
page 1  annotation 4  format u3d  stream object:5:0  payload 27 bytes
  views [Overview, Close-up]  active Overview  activation PI/L  animate true
  requirements: decoder:u3d, animation, view-activation
  plan: three-d-plan/v1|stream=object:5:0|format=u3d|view=0|event=PI|state=L|animate=1|requirements=decoder:u3d,animation,view-activation
EXIT=0

> pdfxi media3d target\tmp\threed.pdf --extract target\tmp\threed-payload.u3d --json
"format": "u3d",
"payload_bytes": 27,
"views": ["Overview", "Close-up"],
"active_view": "Overview",
EXIT=0
extracted_bytes=27 prefix=U3D
```

Rejections:

```text
> pdfxi media3d <plain text PDF>
Error: ... declares no /3D annotations
```

## Scope

Inspection, planning and payload extraction only. The command does not decode
U3D/PRC geometry, rasterize a 3D scene, animate, switch views interactively or
write annotations. A native 3D backend realises the printed plan; the extracted
payload can be opened by an external viewer today.
