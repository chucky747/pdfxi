# T-0353 — Loupe and gesture host (`VIEW-018`)

Row promoted: `VIEW-018` (Loupe magnifier and gesture navigation) `model` ->
`verified`.

The row's boundary note says: "The host feeds `GestureDelta`s into `apply` and
draws `dest_rect`." This task supplies that host headlessly, on a real page.

## 1. Host

```text
pdfxi loupe FILE [--page N] [--zoom Z] [--lens WxH] [--shape rectangle|circle]
    [--viewport WxH] [--center X,Y] [--commands GESTURES] [--json]
```

- The page comes from the real document (one-based, bounds-checked); the default
  viewport equals the page's media size.
- `LoupeModel::new` validates the geometry and clamps `--zoom` into 1..=16.
  `--center` moves the page-space lens centre with the model's clamping.
- `--commands` is a semicolon-separated gesture list:
  - `drag:DX,DY` and `scroll:DX,DY` (bounded per-step, clamped accumulation),
  - `pinch:FACTOR`, `zoom-in`, `zoom-out`,
  - `center:X,Y`, and `reset` (clears the accumulator only).
- The report gives the page/viewport/lens geometry, requested and applied zoom,
  lens centre in page and screen space, `dest_rect`, `source_rect`, accumulated
  drag, shape-aware containment of the lens centre, the
  `screen_to_page(page_to_screen(center))` round trip, and every step's effect
  (`ignored`, `panned`, `zoomed`) and resulting zoom/centre.

No native pointer/scroll/pinch capture, OS window or magnified raster rendering
is involved; those remain the GUI host boundary, exactly as the row documents.

"page_width": 612.0, "page_height": 792.0, "shape": "rectangle",
"requested_zoom": 3.0, "zoom": 6.0, "lens_width": 240.0,

The 3x + pinch:2 case lands at 6x; the 20x request clamps to the documented 16x
maximum, and the page/screen round trip returns the lens centre.

Rejections:

```text
> loupe ... --page 0     -> Error: --page is one-based and must be at least 1
> loupe ... --page 9     -> Error: --page 9 is outside 1..=1
> loupe ... --zoom 0     -> Error: --zoom must be finite and positive
> loupe ... --lens 0x100 -> Error: --lens needs finite positive dimensions
> loupe ... --viewport wide -> Error: --viewport "wide" needs WxH
> loupe ... --shape square -> Error: unknown lens shape "square"; expected rectangle or circle
> loupe ... --center a,b  -> Error: --center x "a" is not a number
> loupe ... --commands swipe -> Error: unknown loupe command "swipe"
> loupe ... --commands drag:1 -> Error: drag "1" needs DX,DY
> loupe ... --commands pinch:x -> Error: pinch factor "x" is not a number
> loupe <not a PDF>      -> Error: parse ...
```

## Scope

The complete loupe/gesture model is user-reachable from the CLI on real pages:
geometry, zoom clamping, page/screen inverses, source/dest rectangles,
shape-aware hit testing, bounded drag/scroll/pinch handling, accumulator reset
and deterministic stepping. Native pointer/scroll/pinch capture, the OS window
and magnified raster rendering remain the GUI host boundary and are not claimed.
