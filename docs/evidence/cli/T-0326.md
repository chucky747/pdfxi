# T-0326 — Cross-file search host (`MANAGE-003`)

Row promoted: `MANAGE-003` (Cross-file search and index) `model` -> `verified`.

The app model ranked caller-supplied page text but had no host that reads a
folder. This task adds `pdfxi find-files`.

## 1. Host

```text
pdfxi find-files <PATH...> --query TEXT [--case-sensitive] [--whole-word]
    [--max-results N] [--max-per-file N] [--json]
```

- Directories are scanned recursively for `.pdf` files (10 000-file and
  32-level caps); explicit files are searched as given.
- Each page's text is extracted through `pdfxi-core`, wrapped in a `TextPage`
  and matched with `pdfxi_text::search`, so case/whole-word rules are the shared
  engine's.
- Results group by file then page with a snippet around the first match. Files
  rank by reported match count, then path.
- `--max-results` and `--max-per-file` trim the reported matches and set
  `truncated`; `--json` reports scanned/matched files, totals and the ranked
  groups.

## 2. Evidence

```text
{
  "query": "needle",
  "files_scanned": 2,
  "files_matched": 2,

                   "snippet": "needle here and needle again." } ] },
    { "file": "...\\two.pdf", "matches": 1,
      "pages": [ { "page": 1, "matches": 1,
                   "snippet": "one needle only." } ] }
  ]

> pdfxi find-files target\tmp\find-src --query needle
query: "needle"  files_scanned: 2  files_matched: 2  matches: 3
...\one.pdf	page 1	2	needle here and needle again.
...\two.pdf	page 1	1	one needle only.
```

```text
> pdfxi find-files ... --query needle --max-results 2 --json
"files_matched": 1, "total_matches": 3, "reported_matches": 2, "truncated": true

> pdfxi find-files ... --query NEEDLE --case-sensitive --json
"total_matches": 0
```

Rejections: a missing directory reports `does not exist`; an empty query is
rejected by the argument parser.

## Scope

Live search, not a persisted index: each run re-reads and re-extracts the
folder. Only `.pdf` inputs are considered; encrypted documents that cannot be
parsed fail the command. Ranking uses reported (post-cap) counts, and snippets
are raw extracted text around the first match.
