# T-0306 — PostScript ingestion host (`CREATE-013`)

Row promoted: `CREATE-013` (PostScript and Distiller-compatible ingestion)
`model` -> `verified`.

The row had a bounded DSC reader and an assembly plan but no writer, so an
import stopped at a plan. This task adds the missing text/vector PDF writer and
the user-facing command.

## 1. Host

```text
pdfxi create postscript <INPUT.ps|eps> <OUTPUT.pdf> [--strict] [--json]
```

- Reads the file bytes and calls `ingest_postscript` (or
  `ingest_postscript_strict`) from `pdfxi-convert::postscript_ingest`.
- Writes the captured pages with the new `pdfxi-convert::postscript_pdf`:
  standard Type 1 fonts (Helvetica/Bold, Courier, Times), Latin-1 literal
  strings with delimiter escapes, `re`/`f`/`S` rectangles, and `m`/`l`/`S`
  lines. Page boxes come from `%%BoundingBox`, otherwise from content extents
  plus a margin. Object numbers and number formatting are fixed, so repeated
  imports are byte-identical.
- Reopens the generated PDF, checks the page count and confirms every captured
  text run extracts from its page.
- Reports `kind` (`PS`/`EPS`), pages, declared pages, bounding box, text/line/
  rectangle counts, unsupported findings (page, kind, token, reason), `clean`,
  `strict` and bytes.
- `--strict` makes any unsupported construct a typed error instead of a report.


The input was:

```postscript
%!PS-Adobe-3.0
%%BoundingBox: 0 0 300 200
%%Pages: 1
%%Page: 1 1
/F1 findfont 18 scalefont setfont
20 150 moveto (Hello PostScript) show
10 10 100 40 rectfill
5 5 moveto 150 5 lineto 2 setlinewidth stroke
showpage
%%Trailer
```

An EPS body reports `kind: EPS` with no declared pages, a two-page file reports
`pages: 2`, `declared_pages: 2`, `verified_pages: 2`, and an unsupported arc is
reported rather than guessed:

```text

  "unsupported": [
    { "kind": "complex-path", "token": "fill",
      "reason": "only straight two-point lines and axis-aligned rectangles are captured" },
    { "kind": "operator", "token": "arc",
      "reason": "operator is outside the supported text/line/rectangle/fill subset" }
  ]

> pdfxi create postscript target\tmp\bad.ps target\tmp\bad2.pdf --strict

```

A file without `%!PS-Adobe` fails with `missing %!PS-Adobe DSC header`.

## Scope

This is a documented text/line/rectangle subset, not a PostScript interpreter:
curves, arbitrary paths, images, transforms, colour spaces, fonts beyond the
five standard faces, DSC includes and `atend` resolution are reported or
rejected. No external Distiller or Ghostscript is invoked. Images never reach
the writer because the ingester records them as unsupported.
