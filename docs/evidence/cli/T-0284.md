# T-0284 — `pdfxi reflow` and `pdfxi read-aloud`: the accessibility text host

Row promoted: `VIEW-013` (Reflow and read aloud) `model` -> `verified`.

## What ships

The row's remaining scope was "no TTS engine and no audio device; the host feeds
utterances to a speech backend". This task adds that host boundary headlessly, in
two commands over the same extracted page text:

```text
pdfxi reflow <FILE> [--width N] [--page N] [--json]
pdfxi read-aloud <FILE> [--wpm N] [--page N] [--seek N] [--json]
```

**`reflow`** — paragraph segmentation on blank lines (a single newline is a soft
break and becomes a space), then greedy wrapping at word boundaries to
`--width` characters (`20..=200`, default `80`). A word longer than the width is
kept whole, so it is the only way a line can exceed the width. `--page` is
one-based; every page is reflowed when it is omitted. JSON carries `width`,
`line_count` and per-page `paragraphs` and `lines`.

**`read-aloud`** — one utterance per sentence, ordered by page then position, with
integer-millisecond timing:

```text
word_ms           = 60_000 / wpm          (wpm 80..=400, default 180)
sentence_pause_ms = word_ms / 2
page_pause_ms     = word_ms * 2
duration_ms       = words * word_ms
pause_ms          = sentence_pause (+ page_pause on a non-final page's last sentence)
```

No floating point is involved, so timings are reproducible. `•` is treated as a
sentence boundary because the shipped slide fixtures use it between a title and
its sentence (`Lantern Slide•The lantern…`), and `3.14` is *not* split because a
terminator only ends a sentence before whitespace or end of text. `--seek N`
drops the first `N` utterances and rebases the remaining clock to `0`, keeping
the original indices — the scriptable form of seek. A seek past the end is a
typed error.

Neither command opens an audio device or calls a speech engine.

## Real-document evidence

```text
> pdfxi reflow fixtures\realworld\powerpoint-slides.pdf --width 40 --page 1
page: 1
  Lantern Slide•The lantern slide marker
  is the first landscape page.

lines: 2
```

```text

  "file": "fixtures\\realworld\\powerpoint-slides.pdf",
  "width": 40,
  "pages": [
    {
      "page": 1,
      "paragraphs": 1,
      "lines": [
        "Lantern Slide•The lantern slide marker",
        "is the first landscape page."
      ]
    },
    {
      "page": 2,
      "paragraphs": 1,

        "Meadow Slide•The meadow slide marker is",
```

```text
> pdfxi read-aloud fixtures\realworld\powerpoint-slides.pdf
utterance 0  page 1  0-832 ms  2 words
  Lantern Slide
utterance 1  page 1  832-4661 ms  9 words
  The lantern slide marker is the first landscape page.
utterance 2  page 2  4661-5493 ms  2 words
  Harbor Slide
utterance 3  page 2  5493-9322 ms  9 words
  The harbor slide marker is the second landscape page.
utterance 4  page 3  9322-10154 ms  2 words
  Meadow Slide
utterance 5  page 3  10154-13983 ms  11 words
  The meadow slide marker is the third and final landscape page.
total: 6 utterance(s), 13983 ms at 180 wpm
```

`832 - 0 = 666` (2 words × 333) + `166` (sentence pause); utterance 1 adds the
page pause: `2997 + 166 + 666 = 3829`, ending at `4661`.

```text
> pdfxi read-aloud fixtures\realworld\powerpoint-slides.pdf --seek 2 --json
{ "wpm": 180, "word_ms": 333, "seek": 2, "total_duration_ms": 9322,
  "utterances": [
    { "index": 2, "page": 2, "text": "Harbor Slide", "start_ms": 0, ... },
    ... ] }
```

Seeking to utterance 2 keeps its original index and restarts the clock at `0`,
ending at `13983 - 4661 = 9322` ms.

## Scope

No TTS engine, no audio device, and no read-along highlight: the CLI prints what
a backend would be handed and when. The desktop models in `pdfxi-app`
(`reflow.rs`, `read_aloud.rs`) are unchanged; the CLI implements the host
policy over the same extracted text, and the book CLI page documents both
commands and their fixed-point conventions.
