# T-0367 — Portable install payload completeness and regression test

Fresh-eyes review of `v0.1.1` found blocking defect B1: the portable
`install.ps1` payload allowlist did not include `install.ps1` itself, even
though `scripts/package.ps1` lists it in the archive and in `manifest.json`.
Every portable install therefore failed its own manifest, and the installed
copy of the script stayed at the pre-fix revision.

## Defect reproduced on the installed 0.1.1 tree

```text
display_version=0.1.0
unins_product_version=0.1.0
installer_sha=602698C146772A835D3FBB6433432C41FA3515ED52FE7BAF6D0A86311DF23461
source_sha_011=7CBD1794E851104CFAC1EEFD34EEDBDBB1BF167A1B635465A674421A16CF36C5
manifest_version=0.1.1
manifest_problems=1
mismatch install.ps1
entries=66
```

The installed script was byte-identical to `2e24f52:scripts/install.ps1`
(the pre-fix v0.1.0 revision).

## Fix

`scripts/install.ps1`:

- adds `install.ps1` to the explicit payload allowlist, so the installed tree
  matches the archive and its manifest;
- adds a `Test-SamePath` guard so a payload file, the PDFium licence directory
  and the guide directory are skipped when source and destination are the same
  path. This makes a re-run of the installed script against its own directory
  a safe no-op instead of a copy-onto-itself error;
- keeps the T-0364 behavior: the guide contents are merged (no `docs\docs`
  nesting) and a legacy `docs\docs` is removed on every run.

No network, elevation, registry, or Start Menu behavior changed.

## Automated regression test

New `scripts/test-portable-install.ps1` builds a synthetic portable payload
(the real installer, stub binaries, licences, guide pages, schema-1 SHA-256
manifest) under `target\tmp\portable-install-test` and runs five scenarios:
fresh install into a path containing a space, manifest self-check, upgrade
with a changed and a new guide page, a legacy `docs\docs` layout, and an
in-place run. It needs no network, no elevation and no package build.

Positive run against the fixed installer:

```text

PASS fresh_install_no_nested_docs
PASS fresh_install_guide_section
PASS upgrade_install_exit
PASS upgrade_merges_changed_page
PASS upgrade_adds_new_page

PASS legacy_install_exit
PASS legacy_nested_docs_removed
PASS legacy_manifest

PORTABLE_INSTALL_TEST passed=18 failed=0

```

Negative run against the shipped v0.1.1 installer (`git show
6861026:scripts/install.ps1`), proving the test fails without the fix:

```text
FAIL fresh_install_copies_installer
FAIL fresh_install_installer_hash
FAIL fresh_install_manifest missing install.ps1

FAIL legacy_manifest missing install.ps1

PORTABLE_INSTALL_TEST passed=11 failed=7
NEGATIVE_EXIT=1
```

`-InstallerPath` exists only for this negative proof; normal runs test
`scripts/install.ps1`.

## Wiring

- `cargo xtask installer-test` now runs `scripts/test-portable-install.ps1`
  before the Inno smoke installer, so the portable contract is part of the
  installer gate even on a host without Inno Setup.
- `scripts/package.ps1 -SelfTest` TEST 7 now installs twice, verifies the
  installed tree against its own manifest, checks the installed script hash,
  injects a legacy `docs\docs` and requires its removal:

```text
TEST 7 installer_copy PASS exit=0 upgrade=0 verified=49 installer_copied=1 nested_removed=1
SELFTEST passed=10 failed=0
SELFTEST_EXIT=0
```
