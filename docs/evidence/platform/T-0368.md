# T-0368 — Corrected release `v0.1.2`

The fresh review of `v0.1.1` requested changes. `v0.1.1` is pushed and stays
immutable; the corrected release is `v0.1.2`.

The review's blocking finding B1 was real: the portable installer did not copy
`install.ps1`, so every portable install failed its own manifest, and the real
install still carried the pre-fix `v0.1.0` script plus `v0.1.0` uninstall
metadata because it had never been upgraded through the setup.

## 6. Review should-fix closure

- Automated installer regression test: added and wired (T-0367); the negative
  run against the shipped v0.1.1 script fails 7 checks.
- Blocker "terminated cleanly" wording: corrected; line 9 now says the viewer
  was force-stopped and line 39 says the session recovered after the recorded
  sign-out/restart.
- `unresolved_link_warnings=0`: removed from the `cargo xtask verify` output
  block and labelled as a separate measurement.
- Memory inbox note for the corrective work: written for this release.
- Stale `orchestration/BOARD.md`: regenerated with `cargo xtask board`.
- `v0.1.1` remains immutable; `v0.1.2` is the superseding tag.

## 7. Residual risks (not blocking)

- The installed user guide still includes internal pages (`plan.md`,
  `memory.md`, `testing.md`, `architecture.md`) and some relative links point
  outside the package. This predates the release and is tracked as a docs
  cleanup follow-up; it does not affect product behavior.
- `pdfxi.exe` has no VERSIONINFO resource (the viewer does). No claim depends
  on a CLI file version.
- macOS remains CI-only; the shipped artifacts are Windows x86_64.
- The Inno setup needs a TEMP path where the session may execute Inno's helper.
  This is an agent-sandbox restriction, not an end-user requirement.
