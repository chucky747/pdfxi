# T-0364 — Installer docs merge fix (review blocking 1)

Fresh-eyes review found that `scripts/install.ps1` copied the user guide with
`Copy-Item -LiteralPath $docsSource -Destination $docsTarget -Recurse -Force`.
When `$target\docs` already existed (every upgrade), PowerShell copied the
`docs` directory **into** it, producing `docs\docs\...`. The viewer serves
`<install>\docs`, so the installed Help kept the stale guide and T-0360's new
"Retired capture features" section was only reachable under `docs\docs`.

## Fix

`scripts/install.ps1` now:

1. creates `$target\docs` explicitly and copies the guide **contents**
   (`Copy-Item -Path "$docsSource\*" -Destination $docsTarget -Recurse -Force`),
   so an upgrade merges over the previous guide instead of nesting it; and
2. removes a `docs\docs` directory left by an older installer, so the viewer's
   `<install>\docs` path always serves the current guide.

No other installer behavior changed: payload allowlist, PDFium licence copy,
Start Menu shortcuts, desktop shortcut and uninstall files are untouched.
