## What packaging produces

Under `target/package/`:

```text

```

The portable payload CLI is `pdfxi.exe` (workspace crate `pdfxi-cli`,
`[[bin]] name = "pdfxi"`). The installer copies those files to a caller-supplied
`-TargetDir` and creates a per-user Start Menu shortcut; it never elevates and
never calls the network. `-Check` scans `install.ps1` for
`Invoke-WebRequest|Invoke-RestMethod|WebClient|RunAs|Start-Process` and fails if
any appear. No PDFium DLL is bundled; PDFium is notice-only in THIRD_PARTY.md.
No Adobe asset is copied. Only an 8-name allowlist is staged, and every staged
file is screened against seven secret/private-file regex families.

Reproducibility inputs recorded in `manifest.json`: `rustc`/`cargo` version
strings, pinned toolchain channel, edition and MSRV, SHA-256 of `Cargo.lock`,
the complete `name@version` crate list from `Cargo.lock`, binary names
(`pdfxi.exe`), and per-file SHA-256 plus byte length. There is deliberately no
wall-clock timestamp, so identical inputs yield a byte-identical manifest. Zip
entry timestamps are normalized to 1980-01-02 local before compression.
