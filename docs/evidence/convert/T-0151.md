## What changed

- `crates/pdfxi-convert/src/image.rs`: added bounded raster validation
  (`MAX_IMAGE_DIMENSION`, `MAX_IMAGE_PIXELS`, `MAX_IMAGE_BYTES`), two new
  dependency-free encoders (`encode_bmp` 32-bit bottom-up BGRA, `encode_tiff`
  little-endian uncompressed single-strip RGBA with an 11-tag IFD), extended
  `ImageFormat` with `Bmp`/`Tiff`, and expanded the PNG/zlib/CRC test coverage.
  Baseline JPEG is intentionally not re-implemented here: it is already provided
  and verified by the renderer-backed `pdfxi-render` encoder (EXPORT-006).
- `crates/pdfxi-convert/src/html_export.rs`,
  `crates/pdfxi-convert/src/office_export/xml.rs`, and the new
  `crates/pdfxi-convert/tests/export_adapters.rs`: added deterministic,
  escaping, structure-ordering, empty-document, malformed-input and per-row
  determinism tests across HTML, DOCX/XLSX/PPTX, RTF, PostScript, text/JSON and
  image export.
- `crates/pdfxi-convert/src/lib.rs`: re-exported the new image encoders/bounds
  and the Office model/error types (`OfficeBlock`, `OfficePage`, `OfficeCell`,
  `CellValue`, `ModelError`, `DocxExportError`, `XlsxExportError`,
  `PptxExportError`) so callers can construct models and match errors without
  reaching into submodules.

No shared file, `docs/features.toml`, or `orchestration/BOARD.md` was edited.
Feature changes are reported in `orchestration/feature-updates/T-0151.toml`.

## Honest scope

The affected rows remain `in-progress`. This task closes library-level gaps:
bounded RGBA encoders, deterministic/structured/escaped serialization, and
cross-adapter regression coverage. It does **not** add PDF byte parsing, CLI or
UI dispatch, a tagged-PDF writer, or a baseline JPEG entropy encoder. Those
remain documented follow-ups (JPEG is already covered by the verified
`pdfxi-render` EXPORT-006 path). No row is falsely marked verified or replaced.
