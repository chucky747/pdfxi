# T-0180 - portfolio package assembly and export closure

Lane: `convert`. Target dir: `target/lanes/convert`, re-run by the integrator in
`target/integration`. Date: 2026-11-19.

## Delivered (crates/pdfxi-convert/** only)

- `portfolio_package.rs` (CREATE-010): real PDF package assembly. Typed
  `PdfValue`/`PdfObject` object graph, caller-supplied embedded-file streams,
  byte-sorted `/EmbeddedFiles` name tree, `/Collection` dictionary with manifest
  fields, deterministic catalog/page/xref/trailer, no timestamps, no file-system
  access, bounded sizes and typed errors. `Document::from_bytes` parses the
  output back.
- `extract_model.rs` (EXPORT-001/002/003/005): validated pages, runs, tables and
  text boxes with deterministic reading order, typed unsupported constructs, and
  end-to-end plain-text and RTF byte emitters (UTF-8/UTF-16BE, deterministic).
- `office_export_plan.rs` (EXPORT-001/002/003): pages to paragraphs/runs/tables/
  slides, deterministic numbering, typed unsupported findings, validated
  `OfficeExportEnvelope` with a stable manifest and `write()` through the
  existing in-process OOXML writers.
- `conformance.rs` (EXPORT-008): per-target forbidden-entry tables,
  `ForbiddenEntryPolicy::{Report, Reject}`, typed
  `ConformanceExportError::ForbiddenEntry`, `present_forbidden_entries()`, a
  `PLAN.FORBIDDEN_ENTRIES` plan step and nested `/Names /EmbeddedFiles`
  detection.
- `tests/t0180_closure.rs`: 9 public-API closure tests.
- `lib.rs`: module wiring, re-exports and rustdoc.
