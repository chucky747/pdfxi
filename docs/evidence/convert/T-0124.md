## What was delivered

- **CLI `create` group** (`pdfxi-cli/src/create.rs`, wired in `src/main.rs`):
  - `pdfxi create image <INPUT> <OUTPUT>` — PNG/JPEG to a one-page PDF.
  - `pdfxi create text <INPUT> <OUTPUT>` — UTF-8 text / Markdown to a
    paginated PDF.
  - Documented options: `--page-size letter|a4`, `--margin <PT>`,
    `--font-size <PT>`, `--line-height <FACTOR>`; `--markdown` on `create text`.
  - Typed library errors (`pdfxi_convert::CreateError`) are surfaced with path
    context at the CLI boundary; output is deterministic (byte-identical for
    identical input + options).
- **CLI `export` group** (`pdfxi-cli/src/export.rs`):
  - `pdfxi export tagged <INPUT.pdf> <OUTPUT.txt> [--format structured|plain]`.
  - Derives a deterministic `pdfxi_accessibility::A11yTree` from extracted page
    text via `ReadingOrderBuilder`, then calls the public
    `pdfxi_convert::export_tagged_text` API. Emits roles/reading-order/text.
- **Public API already existed** in `pdfxi-convert` (`create::*`,
  `export_tagged_text`, `export_structured_text`, `export_plain_text`); this task
  adds the CLI path, tests, honest scope docs, and the feature fragment.
- Documentation: `crates/pdfxi-convert/src/create.rs` (supported image/Markdown
  subset + CLI), `crates/pdfxi-convert/src/tagged_text.rs` (structured text only,
  not PDF/UA certification), `docs/book/src/authoring.md` (CLI examples and
  subset). Feature matrix itself is integrator-owned; fragment below.

## Sample end-to-end output

```
$ pdfxi create text doc.txt out.pdf       # doc.txt = "Hello PDFXI.\nSecond line.\nThird line."
wrote .../out.pdf (text, 1019 bytes); EXIT=0
$ pdfxi info out.pdf
pdf_version: 1.4 / pages: 1
$ pdfxi export tagged out.pdf tagged.txt
wrote .../tagged.txt (tagged structured text, 62 bytes); EXIT=0
$ cat tagged.txt
@document
  @page
    @p Hello PDFXI. Second line. Third line.
```

The structured export preserves document -> page -> paragraph roles in reading
order and the original text content. It is a structured text representation,
**not** a tagged-PDF file and **not** a PDF/UA certification; producing
tagged-PDF structure remains with the accessibility lane.
