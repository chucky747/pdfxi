# T-0163 - HTML, conformance, and PostScript export closure

Lane: `convert`. Target dir: `target/lanes/convert`, verified in
`target/integration`.

## Delivered

- `crates/pdfxi-convert/src/html_export.rs` (extended): deterministic
  document-level HTML export with DOCTYPE/nav/pages in ascending order,
  positioned spans with inverted Y, escaped text, safe link schemes only,
  per-page image policy, single-file and page-set modes, style hooks, typed
  errors for empty/duplicate/malformed input, and document-wide span/link
  budgets.
- `crates/pdfxi-convert/src/conformance.rs` (extended): PDF/A, PDF/X, PDF/E
  conformance plans with target selection, required metadata and output-intent
  steps, enforced vs report-only step reporting, deterministic summaries, and
  honest `certification=false` reporting. No external validator claim.
- `crates/pdfxi-convert/src/postscript.rs` (extended): deterministic PostScript
  export with DSC headers (`%%BoundingBox`, `%%Pages`, `%%Page`, fonts), page
  sections, standard-font positioned text, path operators for rect/line,
  escaping of `\\`, `(`, `)` and control characters, and typed geometry/title
  errors.
- `crates/pdfxi-convert/src/lib.rs`: module docs and re-exports.
