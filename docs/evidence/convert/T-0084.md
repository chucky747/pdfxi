## Files changed

- `crates/pdfxi-convert/src/create/html.rs` (new): bounded HTML tokenizer and
  parser with deterministic recovery. Supports h1–h6, p, strong/em, code/pre,
  ul/ol/li, table/tr/th/td, blockquote, hr, local a (text only), br and local
  PNG/JPEG images, plus a CSS subset (font-size/weight/style/family, color,
  text-align, margin-*, border shorthand/width/color/style, text-decoration,
  tag/class selectors). Typed rejections for script, inline event handlers,
  `javascript:`/`remote`/`file:`/`data:` URLs, traversal/absolute/symlink
  escapes, and size/node/depth/attribute/rule/declaration bounds.
- `crates/pdfxi-convert/src/create.rs`: typed `CreateError` variants
  (`HtmlScriptRejected`, `HtmlRemoteResource`, `HtmlPathTraversal`,
  `HtmlTooLarge`, `HtmlStructure`), `Span`/`TextAlign`/`LineBorder`/
  `FlowItem`/`PlacedItem` layout vocabulary, and generalized `layout_items`
  shared with the plain-text and Markdown paths. Existing text/Markdown/image
  output remains byte-identical.
- `crates/pdfxi-convert/src/lib.rs`: public re-exports and crate docs.
- `crates/pdfxi-convert/tests/html_pdf.rs` (new): integration tests including
  round-trips through `pdfxi-core`.

## Scope and safety

- No new dependencies; no `unsafe`; no `unwrap`/`expect`/`panic!` in non-test
  code.
- Remote resources are never fetched; only local, validated image paths inside
  the caller-provided base directory are read.
- Output is deterministic: same input bytes produce the same PDF bytes.
