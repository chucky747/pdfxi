## What was delivered

- `crates/pdfxi-convert/src/preflight.rs`: loads PDF bytes through
  `pdfxi-core`, builds a preflight snapshot, runs the selected profile via
  `pdfxi-standards`, and applies opt-in fixups that are expressible on bytes
  (version/XMP/output-intent normalization through the existing conformance
  path), with a typed report separating enforced from reported-only checks and
  no certification claim.
- `crates/pdfxi-cli/src/preflight.rs`: `pdfxi preflight <profile> <input>
  [--fix] [--json]`, deterministic output and typed exit codes.
- `crates/pdfxi-cli/src/marks.rs`: `pdfxi marks <input> <output>
  [--crop-marks] [--registration] [--colour-bars] [--page-info]` using the
  core byte-level application API (`Document::apply_printer_marks`), reparse
  verified.
- `crates/pdfxi-cli/tests/cli.rs`: integration tests for both commands.

## Scope

Preflight remains a subset: ICC validity, veraPDF-style cross-validation, and
backend-dependent checks are reported, not certified. PRINT-007 now has a
user-visible CLI path that writes boxes/marks into a real document.
