# T-0359 - Rustdoc link warning sweep (lane convert)

Date: 2026-11-22
Scope: documentation-only fixes so RUSTDOCFLAGS="-D warnings" cargo doc
--workspace --no-deps exits 0. No behavior, API, or feature-matrix changes.

## Files changed and warning addressed

### Library crates (broken links)

- crates/pdfxi-edit/src/document_annotations.rs - AnnotationEditError::EmptyContents
  does not exist; linked the real variant AnnotationEditError::EmptyText.
- crates/pdfxi-edit/src/navigation/document_navigation.rs - DEFAULT_MIME_TYPE
  is a pub const inside the private navigation::attachment module (the module
  is declared mod attachment;, not re-exported), so public docs may not link
  it; converted to a plain code span.
- crates/pdfxi-render/src/win_print.rs - module-level doc linked
  PrintBackendError::Unsupported without a resolvable scope; added the explicit
  public target crate::win_print::PrintBackendError::Unsupported.

### crates/pdfxi-cli binary-crate module docs

The binary target module //! docs are resolved against the crate root, so names
that are only imported inside each module did not resolve. Public items were
given explicit public paths; private or non-existent items became plain code
spans.

- src/export_postscript.rs - PsDocument -> pdfxi_convert::PsDocument.
- src/office.rs - OfficeBundle -> pdfxi_convert::OfficeBundle; OfficeDocument ->
  pdfxi_convert::OfficeDocument.
- src/office_roundtrip.rs - OfficeIntegrationPlan ->
  pdfxi_convert::OfficeIntegrationPlan.
- src/plugin.rs - pdfxi_automation::plugin_output is a private module; plain
  code span.
- src/restyle.rs - RunStyleOverride -> pdfxi_edit::RunStyleOverride.
- src/script.rs - AcrobatContext -> pdfxi_automation::AcrobatContext.
- src/separations.rs - SeparationsPlan -> pdfxi_app::print::SeparationsPlan.
- src/signature.rs - pdfxi_forms::signature, pdfxi_forms::signatureplan and
  pdfxi_forms::signing are private modules (only their types are re-exported);
  plain code spans.
- src/prepress.rs - TrappingPreset, FlattenPolicy, TrapPlan ->
  pdfxi_render::trapping::*.
- src/protection.rs - ProtectionPolicy -> pdfxi_security::ProtectionPolicy.
- src/trust.rs - RsaPkcs1Verifier -> pdfxi_security::RsaPkcs1Verifier.
- src/compare.rs - MAX_ALIGNMENT_CELLS and MAX_DISPLAY_LINES are private
  constants in the same file; plain code spans (module doc and the private
  differing_lines doc).
- src/reflow.rs - selected_pages is pub(crate); plain code span.
- src/structure.rs - A11yTree -> pdfxi_accessibility::A11yTree.
- src/sequence.rs - ActionSequence -> pdfxi_automation::ActionSequence;
  SequenceStepRunner -> pdfxi_automation::SequenceStepRunner in the module doc
  only (the private item doc at line 194 already resolved and was left as a
  plain bracket link).
- src/timestamp.rs - SignatureProvider -> pdfxi_security::SignatureProvider.
- src/flatten.rs - pdfxi_edit::flatten is both a module and a function;
  disambiguated the model link as fn@pdfxi_edit::flatten.
