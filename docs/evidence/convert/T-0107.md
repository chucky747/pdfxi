# T-0107 evidence — local capture adapters and watched folders

Lane: `convert`. Target dir: `CARGO_TARGET_DIR=target/lanes/convert`
(set by `. .\scripts\env.ps1 -Lane convert`). Claim: `cargo xtask claim
T-0107 --lane convert` → `CLAIMED T-0107 for convert`, `CLAIM_EXIT=0`.

## Scope delivered

- **CREATE-011** — `crates/pdfxi-convert/src/capture.rs`: local page capture
  through the existing bounded HTML subset. `capture_html_file` (rooted,
  traversal-free local file, images resolved next to the file),
  `capture_html_markup` (caller-supplied markup), and `capture_mhtml` (first
  `text/html` part of an MHTML-like `multipart/related` payload; quoted-printable
  and base64 supported; resource parts ignored, never fetched). No remote fetch,
  network, or browser extension.
- **CREATE-012** — `crates/pdfxi-convert/src/email.rs`: local `.eml` ingestion.
  Folded RFC 5322 headers, bounded recursive MIME parsing, `text/plain` and
  `text/html` bodies (HTML preferred), attachment **names only** (content is
  never decoded or embedded), typed errors and bounded reads.
- **CREATE-014 / AUTO-003** — `crates/pdfxi-automation/src/watched.rs`:
  validated rooted folder config, deterministic `plan()`, host-driven
  `poll_once` with a caller-supplied `FolderConverter`, one `FileOutcome` per
  file, in-memory idempotency markers, symlink rejection, and no background
  thread or OS watcher.
- Shared bounded MIME helpers: `crates/pdfxi-convert/src/mime.rs`.
- Two pre-existing rustdoc link warnings in owned files (`office_export/mod.rs`,
  `preflight.rs`) were corrected so `cargo doc --no-deps` passes with
  `RUSTDOCFLAGS=-D warnings`.

No new dependencies, no `unsafe`, no `unwrap`/`expect`/`panic!` in non-test
code, no CLI or shared-file edits.
