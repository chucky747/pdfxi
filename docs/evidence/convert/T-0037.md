# T-0037 — PDF/A and PDF/X preflight

Status: verified (task); PRINT-002, STD-007, STD-008, STD-009 stay in-progress
until ICC validation, fixups, and veraPDF-backed conformance land.

## Files

- `crates/pdfxi-standards/src/input.rs` — documented input abstraction carrying
  version, catalog flags, page boxes, fonts, colour spaces, image filters,
  transparency usage, and XMP presence.
- `crates/pdfxi-standards/src/document_profile.rs` — `PdfA1b`, `PdfA2b`,
  `PdfX1a`, and `PdfX4` profiles with deterministic finding order and stable
  codes such as `PDFA1B.NO_OUTPUT_INTENT`.
- `crates/pdfxi-standards/src/profile.rs` — report assembly and severity
  filtering.

## Verification

```text
$ . .\scripts\env.ps1 -Lane convert
$ cargo test -p pdfxi-standards
27 passed; 0 failed; 0 ignored; 0 doctests
$ cargo clippy -p pdfxi-standards --all-targets -- -D warnings
clean
$ cargo fmt -p pdfxi-standards -- --check
clean
```

Coverage: one conforming and one non-conforming input per profile, stable
finding codes, ordering independent of discovery order, severity filtering, and
stable report summaries.

## Limits

Checks are limited to decidable facts in the input abstraction. Full byte-level
conformance (ICC profiles, embedded-font validation, veraPDF corpus, PDF/E,
PDF/VT, and fixups) remains future work.
