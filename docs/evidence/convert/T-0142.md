## What was delivered

- `crates/pdfxi-convert/src/postscript_ingest.rs`: bounded DSC reader with
  `%%BoundingBox` / `%%Pages` / `%%Page` / `%%Trailer` / `%%EndComments` parsing,
  EPS-vs-PS detection (`EPSF` header token, or bounding box with no `%%Page`
  markers), deterministic page ordering by ascending `%%Page` ordinal, and a
  documented minimal operator subset (`moveto`/`rmoveto`, `lineto`/`rlineto`,
  `newpath`, `closepath`, `rectfill`/`rectstroke`, `fill`/`stroke` limited to
  straight two-point lines and axis-aligned rectangles, `show` with escaped
  literal strings, and `findfont`/`scalefont`/`setfont`). Extracted content
  reuses the existing [`PsContent`] vector model from the writer. Input is
  bounded before parsing (bytes, lines, pages, tokens per page, stack depth,
  findings, text length). Every other construct is recorded once per page in a
  `PsIngestReport` with a stable `kind`/`reason`; strict mode promotes findings
  to a typed `PsIngestError::Unsupported`. Binary `%%BeginData`/`%%BeginBinary`
  sections are a typed error rather than a guess.
- `crates/pdfxi-convert/src/office_import.rs`: caller-supplied Office-derived
  HTML/XML bundle importer with a documented input envelope, page-break markers,
  Word namespace aliases (`w:p`, `w:tbl`, `w:tr`, `w:tc`, `w:t`, `w:br`), entity
  decoding, and mapping onto the existing `OfficeDocument` model so imported
  bundles immediately work with `DocxExporter`/`XlsxExporter`/`PptxExporter`.
  Active content, event-handler attributes, and remote `http(s)` references are
  typed errors; media and unknown tags are deterministic report findings.
  All sizes and block counts are bounded.
- `crates/pdfxi-convert/src/lib.rs`: both modules declared and their public API
  re-exported; crate-level documentation updated with honest scope notes.

## Honest remaining scope

CREATE-013: no full PostScript interpreter, no general graphics-state or
coordinate-transform modeling, no Bezier/path rasterisation, no image or font
embedding, no CID/keyed font handling, no DSC `(atend)` resolution across
`%%Trailer`, no `%%Include*` resource following, and no CLI/UI entry point.
CREATE-006: no ZIP/OOXML archive reading, no real Office extraction, no COM or
LibreOffice subprocess, no inline-style fidelity, no image/media embedding, and
no CLI/UI entry point. Neither row claims certification or full parity.
