# PDFXI 0.1.5 release notes

PDFXI 0.1.5 is a Windows x64 release. It replaces GitHub CI with a local gate,
signs the build with a local self-signed certificate, adds a real screen-reader
gate, and closes the remaining ADR 0009 rows.

## Verification and release engineering

- **Local CI replaces GitHub CI.** `cargo xtask ci` runs fmt, clippy with
  warnings denied, the workspace and feature tests, `cargo doc -j 1`, the
  feature matrix, mdBook, the benchmark gate, `cargo xtask installer-test`, the
  NVDA screen-reader smoke against the installed viewer, and the Authenticode
  check when `PDFXI_SIGN_THUMBPRINT` is set. It writes `target/ci/ci-report.md`
  and exits non-zero on the first failure. `scripts/register-local-ci.ps1` is
  an opt-in Windows Task Scheduler nightly wrapper.
- **Code signing.** `scripts/new-signing-cert.ps1` creates a local code-signing
  certificate and `scripts/trust-signing-cert.ps1` trusts it in the current
  user's Root and TrustedPublisher stores. `scripts/package.ps1` signs
  `pdfxi.exe`, `pdfxi-ui.exe` and the setup executable, and verifies each
  signature. **This is a local self-signed publisher: it is not a publicly
  trusted publisher, other machines do not trust it, and SmartScreen may still
  warn there.** A public OV/EV certificate remains required for distribution.
  See `orchestration/blockers/T-0202-code-signing.md`.
- **Screen reader.** `scripts/screen-reader-smoke.ps1` runs a real NVDA 2026.3
  session with its Speech Viewer, drives the shell with real keyboard input and
  asserts 14 announcements (window, Open/Print/Fit, Pages/Comments, page number,
  next page, Fill & Sign, and the text/checkbox/choice form widgets with names,
  roles and values). It fails closed when NVDA is absent.

## Feature-row close-out (ADR 0009)

- **EXPORT-006** is `verified` on the GUI host: the export card offers all nine
  A-27 targets including a multi-page TIFF, and `pdfxi render --format tiff`
  reaches the same encoder.
- **CREATE-008** is `verified` on the CLI host: `pdfxi create ocr` recognizes the
  image itself with `--engine auto|tesseract|windows`. Tesseract is used when
  installed; otherwise the built-in Windows.Media.Ocr sidecar runs. A real
  Excel page rendered to JPEG produced 22 words and a 72,531-byte searchable
  PDF whose extracted text contains those words.
- **CREATE-007** is `verified` on the CLI host: `pdfxi create scan --device`
  acquires pages from an attached WIA scanner through the bundled sidecar
  (BMP-to-PNG conversion when a driver ignores the requested format). A real
  HP Officejet Pro 6830 produced a 2550x3549 page and a verified 612x851.76 pt
  PDF.
- **SEC-003** is `verified` on the CLI host: `pdfxi recipient seal/open` is real
  certificate-addressed AES-CBC/AES-KW encryption with a permission gate.
- **STD-007** is `verified` on the CLI host: `pdfxi preflight` and
  `pdfxi export conformance` validate and normalize real files with no
  certification claim.
- **REVIEW-007** is `verified` on the CLI host: `pdfxi review status` rebuilds
  the tracker from a real PDF's `/IRT` and `/State`, and `pdfxi annotate reply`
  writes replies and states.
- **VIEW-002, VIEW-006, VIEW-012** are `verified` on the GUI host: the bottom
  bar has Page layout, Split view and Present controls with widget tests.
- **REVIEW-001** is `verified` on the GUI host: note, highlight, underline,
  strikeout and squiggly are all reachable from the Comments panel; squiggly
  gained a real writer and zigzag appearance.
- **AUTO-008** is `replaced` per ADR 0014: the sandboxed plugin plan/output
  contract is the plugin surface, no WebAssembly is loaded, and a future WASM
  host is a new row. **PLAT-002** stays `deferred` because the project is
  Windows-only.

## Fixed and added

- `pdfxi render` gained `--format tiff` and `--format jpeg`.
- `pdfxi annotate reply` writes a real `/IRT` reply and can set the parent's
  `/State`.
- The unit-test harness' command-coverage guard now proves the new commands.

## Verification

- `cargo xtask goal-verify --all` prints
  `GOAL VERIFIED: <git-sha> <unix-time>`.
- `cargo xtask ci` is green on this host with the NVDA smoke and the signature
  check.
- The 0.1.5 setup is signed, verifies, installs per-user, and leaves a working
  desktop shortcut to the installed `pdfxi-ui.exe`.

## Limits

Windows x86_64 is the only verified target. Signing is local/self-signed, not a
publicly trusted publisher. TWAIN is not spoken directly (WIA only), and OCR
runs one image page per command with no deskew or language auto-detection.
