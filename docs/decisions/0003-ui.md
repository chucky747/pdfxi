# ADR 0003 — Desktop UI

## Status

Accepted.

## Context

The application needs a custom PDF canvas, dockable panels, tabs, keyboard
navigation, and accessibility. A web UI would add a second language and runtime.

## Decision

Use `egui`/`eframe` with `wgpu` and `accesskit`. Keep the UI in `pdfxi-app` and
all document operations in feature crates.

## Consequences

- Fast iteration and a single Rust toolchain.
- Accessibility requires explicit accesskit work.
- The UI can be replaced later without changing core contracts.
