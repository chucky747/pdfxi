# T-0108 — blocked by path overlap with T-0109

## Status

Deferred, not failed. Core lane attempted `cargo xtask claim T-0108 --lane core`
and received:

```text
Error: claim conflict: T-0108 owns crates/pdfxi-core/** which overlaps
crates/pdfxi-core/** owned by security (T-0109)
```

## Cause

T-0108 (incremental updates, STD-010) and T-0109 (password and certificate
encryption writer, SEC-001) both legitimately need `crates/pdfxi-core/**`.
T-0109 claimed first, so T-0108 stopped before editing, per RULES §4.

## Resolution

1. T-0109 keeps `crates/pdfxi-core/**` while it implements the encrypting save
   integration.
2. T-0108 stays queued; it is re-dispatched to the core lane after T-0109
   releases its claim.
3. No files were edited by the blocked attempt, and no claim file exists for
   T-0108.

## Next viable alternative

If T-0109 has not released when the core lane frees, the core lane takes a
non-overlapping task (for example STD-001 closing work in a later wave) rather
than waiting idle. Incremental save remains on the critical path for M4.
